# 離子阱與中性原子量子電腦：系統架構、連接與操作指南

> 本指南把兩種「原子型」量子電腦拆解成子系統，說明每個子系統的功能、彼此怎麼連接，以及從開機到量子處理器可以執行線路的完整流程。最後與超導系統比較設施需求。
> 搭配簡報 `slides/Ion_NeutralAtom_Talk.pptx`、演講稿 `speech/離子阱與中性原子演講稿.md` 與 3D 動畫 `animations/atoms.html`（18 個場景）；對話形式的入門見 `docs/離子阱與中性原子師生對話教學紀錄.md`。
>
> **數值性質**：除非另外註明，數值都是公開文獻與廠商資料中的**代表值**（來源見文末），實際依原子種類、阱設計與廠商而異。離子阱以 ¹⁷¹Yb⁺ 為例，中性原子以 ⁸⁷Rb 為例。

## 1. 一張表看懂兩個平台

| 項目 | 離子阱 | 中性原子 |
|---|---|---|
| 量子位元載體 | 帶電原子（離子） | 不帶電原子 |
| 囚禁方式 | RF 電場（Paul 阱），離子懸浮於電極上方 50–100 μm | 聚焦雷射（光鑷），深度 ~1 mK、腰寬 ~1 μm |
| 量子位元 | ¹⁷¹Yb⁺ 超精細 \|F=0,m=0⟩ ↔ \|F=1,m=0⟩，12.6428 GHz | ⁸⁷Rb 超精細 \|F=1,m=0⟩ ↔ \|F=2,m=0⟩，6.8347 GHz |
| 初始化 | Doppler + 邊帶冷卻；光泵浦到 \|0⟩ | MOT 冷卻 → 裝進光鑷 → 成像 + 重排；光泵浦到 \|0⟩ |
| 單位元閘 | 微波（12.6 GHz）或 355 nm Raman，1–10 μs | 全域微波 / Raman + 局部光位移（AOD 定址），~1–100 μs |
| 雙位元閘 | Mølmer–Sørensen（共享振動模態），10–200 μs | 芮德堡阻斷 CZ（420 + 1013 nm），~0.2–0.5 μs |
| 讀取 | 狀態相依螢光（369 nm）→ PMT / 相機，100–300 μs | 推出 \|1⟩ + 螢光成像（780 nm）→ 相機，1–20 ms |
| 連接性 | 同一條離子鏈全連接；QCCD 搬運 | 由 AOD 搬運決定，任意配對 |
| 擴展方式 | QCCD 晶片 → 2D 阱 → 光子互連 | 更大光鑷陣列、分區架構、連續補充原子 |
| 環境 | 超高真空 < 10⁻¹¹ mbar；室溫或 4–20 K 低溫恆溫器 | 超高真空玻璃腔；室溫 |

## 2. 離子阱系統

### 2.1 子系統

| 子系統 | 主要設備 | 功能 |
|---|---|---|
| 真空與阱 | 超高真空腔（或低溫恆溫器）、表面電極阱晶片、離子泵、NEG 吸氣劑、原子爐或燒蝕靶、真空計 | 提供無碰撞環境，懸浮並排列離子 |
| 雷射 | 369.5 nm（冷卻 / 光泵浦 / 偵測）、935 nm（回泵）、399 nm（光游離）、355 nm 脈衝雷射（Raman 閘）、638 nm（選用回泵） | 冷卻、初始化、閘、讀取、裝載 |
| 光學與調變 | AOM（開關、調頻）、EOM（GHz 邊帶）、光纖、偏振與指向穩定、波長計、參考腔 | 把每道光在正確時間、頻率、強度送到正確的離子 |
| 成像與偵測 | 高 NA 物鏡（真空內或外）、PMT / EMCCD / SPAD 陣列、濾光片 | 收集螢光，讀取量子位元 |
| RF 與 DC | RF 訊號源、放大器、螺旋共振器；多通道 DAC（數十～數百通道） | 囚禁電場；軸向位井與 QCCD 搬運波形 |
| 微波與磁場 | 12.6 GHz 微波源與號角；量化軸線圈與電流源；μ-metal 屏蔽 | 單位元閘；定義量化軸、抑制磁場雜訊 |
| 控制 | FPGA 時序系統（例：ARTIQ / Sinara）、DDS、即時計數判別、控制電腦、10 MHz 參考時脈 | 奈秒級時序、即時回饋、編譯與排程 |
| 設施 | 恆溫空調（光學桌 ±0.1 °C 等級）、雷射冷卻水、防振光學桌、潔淨度、UPS、網路 | 光路與頻率穩定、可用率 |

| 從 | 到 | 介質 | 說明 |
|---|---|---|---|
| 各雷射 | AOM / EOM | 自由空間光 | 每道光一個以上 AOM：開關（ns）、頻率、振幅 |
| AOM | 真空腔視窗 / 阱 | 單模光纖 + 聚焦光學 | 光纖隔離光學桌與真空腔；閘光束需聚焦到單顆離子 |
| 雷射 | 波長計 / 參考腔 | 光纖分光 | 頻率鎖定；鎖頻誤差訊號回饋到雷射 |
| DDS / AWG | AOM 驅動器 | 同軸 RF | 頻率、相位、振幅由 FPGA 即時控制 |
| RF 源 | 螺旋共振器 → 阱 RF 電極 | 同軸 + 真空饋通 | 數百伏、數十 MHz；振幅主動穩定 |
| 多通道 DAC | 阱 DC 電極 | 多芯真空饋通 + 低通濾波 | QCCD 需 μs 級更新的電壓波形 |
| 微波源 | 微波號角 | 同軸 / 波導 | 12.6 GHz 單位元閘 |
| 線圈電流源 | 磁場線圈 | 電纜 | 數高斯量化軸，電流穩定度影響相干 |
| 物鏡 | PMT / 相機 | 自由空間或多模光纖 | 螢光收集 |
| PMT / 相機 | FPGA | 數位脈衝 / 影像介面 | 即時計數與判別 |
| 銣鐘 / 氫邁射 | 所有 RF / 微波 / FPGA | 10 MHz 同軸 | 所有頻率鎖相（見第 6 節） |
| 控制電腦 | FPGA、DAC、雷射控制器 | 乙太網路 | 程式下傳、結果回傳 |
| 冷卻水機 | 雷射、放大器 | 水管 | 雷射溫度穩定 |
| UPS | 雷射控制器、電子、電腦、真空控制器 | 電力 | 停電時保持鎖頻與真空 |

### 2.3 從開機到可以執行線路

1. **真空確認**：真空計 < 10⁻¹¹ mbar；離子泵電流正常（新系統需烘烤數天）。
2. **雷射啟動與鎖頻**：369、935、399、355 nm 各自鎖頻；確認波長計讀值與 AOM 功率。
3. **RF 與 DC**：RF 振幅緩升到工作值，確認穩定；DAC 載入囚禁電壓組。
4. **裝載**：開原子爐或燒蝕 → 399 + 369 nm 光游離 → 相機確認離子顆數；必要時倒出多餘離子。
5. **冷卻與補償**：Doppler 冷卻；量測並補償 micromotion（調整補償電極電壓）。
6. **頻率校準**：量子位元頻率（微波或 Raman 掃頻）、Rabi 振盪找 π 時間、Ramsey 精修頻率。
7. **運動模態**：掃邊帶光譜找出各正規模頻率；邊帶冷卻到 n̄ < 0.1；量加熱率。
8. **讀取校準**：準備 \|0⟩ 與 \|1⟩ 各數千次，建立光子數直方圖、設定閾值、算判別保真度。
9. **兩位元閘校準**：MS / ZZ 閘的失諧、功率、相位；用 parity 振盪確認 Bell 態保真度。
10. **（QCCD）搬運校準**：每段搬運、分離 / 合併、接面的電壓波形；量測搬運後的加熱與相位。
11. **基準測試**：隨機化基準（RB）、跨位元串擾檢查 → 上線。

### 2.4 日常監控與異常

| 現象 | 可能原因 | 處置 |
|---|---|---|
| 離子突然消失 / 變暗 | 背景氣體碰撞、離子掉到 D 或 F 態 | 確認 935 / 638 nm 回泵；重新裝載 |
| 閘保真度下降 | 雷射功率或指向漂移、運動模態頻率漂移、加熱率上升 | 重新校準功率與模態頻率；檢查 RF 振幅穩定 |
| 讀取錯誤增加 | 偵測光頻率或功率漂移、背景光 | 重新鎖頻、檢查光路與遮光 |
| 頻率漂移 | 磁場變化、溫度變化 | 線圈電流與屏蔽檢查；Ramsey 追蹤頻率 |
| 搬運後錯誤 | 電壓波形不平滑、DAC 雜訊 | 調整波形、加強濾波、搬運後再冷卻 |

### 2.5 模組化擴展：光子互連

> 3D 動畫：`atoms.html#photonic`（場景 9）；對話說明見《師生對話教學紀錄》第 7 課。

| 子系統 | 主要設備 | 說明 |
|---|---|---|
| 通訊離子 | ¹³⁸Ba⁺（493 nm）或 ⁸⁸Sr⁺（422 nm），與記憶離子（¹⁷¹Yb⁺ / ⁴³Ca⁺）同阱 | 雙元素避免發光干擾記憶位元 |
| 激發 | ps 級超快脈衝雷射（π 脈衝） | 每次只放一顆光子；離子–光子以偏振 / 頻率 / time-bin 糾纏 |
| 收集 | 高 NA 物鏡 → 單模光纖 | 收集約 10 %，加上耦合與傳輸損耗後每顆光子總效率 η 約 1–3 % |
| 貝爾態分析站 | 50:50 分光鏡、偏振分光鏡、4 個單光子偵測器（SPAD / SNSPD）、符合計數電子 | 雙光子干涉 → 宣告 \|Ψ±⟩；要求兩邊光子無法分辨（波長、時間、偏振、模態匹配） |
| 古典連線 | 宣告訊號 → 兩邊 FPGA | 成功才進行下一步；失敗即重新冷卻、重試 |
| 頻率轉換（選用） | 非線性晶體 / 波導 | 轉到 1550 nm 通訊波段，走長距離光纖 |

- 成功率 p ≈ ½·η²；以每秒約 5×10⁵ 次嘗試計，η ≈ 2 % 時約 100 對 / 秒（Oxford 2020：182 對 / 秒、保真度約 94 %）。
- 成功後用本地 MS 閘把糾纏交給記憶離子，再以量子態 / 量子閘傳送連接模組；保真度不足時做糾纏純化。
- 校準重點：兩邊光子的波長與到達時間匹配（Hong–Ou–Mandel 干涉可見度）、光纖偏振補償、偵測器暗計數與時間窗。

## 3. 中性原子系統

### 3.1 子系統

| 子系統 | 主要設備 | 功能 |
|---|---|---|
| 真空與原子源 | 玻璃真空腔、Rb 原子源（dispenser / 2D MOT）、離子泵、NEG | 提供冷原子來源與無碰撞環境 |
| 冷卻（MOT） | 780 nm 冷卻 + 回泵雷射、6 道光束、反亥姆霍茲線圈、補償線圈 | 把原子冷到 ~10–100 μK |
| 光鑷 | 852 / 1064 nm 高功率雷射（數十 W 光纖放大器）、SLM、2D AOD、高 NA 物鏡 | 抓住單顆原子、排成陣列、搬運 |
| 閘雷射與微波 | 420 + 1013 nm 芮德堡雷射（鎖在超穩參考腔）、局部定址光束（AOD）、6.8 GHz 微波 | 單位元閘、CZ 閘 |
| 成像 | sCMOS / EMCCD 相機、成像光路、推出光 | 裝載確認、重排、讀取 |
| 即時控制 | FPGA（影像判別 + 重排路徑規劃）、多音 RF AWG（AOD）、DDS、控制電腦 / GPU | 數十 ms 內完成「拍照 → 算路徑 → 搬運」 |
| 設施 | 恆溫空調、防振光學桌、雷射冷卻水、UPS、網路 | 陣列位置與雷射穩定 |

### 3.2 連接清單

| 從 | 到 | 介質 | 說明 |
|---|---|---|---|
| 780 nm 雷射 | MOT 光束、成像、推出光 | 光纖 + AOM | 6 道 MOT 光束；成像與推出由 AOM 切換 |
| 光鑷雷射 | SLM → AOD → 物鏡 → 腔內 | 自由空間（高功率） | SLM 產生靜態陣列；AOD 產生移動光鑷 |
| 多音 RF AWG | AOD | 同軸 RF | 每個頻率 = 一列（或一欄）光鑷的位置 |
| 芮德堡雷射 | 參考腔 → AOM → 腔內 | 光纖 + 自由空間 | 全域照射糾纏區；相位 / 強度由 AOM 調變 |
| 定址雷射 | AOD → 物鏡 | 自由空間 | 局部光位移（Z 旋轉）、局部操作 |
| 微波源 | 微波號角 | 同軸 | 6.8 GHz 全域單位元閘 |
| 線圈電流源 | MOT / 補償線圈 | 電纜 | 裝載時開 MOT 梯度，計算時關閉並保留量化軸 |
| 相機 | FPGA / GPU | 高速影像介面 | 即時判別每格有無原子 |
| FPGA | AWG（AOD）、AOM 驅動 | 數位 / 同軸 | 重排路徑、脈衝時序 |
| 銣鐘 / 氫邁射 | 所有 RF / 微波 / FPGA | 10 MHz 同軸 | 頻率鎖相（見第 6 節） |
| 光頻梳 | 芮德堡雷射、參考腔 | 光纖 / 拍頻訊號 | 把光頻接回 10 MHz 基準 |
| 冷卻水機 | 光鑷放大器、雷射 | 水管 | 高功率雷射散熱 |
| UPS | 雷射控制器、電子、電腦、真空控制器 | 電力 | 停電時保持鎖頻與真空 |

### 3.3 從開機到可以執行線路

1. **真空確認**：< 10⁻¹¹ mbar（決定原子在光鑷中的壽命）。
2. **雷射鎖頻**：780 / 795 nm 鎖在原子譜線；420 / 1013 nm 鎖在超穩參考腔；光鑷雷射功率穩定。
3. **MOT 與冷卻**：開原子源與線圈，確認 MOT 原子數；偏振梯度冷卻到 ~10 μK。
4. **光鑷校準**：SLM 圖案均勻度（每個光鑷深度一致）、AOD 頻率對位置的對應。
5. **裝載 → 成像 → 重排**：確認裝載率（~50 %）、成像判別閾值、重排成功率。
6. **量子位元校準**：光泵浦、微波 Rabi / Ramsey 找頻率；局部定址光束對位與光位移量。
7. **芮德堡校準**：單原子芮德堡 Rabi 振盪、失諧與相位；兩原子阻斷確認；CZ 脈衝參數最佳化。
8. **搬運校準**：AOD 移動速度與加速度（避免加熱或損失）、搬運前後相位校正。
9. **讀取校準**：推出效率、成像保真度、原子損失率。
10. **基準測試**：單位元 RB、CZ 保真度（含並行）→ 上線。

### 3.4 日常監控與異常

| 現象 | 可能原因 | 處置 |
|---|---|---|
| 裝載率下降 | 原子源耗盡、MOT 光束功率或對準漂移 | 調整原子源電流、重新對準 |
| 原子壽命變短 | 真空變差、光鑷雷射雜訊加熱 | 檢查真空；光鑷強度雜訊抑制 |
| 陣列位置漂移 | 溫度變化造成光路漂移 | 恆溫、主動指向穩定、重新校準 SLM / AOD |
| CZ 保真度下降 | 芮德堡雷射相位雜訊或功率漂移、原子溫度上升 | 參考腔檢查、重新校準脈衝、加強冷卻 |
| 讀取錯誤增加 | 推出不完全、成像光漂移、原子損失 | 調整推出 / 成像參數；監控損失率 |

## 4. 設施與電力需求

| 項目 | 超導（參考） | 離子阱 | 中性原子 |
|---|---|---|---|
| 主要環境設備 | 稀釋冷凍機 + 壓縮機 | 超高真空腔（± 小型低溫恆溫器） | 超高真空玻璃腔 |
| 單套用電（量級） | ~25 kW（實測型） | Helios 官方 < 40 kW；Oracle 合作資料約 60 kW（不含外部空調） | 無官方數字；~10 kW 級（估計） |
| 最大負載 | 壓縮機 ~10.7 kW、冷卻水 ~10 kW | 雷射與其冷卻、控制電子、精密空調 | 光鑷雷射與其冷卻、控制電子 / GPU、精密空調 |
| 環境要求 | 冷卻水、防振、³He 供應 | 恆溫 ±0.1 °C 等級、防振、潔淨 | 恆溫、防振、潔淨 |
| 停電影響 | 重新降溫 2–5 天（最壞約 10 天），之後需完整校準（LRZ 實測） | 雷射重新鎖頻、重新裝載離子（數十分鐘～數小時） | 雷射重新鎖頻、重新裝載（數十分鐘～數小時） |
| 機櫃化 | 冷凍機難以機櫃化 | IonQ Forte Enterprise / Tempo 為機櫃式；Quantinuum Helios 進駐 Oracle 雲 | 系統以光學桌為主，商用機逐步模組化 |

建議的供電規劃（兩個原子平台通用）：

- **UPS** 涵蓋雷射控制器、鎖頻電子、真空控制器與控制電腦：避免短暫停電造成雷射失鎖、離子 / 原子遺失。
- **電源品質**：雷射驅動與 DAC 對雜訊敏感，建議隔離變壓器、單點接地，並將大功率負載（空調、冷卻水機）與精密電子分開配電。
- **溫度穩定**：光學桌附近的空調是關鍵負載；溫度漂移會直接造成光路漂移與頻率漂移。
- **冷卻水**：高功率雷射（光鑷、放大器）需要穩定的冷卻水；中斷會造成雷射停機。

## 5. 運算與讀取：三平台問答

> 3D 動畫：離子阱 `atoms.html#ionflow`（場景 7）、中性原子 `atoms.html#atomflow`（場景 16）。

### 5.1 量子特性從哪裡來？

| | 超導 JJ | 離子阱 | 中性原子 |
|---|---|---|---|
| 量子位元 | 人造原子：LC + 約瑟夫森接面的非線性，能階由電路決定 | 真原子：¹⁷¹Yb⁺ 超精細 F=0 ↔ F=1（12.6 GHz） | 真原子：⁸⁷Rb 超精細 F=1 ↔ F=2（6.835 GHz） |
| 一致性 | 每顆頻率不同，逐顆校準 | 每顆完全相同 | 每顆完全相同 |
| 「固定」方式 | 做在晶片上 | RF 電場（Paul 阱），阱只負責抓住 | 光鑷（852 nm 聚焦雷射） |

### 5.2 怎麼運算？

| 步驟 | 超導 JJ | 離子阱 | 中性原子 |
|---|---|---|---|
| 準備 | 等待熱化 / 主動重置（約 μs） | Doppler + 邊帶冷卻 → 光泵浦到 \|0⟩ | 裝載（約 50 %）→ 成像 → 重排 → 光泵浦 |
| 單位元閘 | XY 微波（4–8 GHz），20–50 ns | **全域微波** 12.6 GHz（無法只打一顆）或 **Raman 定址**（兩道 355 nm，頻差 = 12.6 GHz，聚焦約 1 μm），1–20 μs | **全域微波** 6.835 GHz / Raman；**定址** = 局部光位移（Z）+ 全域脈衝，約 1–100 μs |
| Z 閘 | 虛擬 Z | 虛擬 Z | 虛擬 Z / 局部光位移 |
| 雙位元「匯流排」 | 電容 / 可調耦合器、共振腔 | **共享振動模態（聲子）** | **芮德堡態的偶極交互作用**（平常關閉，激發後打開） |
| 雙位元閘 | CZ、iSWAP、CR，20–100 ns | Mølmer–Sørensen：自旋相依力讓振動在相空間繞一圈回原點，留下幾何相位 → exp(−iπ/4·XX)，10–200 μs | 芮德堡阻斷：R_b（約 8.7 μm）內兩顆原子最多一顆被激發 → CZ，0.2–0.5 μs |
| 連接性 | 固定最近鄰，遠的要 SWAP | 同一條鏈內全連接；QCCD 搬運 | AOD 搬運原子 → 任意配對、可並行 |

**為什麼 Raman 能做雙位元閘、微波不行？** 兩道雷射的動量差（Δk）能「推」離子，讓內部態和振動耦合；微波波長數公分，動量可忽略。電子式控制（微波 + 磁場梯度，Oxford Ionics / IonQ 路線）是另一個產生自旋相依力的方法。

**MS 閘 vs 芮德堡 CZ**：中性原子不帶電、各自在光鑷裡，沒有共享振動，所以不用 MS 閘。MS 的原生形式是 exp(−iπ/4·XX)（從 |00⟩ 直接得到 Bell 態），芮德堡 CZ 是 diag(1,1,1,−1)（|00⟩ 不變，要先做疊加）；兩者只差 Hadamard 與單位元 Z 旋轉，都是最大糾纏閘。MS 對離子溫度一階不敏感，芮德堡 CZ 在阻斷區內對確切距離不敏感。詳見《師生對話教學紀錄》第 6 課。

**慢不一定差**：離子的雙位元閘比超導慢約 1000 倍，但 T₂ 長數千倍以上，「相干時間 ÷ 閘時間」反而較大。

### 5.3 怎麼讀取？

| | 超導 JJ | 離子阱 | 中性原子 |
|---|---|---|---|
| 原理 | 色散讀取：量子位元狀態讓讀取共振腔頻率偏移 | **狀態相依螢光**（Dehmelt 電子擱置法）：369 nm 只和 \|1⟩ 的循環躍遷共振 | **推出 + 成像**：先把 \|1⟩ 推出光鑷，再拍 780 nm 螢光 |
| 亮 / 暗 | （微波訊號的相位與振幅） | **亮 = \|1⟩**、暗 = \|0⟩（\|0⟩ 差 12.6 GHz ≫ 線寬約 20 MHz） | **亮 = \|0⟩**、暗 = \|1⟩ |
| 偵測器 | JPA / TWPA + HEMT | 高 NA 物鏡 + PMT / EMCCD / SPAD（收集效率幾 %） | 高 NA 物鏡 + sCMOS / EMCCD |
| 時間 | 約 0.1–1 μs | 約 100–300 μs（亮態約 10–30 個光子 vs 暗態約 0） | 約 1–20 ms |
| 保真度 | 約 99 %+ | > 99.9 % | > 99 %（Caltech 2025 成像 > 99.99 %） |
| 量完之後 | 量子位元還在 | 離子還在，可重新初始化 | \|1⟩ 的原子被推走，要重新裝載；原子遺失會被讀成 \|1⟩ |
| 中途量測 | 讀取共振腔各自獨立 | 散射光會干擾鄰居 → 搬到偵測區或把其他離子藏到暗態 | 搬到讀取區、雙原子種類（Rb + Cs）、非破壞讀取 |

## 6. 頻率基準：氫邁射、參考腔與光頻梳

> 3D 動畫：`atoms.html#hmaser`（場景 8）、`atoms.html#atomclock`（場景 17）。簡報圖：`slides/figures/atoms/clock_stability.png`。

### 6.1 為什麼需要超穩定的參考？

單位元閘的旋轉角度由脈衝面積決定、旋轉軸由微波相位決定。微波源的頻率飄移會讓量子位元累積 Z 誤差，效果等同 dephasing。粗估：Ramsey 自由演化 T 秒內的相位誤差

  δφ ≈ 2π · f₀ · σ_y(T) · T（f₀：量子位元頻率，σ_y：參考源的 Allan 偏差）

| 參考源 | σ_y(1 s) | σ_y(約 1 天) | 12.6 GHz、T = 10 s 的相位誤差 |
|---|---|---|---|
| 石英 OCXO | ~10⁻¹² | 會漂移 | 約 0.8 rad |
| 銣鐘 | ~10⁻¹¹ | ~10⁻¹² | 約 2.5 rad（糊掉） |
| 銫鐘 | ~10⁻¹¹ | ~10⁻¹⁴ | 約 2.5 rad |
| **氫邁射** | **~10⁻¹³** | **~10⁻¹⁵** | **約 0.01 rad** |

（代表性經驗模型，量級正確；實際依機型而異。< 0.1 秒的短時間由石英決定，所以氫邁射內部也鎖一顆石英。）

### 6.2 氫邁射怎麼運作

1. **解離**：H₂ 經射頻放電拆成 H 原子，形成原子束。
2. **選態**：六極磁鐵（類似 Stern–Gerlach）把 F=1（m=+1、0，弱場尋求者）聚焦進儲存泡，F=0 與 m=−1 被甩開 → **粒子數反轉**。
3. **儲存**：內壁塗鐵氟龍的石英泡，原子停留約 1 秒、撞牆上萬次而相位幾乎不被破壞 → 線寬約 1 Hz，Q ≈ 10⁹。
4. **受激輻射**：泡放在調諧到 1,420,405,751.77 Hz 的銅色 TE₀₁₁ 共振腔中，增益超過腔損耗就自我維持振盪（maser）。輸出約 −100 dBm，再把石英 VCXO 鎖相上去，輸出 10 MHz / 100 MHz / 1 PPS。
5. **工程細節**：多層 μ-metal 磁屏蔽 + C 場線圈定義量化軸；腔體精密恆溫（cavity pulling：Δf ≈ (Q_腔/Q_原子)·Δf_腔）。

使用 m=0 ↔ m=0「時鐘躍遷」（對磁場一階不敏感），和 ¹⁷¹Yb⁺ / ⁸⁷Rb 量子位元選時鐘態的理由相同。歷史：1960 年 Ramsey、Kleppner、Goldenberg（哈佛）；1989 年諾貝爾物理獎 Ramsey（分離振盪場法與氫邁射）與 Paul、Dehmelt（離子阱技術）共享。

### 6.3 在系統中的位置

```
氫邁射 / 銣鐘 ──10 MHz──┬─> 微波合成器（PLL）──> 12.6 GHz（Yb⁺）/ 6.835 GHz（Rb）號角
                         ├─> DDS / AWG（脈衝相位與時序）、FPGA 時脈
                         └─> 光頻梳（f_rep、f_ceo）──拍頻──> 雷射頻率（絕對值）
芮德堡 / 光學量子位元雷射 ──PDH──> ULE 參考腔（短時間線寬 < 1 kHz）
```

- 氫邁射**不直接操作量子位元**，是整套系統的頻率基準。不是每個實驗室都需要：多數用銣鐘或 GPS 馴服振盪器，做長時間相干或精密量測才用氫邁射。
- **中性原子多一條雷射鏈**：芮德堡雷射的相位雜訊直接變成 CZ 錯誤。粗估只算線寬：ε ≈ π·Δν·t_gate（t_gate ≈ 0.25 μs）→ 自由運轉約 100 kHz 時約 8 %，鎖到 ULE 腔約 1 kHz 時約 0.08 %。實務上還要壓伺服鎖頻在 MHz 附近的相位雜訊（濾波腔）。
- **類氫結構**：H（I=1/2，1.420 GHz）、⁸⁷Rb（I=3/2，6.835 GHz，商用銣鐘同一條線）、¹³³Cs（I=7/2，9,192,631,770 Hz，定義「秒」）、¹⁷¹Yb⁺（I=1/2，12.643 GHz）——一顆價電子 + 核自旋 → 兩個超精細能階。
- **原子鐘也是中性原子平台**：銫噴泉鐘（Ramsey 法原型，自由演化約 0.5–1 秒）；鍶光晶格鐘、光鑷原子鐘與中性原子量子電腦共用硬體。離子阱也做最準的鐘之一（Al⁺ 量子邏輯鐘）。
- 超導的微波源同樣鎖 10 MHz，但 T₂ 約 0.1 ms，瓶頸是短時間相位雜訊而不是長期穩定度。

### 6.4 設施注意事項

| 項目 | 說明 |
|---|---|
| 安置 | 氫邁射體積與重量都大（機櫃級），需穩定溫度、遠離強磁場與振動源 |
| 電力 | 接 UPS；斷電後重新起振與穩定需要時間（數小時～數天才回到最佳穩定度） |
| 分配 | 10 MHz 分配放大器、相位穩定的同軸 / 光纖分配；各儀器的參考輸入都要接上 |
| 監控 | 鎖相狀態、與 GPS 的長期比對；ULE 腔的漂移率（例行用光頻梳校正） |
