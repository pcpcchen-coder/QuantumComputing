**項目之間的依賴關係：**

```
#2 現場勘查 ──→ 提供實測數據 ──→ #1 參考設計、#10 資料中心配電
#3 QGP 量測台 ─→ 規格與驗證 ──→ #5 DC-DC、#6 集中供電、#7 電流源、#9 高通道供電
#1 參考設計 ──→ 示範場域 ────→ 驗證平台（電源事件 ↔ 量子位元）
#4 變頻驅動 ──→ 壓縮機群管理 ─→ #1 的 UPS 容量、#10
#6 集中供電 ──→ 背板架構 ───→ #9
#8 低溫轉換 ──→ 獨立的長期線，成果回饋 #9、#10
```

**原先建議的啟動順序**（已由第 0A 節取代）：#2、#3 先做 → #1 → #6 的 PDU 與 #5 → #4、#7 → 長期項目以小規模合作並行。

## 0A. 修正後的定位與優先序（2026-11-24）

### 0A.1 為什麼要修正

原計畫把 11 個項目並列，讀起來像每一項都需要開發。後續四項分析改變了這個判斷：

1. **儀器自己會擋雜訊。** 設計良好的偏壓源與微波儀器，內部已有隔離、穩壓與濾波（QGP 草案附錄 B.6：Qblox、巴塞爾 LNHR DAC、QPower）。「外面的電源不乾淨，量子位元就會壞」對這類儀器不成立。
2. **AI 資料中心的電源容量綽綽有餘。** 降規格、放遠一點就能用（1,000 位元設計文件第 7A 節）。西班牙 CESGA 已把量子電腦直接裝進一般超算機房。
3. **備援是標準的 UPS 工程。** 壓縮機每台約 12.5 kW，算好電池容量、處理啟動湧浪即可。要決定的是「撐多久」，那是成本問題。
4. **原先假設的規格可能過嚴。** 現役低雜訊偏壓源的隔離電容約 2.5 nF 也能用，不是原計畫假設的個位數 pF。

結論：**室溫側到 1,000 位元以上，需要的是整合工程，不是新技術。** 這個市場的門檻不在電力轉換技術，而在知道客戶真正的需求、有管道接觸儀器廠與系統商、有能力量出差別。

### 0A.2 重新分類

| 類別 | 項目 | 做法 | 投入 |
|---|---|---|---|
| **甲：整合**（現有產品＋參考設計，不需新技術） | #1 分層 UPS 與壓縮機備援、#2 現場勘查、#6 集中供電與接地電流監測、#10 模組化配電、#11 解碼機櫃 | 拿現有的資料中心電源降規格，配上接地規劃與備援設計，寫成參考設計；找一個示範場域 | 低。以方案與文件為主，目的是卡位與累積案例 |
| **乙：漸進式開發**（客戶確認需求後才啟動） | #5 隔離 DC-DC 模組、#9 高通道數供電、#4 壓縮機變頻驅動、#7 線圈電流源 | 從既有平台改良。#5、#9 的客戶是**儀器廠**，不是機房 | 中。每項都要先有一家願意共同開發的客戶 |
| **丙：研發賭注** | #8 4 K 低溫電源轉換 | 與學研合作；半導體與磁性元件在低溫的行為、熱預算、緊鄰量子位元的切換雜訊都是新問題 | 長期、不確定；和甲、乙分開決策 |
| **工具** | #3 QGP 量測能力 | 縮小範圍：先具備隔離電容、共模電流、漏電流三項的量測能力。用途是比較自家模組、供儀器廠篩選供應商，不急著推成標準 | 低 |

各項目的難度重新評估：

| 項目 | 原計畫寫的最大困難 | 修正後的看法 |
|---|---|---|
| #1 參考設計 | 拿不到真實負載數據 | 仍成立，但這是資訊問題，不是技術問題 |
| #4 變頻驅動 | 壓縮機與冷頭的匹配是 OEM 的秘密 | 既有技術的應用；能不能做取決於 OEM 願不願意合作 |
| #5 隔離 DC-DC | 低隔離電容、低漏電流和安規衝突 | 目標規格要先向儀器廠確認；可能不需要做到原先假設的程度 |
| #6 集中供電 | 儀器廠要改電源入口 | 仍成立，是生態系問題。PDU 與接地電流監測可以先做 |
| #7 線圈電流源 | ppm 等級的量測與溫漂 | 技術上確實困難，但市場很小，且已有專業廠商 |
| #8 低溫轉換 | 4 K 的熱預算與磁性元件 | 仍成立，是唯一真正的新領域 |
| #9 高通道供電 | 與儀器廠的分工界線 | 仍成立；儀器廠也可能選擇自己做 |

### 0A.3 修正後的啟動順序

**第 0 步（0–3 個月）：先問，再決定做什麼。** 訪談 2–3 家控制與量測儀器廠、1 家量子系統商，問五件事：

1. 現在儀器內部的前級電源用什麼？為了擋雜訊付出多少代價（電池、線性穩壓、發熱、體積）？
2. 通道數從數十放大到數千時，電源卡在哪裡？
3. 會不會考慮改成直流輸入、由機櫃集中供電？
4. 願不願意提供樣機或驗證平台，一起比較不同的前級電源？
5. 現場花多少時間處理接地迴路？同軸線數放大到數千條後，打算怎麼處理？（背景見 [`1000量子位元系統供電設計.md`](1000量子位元系統供電設計.md) 第 7B 節）

**之後依訪談結果分流：**

| 訪談結果 | 做法 |
|---|---|
| 儀器廠說「內部都處理好了，不需要更好的前級」 | 乙類的 #5、#9 不啟動；只做甲類 |
| 儀器廠說「放大時發熱與電池是問題」 | 啟動 #5（隔離模組），並用 #3 的量測能力與對方的樣機驗證 |
| 系統商說「接地與漏電流在現場造成困擾」 | 甲類加強 #6 的接地電流監測與 #2 的勘查 |
| 沒有人願意談 | 甲類以最低投入維持；一年後重新評估 |

**甲類**不必等訪談，可同時以低投入進行：寫出參考設計、找一個示範場域。
**丙類**的 #8 是獨立的決定：要不要為一個時程不確定的新領域投入長期研發。

### 0A.4 這份修正本身的限制

- 「儀器自己會擋雜訊」來自三份公開資料，不代表所有儀器都如此，也沒有規模放大後的數據。
- 「室溫側不需要新技術」是工程判斷。如果第 0 步的訪談顯示儀器廠確實擋得很辛苦，乙類的重要性會回升。
- 本節沒有市場規模的數字。

# 第一階段：0–1 年，建立案例與規格

## 1. 分層 UPS＋精密空調＋冷卻水蓄冷參考設計（矩陣 A＋B）

### 1.1 要做出什麼
- 一份**可以直接給場地設計單位使用的參考設計**：單線圖、負載表、UPS 與蓄冷容量計算方法、機房佈局規則、驗收量測項目。
- 一個**實際運轉的示範場域**（哪怕只有 20–50 位元規模）。
- 依平台分三個版本：超導（保冷卻鏈）、離子阱（零中斷）、中性原子（保熱穩態）。先做超導。

**設計要點（假設值）：**

| 層 | 負載 | 設計目標 |
|---|---|---|
| 冷卻鏈 | 壓縮機、GHS、冰水機泵與控制 | 市電中斷到發電機接手期間不停機；冷卻中斷容忍約 2 分鐘（LRZ） |
| 控制與量測 | 控制電子、精密直流、時脈 | 雙轉換 UPS、零切換；獨立隔離變壓器、單點接地 |
| 運算 | 解碼、伺服器 | 沿用資料中心規格 |
| 冷卻水 | 蓄冷槽 | 冰水機停機期間，水溫維持在冷凍機廠要求範圍（LRZ 案例 15–25 °C） |

### 1.2 開發步驟
1. **蒐集需求**（1–3 個月）：向 2–3 家冷凍機與量子系統廠取得場地規劃文件（NDA）；訪談已有量子電腦的場域（運轉人員最清楚哪些事件造成停機）。
2. **負載特性量測**（2–4 個月，和 #2 一起做）：壓縮機啟動電流波形與持續時間、再啟動的等待時間與條件、功率因數與諧波、GHS 與冰水機的負載曲線。
3. **設計與模擬**（3–6 個月）：UPS 容量（含啟動電流）、蓄冷槽容量、發電機接手時序、故障情境表（單一壓縮機故障、冰水機故障、UPS 旁路）。
4. **示範場域建置**（6–12 個月）：安裝、量測、故意做斷電演練（在客戶同意下）。
5. **文件化**：把結果寫成參考設計與驗收檢查表。

### 1.3 需要的能力與夥伴
- 關鍵電力系統設計、暖通與冰水系統、現場應用工程。
- 夥伴：示範場域（國內學研單位）、一家冷凍機廠（提供壓縮機與 GHS 的再啟動條件）。

### 1.4 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **拿不到真實數據**：冷凍機廠的規格書在 NDA 之後，而且通常只寫額定值，沒有啟動暫態與再啟動條件 | 以「共同量測」換數據：提出免費幫場域做一次電力品質與啟動暫態量測，報告雙方共有。先從國內學研場域做，門檻最低 |
| **冷卻容忍時間只有一個公開數據點**（LRZ 約 2 分鐘超過 1 K），而且隨機型不同 | 參考設計不要寫死 2 分鐘，改成「容忍時間 T 為輸入參數」的計算方法；在示範場域實測一次受控的短暫停機（由冷凍機廠人員在場） |
| **壓縮機啟動電流讓 UPS 過度放大** | 三個手段依序評估：錯開啟動順序（只要改控制邏輯）→ 軟啟動器 → 變頻驅動（#4）。參考設計先用第一種，把 #4 當成升級選項 |
| **壓縮機停機後不能立刻再啟動**（壓力平衡需要時間，這是一般冷凍壓縮機的特性；氦氣壓縮機的實際條件要向廠商確認） | 設計目標改成「不讓它停」：UPS 直接帶壓縮機撐到發電機接手，而不是停機後再啟動 |
| **場域不願意做斷電演練** | 分級演練：先只切換市電到 UPS（不影響負載），再做發電機帶載測試，最後才是完整演練。每一級都有量測數據可以交付 |
| **案子小，不像資料中心有規模效益** | 把它定位成「取得數據與案例的投資」，不以單案損益評估；交付物要能複製到下一個場域 |

### 1.5 完成的判準
- 示範場域經過至少一次真實或演練的市電中斷，冷凍機溫度沒有離開運轉範圍。
- 參考設計文件被一家冷凍機廠或系統廠接受，引用在他們的場地規劃建議裡。

## 2. 現場勘查服務（矩陣 H）

### 2.1 要做出什麼
一套標準化的**量子機房電磁與電力環境勘查**：固定的量測項目、儀器、流程與報告格式，可以在 2–3 天內完成一個場域。

| 量測項目 | 對照的要求 | 儀器 |
|---|---|---|
| 直流磁場（三軸） | LRZ：每軸 < 100 µT | 三軸磁通門磁力計 |
| 交流磁場頻譜（至 1 kHz 以上） | LRZ：≪ 1 µT | 磁通門或感應線圈＋頻譜分析 |
| 接地電流與地電位差 | 尚無規範（本計畫要建立） | 高靈敏度鉗形電流表、差動探棒、頻譜分析儀 |
| 電力品質（驟降、諧波、不平衡） | 尚無量子專用規範 | 電力品質分析儀，至少記錄一週 |
| 地板振動、噪音 | LRZ：< 400 µm/s、< 80 dBA | 加速規、噪音計 |
| 溫濕度穩定度 | LRZ：電子櫃 12 小時 ±1 °C | 記錄器，至少 25 小時 |
| 射頻環境（含 5–7 GHz） | Wi-Fi 6E／7 落在量子位元頻段 | 頻譜分析儀＋天線 |

### 2.2 開發步驟
1. **買齊儀器、建立流程**（1–2 個月）。
2. **在自家環境練習**（1–2 個月）：先量自己的 UPS、變頻器、變壓器周圍的磁場隨距離的衰減，建立「我們產品的磁場與漏電流數據庫」。這份數據庫本身就是 #1、#10、#11 的輸入。
3. **做 2–3 個外部場域**（3–6 個月）：前幾次免費，換取數據使用權。
4. **建立對照基準**：把量測值和場域自己的量子性能紀錄（校準頻率、位元頻率漂移）放在一起看。

### 2.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **量到了數字，但說不出它對量子位元的影響有多大** | 這正是文獻缺口，短期內誠實地只交付「是否符合廠商現場規格」；長期靠示範場域的時間關聯數據（#1 的 DCIM）累積 |
| **干擾是間歇性的**（電梯、空調啟停、隔壁實驗室），2–3 天量不到 | 留下低成本的長期記錄器（磁場、接地電流、電力品質）至少兩週；這也是 DCIM 感測套件的原型 |
| **接地電流量測沒有標準方法**，探棒擺放會影響結果 | 自己定義方法並寫進 #3 的 QGP；在同一場域重複量測，確認再現性 |
| **客戶不讓外人進機房或看量子性能數據** | 分兩級報告：環境數據歸我們，量子性能關聯分析由客戶自己做，我們提供分析腳本 |
| **服務本身不賺錢** | 定位為產品的前哨：每次勘查都會指出具體的改善項目，對應到我們的產品 |

### 2.4 完成的判準
- 標準報告格式定案；同一場域兩次量測的結果差異在可接受範圍。
- 累積至少 3 個場域的數據。

## 3. 量子等級電源規格（QGP）與量測台

> 量測規範的草案已寫成獨立文件：[`QGP量測規範草案.md`](QGP量測規範草案.md)（量測項目 M1–M10、報告格式、分級提案）。

### 3.1 要做出什麼
- **一份規格文件**：定義一般電源規格書沒有的參數與**量測方法**。
- **一座量測台**：能重複量出這些參數。
- 之後所有電源類項目（#5、#6、#7、#9）都以它作為驗證依據。

| 參數 | 量測方法的方向 | 需要的設備 |
|---|---|---|
| 隔離電容 | 初次級短路後以 LCR 表或阻抗分析儀量測 | 阻抗分析儀 |
| 共模雜訊電流頻譜 | 固定負載與接地配置下，以寬頻電流探棒量輸入與輸出的共模電流 | 電流探棒、頻譜分析儀、LISN、屏蔽箱 |
| 漏電流（接地電流） | 依安規量測網路量工頻值；另外量寬頻頻譜 | 漏電流測試器、差動探棒 |
| 近場磁場 | 固定距離（例如 5、10、30 cm）以近場探棒掃描 | 近場探棒組、掃描平台 |
| 低頻雜訊頻譜（0.1 Hz–100 kHz） | 低雜訊前置放大器＋動態訊號分析儀，電池供電、屏蔽 | 低雜訊放大器、動態訊號分析儀 |
| 長時間漂移 | 恆溫箱內以高位數電表長時間記錄；另量溫度係數 | 8 位半電表、恆溫箱 |
| 切換頻率同步能力 | 外部時脈鎖定範圍、鎖定後的雜散頻率 | 頻譜分析儀、時脈源 |
| 保持時間與驟降耐受 | 可程式交流電源模擬驟降 | 可程式交流電源 |

### 3.2 開發步驟
1. **定草案**（1–2 個月）：只定參數與量測方法，門檻值留白或分成 A／B／C 三級。
2. **建量測台**（2–4 個月）：重點是把量測台自己的雜訊底壓到比待測物低。
3. **量現有產品**（2–3 個月）：我們自己的電源、市售醫療級電源、實驗室線性電源，各量幾台，建立「現況分布」。
4. **找儀器廠對規格**（3–6 個月）：把分布圖給 1–2 家控制電子或直流源廠商看，問「你們需要落在哪裡」。
5. **公開**：以白皮書或 OCP 提案形式發表量測方法。

### 3.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **門檻值沒有依據**：沒有人知道共模電流要多小才「夠」 | 先定量測方法、不定門檻；用分級取代單一門檻。門檻值等驗證平台（示範場域加量子位元實測）有數據後再收斂 |
| **量測台本身的雜訊與接地**：nV/√Hz 與 µA 等級的量測，很容易量到的是環境 | 屏蔽室或屏蔽箱、電池供電的前置放大器、先量短路與開路的雜訊底並附在每份報告裡 |
| **量測結果和配置強烈相關**（線長、接地方式、負載） | 規格裡把測試配置畫死（治具、線長、接地點），犧牲通用性換再現性 |
| **客戶不承認自訂規格** | 找一家儀器廠共同署名；量測方法公開，讓別人可以重做；提到 OCP 量子工作小組 |
| **內部產品線覺得多了一套測試負擔** | QGP 只用在「量子等級」料號，不改既有產品的出貨規格 |

### 3.4 完成的判準
- 同一顆電源在不同日期、不同操作員量測，結果一致。
- 至少一家儀器廠願意用 QGP 的參數來描述他們的需求。

# 第二階段：1–3 年，進入供應鏈

## 4. 壓縮機變頻驅動（矩陣 F）

### 4.1 要做出什麼
給脈衝管氦氣壓縮機（約 12.5 kW 等級）用的變頻驅動，賣給冷凍機廠或壓縮機廠。

| 功能 | 目的 |
|---|---|
| 軟啟動、限制啟動電流 | UPS 與發電機容量小一個級距 |
| 多台壓縮機的啟動排程與群控 | 3–5 台時避免同時啟動 |
| 部分負載降頻運轉 | 系統穩態後降低用電（效果需實測） |
| 主動前端或低諧波整流 | 不把諧波送回同一棟建築的電網 |
| 正弦波輸出濾波、屏蔽、低共模 | 不成為量子機台的磁場與接地雜訊源 |
| 驟降穿越 | 短暫電壓驟降時不跳機 |
| 狀態遙測 | 接進 DCIM，預測性維護 |

### 4.2 開發步驟
1. **外掛驗證**（6–9 個月）：借一台商用壓縮機，用現有的工業變頻器加正弦波濾波器驅動，量測啟動電流、冷卻功率、振動、電磁干擾。這一步不需要 OEM 開放內部設計。
2. **和 OEM 定規格**（3–6 個月）：依驗證結果談共同開發。
3. **專用機開發**（12–18 個月）：依壓縮機特性調整控制、EMC 與機構。
4. **整機驗證**：在真實稀釋冷凍機上跑完整降溫與長時間運轉。

### 4.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **壓縮機與冷頭的匹配是 OEM 的核心技術**。改變壓縮機轉速會改變氦氣流量與壓力比，可能影響冷卻功率與基底溫度 | 第一版只做「軟啟動＋額定頻率運轉」，不碰穩態工作點，這樣不影響低溫性能；降頻節能留到 OEM 願意合作後再做 |
| **壓縮機內部油潤滑與冷卻對最低轉速有限制** | 降頻範圍由 OEM 定義；驅動器只提供能力，不自行決定工作點 |
| **變頻器自己變成干擾源**（PWM 共模電流、磁場），客戶最怕這個 | 正弦波濾波器、屏蔽電纜、主動前端做成標配；用 #2 的方法量「距離 X 公尺的磁場」並寫進規格；用 #3 的量測台量共模電流 |
| **OEM 沒有動機改**：現有定頻方案能用，而且量小 | 從場域端推：#1 的參考設計顯示 UPS 成本因啟動電流而放大，由客戶向 OEM 提需求。同時鎖定正在開發大型多脈衝管系統的廠商，他們最有壓力 |
| **市場量小**（每台冷凍機 1–5 台） | 以既有工業變頻器平台衍生，不開新平台；同一產品也可用於其他閉循環低溫設備（MRI、低溫泵） |
| **認證與服務責任**：壓縮機故障時責任歸屬 | 以 OEM 品牌出貨、OEM 負責系統保固；我們只對驅動器負責 |

### 4.4 完成的判準
- 外掛驗證證明：啟動電流下降幅度、冷卻功率與基底溫度無退化、磁場與共模電流符合現場要求。
- 一家 OEM 簽共同開發或試用協議。

## 5. 量子等級隔離 DC-DC 與 AC-DC 前端（矩陣 D）

### 5.1 要做出什麼
給精密直流源與控制電子的**內部電源模組**，以 OEM 零組件供應儀器廠。

| 產品 | 開發起點的目標（假設值，由 #3 修正） |
|---|---|
| 隔離 DC-DC 模組（數瓦到數十瓦） | 隔離電容個位數 pF；切換頻率固定且可鎖外部時脈；閉磁路、屏蔽的磁性元件；附共模電流頻譜 |
| AC-DC 前端（數十到數百瓦） | 漏電流低於醫療級（100 µA 等級）；低切換雜訊；足夠的保持時間 |

### 5.2 開發步驟
1. **差距分析**（2–3 個月）：用 #3 的量測台量現有的醫療級與通訊級模組，找出離目標多遠。
2. **拓撲與變壓器選型**（3–6 個月）：比較低隔離電容的變壓器結構（分槽繞組、加靜電屏蔽、加大間距）、軟切換拓撲（降低 dV/dt）、固定頻率控制。
3. **原型與迭代**（6–9 個月）：每一版都跑 QGP 全套量測。
4. **客戶端驗證**（6–12 個月）：送樣給 1–2 家儀器廠，裝進他們的儀器，量輸出端雜訊與通道間串擾。
5. **安規與量產**。

### 5.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **低隔離電容和效率、體積衝突**：拉開繞組間距會增加漏感，降低效率 | 選能利用漏感的諧振型拓撲；接受比一般模組大的體積（客戶在意雜訊多過體積） |
| **低漏電流和 EMC 衝突**：少放 Y 電容，傳導干擾測試難過 | 改用軟切換降低雜訊源、加靜電屏蔽、共模扼流圈；若仍不足，定義為「須搭配系統級濾波」的元件級產品 |
| **同步切換頻率和輕載效率衝突**：固定頻率在輕載效率差 | 這個市場不以輕載效率為優先；規格書明寫取捨 |
| **近場磁場沒有既有設計規則** | 用 #3 的近場掃描在原型階段反覆量；磁性元件用閉磁路、必要時加屏蔽罩 |
| **客戶驗證週期長**：儀器廠要裝機量測，一輪數個月 | 提供評估板與 QGP 報告，讓客戶先在桌上驗證；同時支援 2 家以上，避免卡在單一客戶 |
| **量小、料號多** | 做成少數幾個電壓可調的平台料號；定價反映小量 |
| **儀器廠習慣自己做電源，不信任外購** | 先切入他們最頭痛的一顆（通常是類比域的隔離電源）；用 QGP 數據證明比自製好 |

### 5.4 完成的判準
- 原型在 QGP 量測上明顯優於現有醫療級模組（至少隔離電容與共模電流）。
- 一家儀器廠完成裝機量測並回報輸出端雜訊或串擾的改善。

## 6. 機櫃集中供電＋接地電流監測 PDU（矩陣 A／D）

### 6.1 要做出什麼
兩個可以分開推的產品：

**(a) 接地電流監測 PDU**（先做，不需要儀器廠配合）
- 每個插座量測負載電流、剩餘電流（漏電流）；量測保護地線總電流。
- 資料接進 DCIM，可以和校準事件做時間對照。

**(b) 機櫃集中供電（power shelf）**
- 一個機櫃只有 1–2 個交流入口；內部以乾淨、隔離的直流母線供電給各模組。
- 交流入口從數百個降到十幾個，漏電流路徑大幅減少。

### 6.2 開發步驟
- **PDU**（9–12 個月）：以既有智慧 PDU 平台加上高解析度的剩餘電流感測（mA 以下）；韌體與 DCIM 整合；在示範場域裝第一批。
- **集中供電**（18–24 個月）：
  1. 和 1–2 家儀器廠定直流母線規格（電壓、連接器、接地方式）；
  2. 做電源架與背板原型；
  3. 儀器廠改一款模組化機箱來配合；
  4. 整櫃量測：接地電流、通道間串擾、輸出雜訊。

### 6.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **PDU：要量 mA 以下的剩餘電流，但負載電流是數安培**，差動量測的精度與溫漂是挑戰 | 用磁通門式剩餘電流感測器（電動車充電樁已大量使用同類技術）；出廠逐一校正 |
| **PDU 自己的電源與通訊變成雜訊源** | PDU 的內部電源也要過 QGP；通訊用光纖或隔離介面 |
| **集中供電：需要儀器廠改設計**，他們各有各的機箱標準 | 先從已經是模組化機箱的廠商切入（例如背板式的控制系統）；提出開放的直流母線規格，提到 OCP |
| **共用母線造成模組間串擾** | 每個模組入口仍保留隔離 DC-DC（#5）；母線只負責「乾淨的粗電」 |
| **單點故障**：一個電源架壞掉，整櫃都停 | N+1 電源模組、熱插拔；雙母線選配 |
| **直流母線電壓的選擇沒有共識**（48 V、較低的類比電壓、或多軌） | 第一版用 48 V 加模組內隔離轉換，和資料中心生態相容；類比多軌留到 #9 |
| **安規與責任界線**：儀器沒有自己的交流入口後，認證方式改變 | 及早找認證單位討論以系統方式認證；電源架單獨取證 |

### 6.4 完成的判準
- PDU：在示範場域抓到至少一次「接地電流變化 ↔ 量測異常」的時間對應。
- 集中供電：同一櫃儀器，改用集中供電後保護地線電流明顯下降，輸出雜訊或串擾不變差。

## 7. 精密線圈電流源（矩陣 G，離子阱與中性原子）

### 7.1 要做出什麼

| 型號方向 | 規格起點（假設值） | 用途 |
|---|---|---|
| 穩定型 | 數安培到數十安培；雜訊與漂移 ppm 等級；內建 50/60 Hz 及諧波的前饋補償輸入 | 離子阱與中性原子的量化軸磁場 |
| 快切型 | 數十到上百安培；毫秒級關斷；關斷後殘餘電流極低 | 中性原子 MOT 線圈 |

依據：線圈電流雜訊通常主導磁場雜訊；60 A 線圈做電流回授加 50 Hz 前饋後，同調時間提升約 25 倍（主報告 §8.3）。

### 7.2 開發步驟
1. **穩定型原型**（6–9 個月）：線性輸出級＋磁通門式電流感測器回授＋低溫漂基準；先做 20 A 等級。
2. **實驗室驗證**（6 個月）：交給國內的原子物理實驗室，量同調時間的變化。
3. **前饋功能**：加入市電相位鎖定與可程式諧波補償波形。
4. **快切型**：以開關元件加能量回收或吸收電路，處理線圈電感的能量。
5. **產品化**：多通道、遠端控制、和實驗控制系統整合。

### 7.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **ppm 等級怎麼量**：量測設備本身要比待測物好 | 用計量等級的電流感測器與 8 位半電表；最終以「原子自己」當感測器，由合作實驗室量同調時間 |
| **溫度漂移**：分流電阻與基準的溫度係數決定長期穩定度 | 低溫漂電阻或磁通門式感測器、關鍵元件恆溫、水冷散熱板 |
| **線性輸出級的效率差、發熱大** | 交換式預穩壓＋線性後級；預穩壓的切換雜訊要過 QGP |
| **電感負載的穩定性**：不同線圈的電感差很多 | 可調的補償網路或數位控制；出廠附調校流程 |
| **快切與低雜訊互相衝突** | 做成兩個模式或兩個產品：裝載時用快切級，計算時切到低雜訊級 |
| **環境磁場不是電流源能解決的**（電流再穩，外界磁場仍在變） | 提供外部感測器輸入做前饋；和 #2 的磁場量測、建築級諧波治理一起提案 |
| **市場小、客戶習慣自製** | 鎖定正在產品化的系統廠（他們需要可量產、有保固的零件）；以實驗室的同調時間數據當背書 |

### 7.4 完成的判準
- 合作實驗室量到同調時間或磁場穩定度的改善，並願意共同發表。
- 一家離子阱或中性原子系統廠索樣。

# 第三階段：3–7 年，下一代架構

## 8. 4 K 低溫電源轉換（矩陣 I）

### 8.1 要做出什麼
在冷凍機 4 K 層工作的 DC-DC 轉換器：以較高電壓、低電流把電送進冷凍機，在 4 K 降壓後供電給低溫控制晶片。

依據：低溫 CMOS 控制器每位元 1–2 mW，10,000 位元就是 10–20 W；已有 4 K GaN 轉換器在 7.6 W 下達 91.6% 效率的展示（廠商文章，正式論文待確認），以及 4 K cryo-CMOS 降壓轉換器 63% 的結果（主報告第 5 章）。

### 8.2 開發步驟
1. **元件低溫特性量測**（第 1–2 年）：和學研單位合作，量 GaN 元件、電容、磁性材料在 4 K 的特性。
2. **小功率原型**（第 2–3 年）：在測試用低溫恆溫器中展示。
3. **和低溫 CMOS 團隊對接**（第 3–5 年）：實際供電給控制晶片，量對量子位元的影響。
4. **模組化**（第 5 年以後）。

### 8.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **損耗直接吃 4 K 的冷卻預算**：效率 90% 時，供 10 W 就要多散 1.1 W；而 4 K 每支脈衝管只有約 2 W | 效率目標要高於室溫產品；或把轉換器放在冷卻功率大得多的 50 K 層，再用超導或低阻線送到 4 K（需權衡線損與熱導） |
| **磁性元件在低溫的行為改變**：多數鐵氧體的磁導率在低溫大幅下降 | 評估空心電感、低溫適用的磁性材料，或改用開關電容拓撲減少磁性元件 |
| **電容在低溫容值下降**（高介電常數陶瓷特別明顯） | 選低溫特性穩定的介質，接受較大的體積 |
| **切換雜訊離量子晶片很近** | 屏蔽、遠離晶片的擺放、切換頻率避開量子位元與讀取頻段並鎖定系統時脈 |
| **封裝與可靠度**：熱循環造成的應力、焊點 | 借鏡太空與低溫儀器的封裝經驗；做熱循環測試 |
| **測試成本高**：每次降溫都要時間 | 自建或合作使用小型 4 K 恆溫器（不需要稀釋冷凍機） |
| **市場時程不確定**：低溫 CMOS 何時成為主流沒有定論 | 維持小團隊與學研合作，以論文與專利累積位置；設定檢查點（例如主要廠商公布低溫控制器量產計畫） |

## 9. 高通道數直流供電（矩陣 I）

### 9.1 要做出什麼
數千到上萬路精密直流偏壓背後的**電源分配架構**：多軌、低雜訊、彼此隔離的類比電源，以高密度方式送到每個 DAC 通道群。它是 #6 集中供電的延伸，也可能延伸到低溫端（與 #8 結合）。

### 9.2 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **和儀器廠的分工界線**：DAC 與基準是他們的核心，電源架構和電路板設計綁得很緊 | 以共同設計（JDM）方式合作；我們負責到「每個通道群的類比電源軌」為止 |
| **通道間經由共用電源耦合** | 分群隔離、每群獨立穩壓；以 QGP 量串擾 |
| **密度與散熱**：每通道功耗雖小，數千通道加起來是 kW 等級，而且要恆溫 | 背板液冷或恆溫風道；把熱管理和電源一起設計 |
| **架構可能被取代**：若控制電子搬進低溫，室溫的高通道供電需求會縮小 | 架構設計時保留把電源送進冷凍機的介面；和 #8 共用技術 |

### 9.3 開發方式
不單獨立項，作為 #6 的第二代：#6 的第一代驗證 48 V 加模組內轉換，第二代再處理多軌與高密度。

## 10. 模組化量子資料中心配電（矩陣 A）

### 10.1 要做出什麼
把 #1 的參考設計做成**可複製的模組**：每個「量子單元」（一台冷凍機加上它的壓縮機、電子櫃、解碼櫃）有標準化的電力與冷卻介面，可以並排擴充到 MW 等級。

依據：IBM 的模組化低溫系統每模組約 30 kW，Starling 約 12 個模組（主報告與 1,000 位元文件第 7 章）。

### 10.2 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **大電流母線的磁場**：1,000 A 單根母線在 1 m 處約 200 µT；成對配線在 3 m 處仍約 2 µT | 提高配電電壓以降低電流；母線成對、緊密並行；配電走廊與量子機台保持距離；用 #2 的實測定出距離規則 |
| **800 VDC 是否適用**：直流母線產生靜磁場，而超導晶片降溫時對殘留磁場敏感 | 先做評估而不是預設答案：比較交流與直流方案在機台位置的磁場；直流方案搭配緊密的正負極並行與局部屏蔽 |
| **數十台壓縮機的群控**：啟動排程、N+1、維護時的切換 | 延伸 #4 的群控功能 |
| **不同平台的需求不同**（§17 的三種 UPS 邏輯） | 模組介面統一，UPS 分層依平台選配 |
| **市場時程**：MW 級量子資料中心在 2029 年以後才可能出現，而且客戶極少 | 不獨立開發產品；持續把 #1 每個案子的設計模組化，等需求出現時已有可複製的設計 |
| **業主通常自己主導設計** | 以零組件與子系統供應者的角色參與；參與 OCP 的規格制定 |

## 11. 解碼機櫃供電與液冷（矩陣 E）

### 11.1 要做出什麼
量子錯誤更正的即時解碼需要 FPGA／GPU 機櫃。這部分的供電與散熱**規格和 AI 機櫃相同**，我們已有產品；要補的是「緊鄰量子機台」這個條件。

依據：超導系統的回饋預算是個位數到數十微秒，解碼器必須在量子機台旁邊；已有中性原子機台與上千張 GPU 並置的案例。

### 11.2 開發步驟
1. 用 #2 的方法量現有 AI 機櫃電源與液冷設備的磁場、漏電流、振動。
2. 依結果定出「與量子機台的最小距離」或需要的改良（屏蔽、濾波）。
3. 和 #1 的參考設計整合成一個方案。

### 11.3 困難與解法

| 困難 | 可能的解法 |
|---|---|
| **大功率電源、泵與風扇就在量子機台旁**：磁場、振動、噪音 | 量測後定距離；機櫃內的大電流路徑成對配線；液冷泵浦遠端放置 |
| **低延遲的要求限制了距離**：不能為了避干擾把機櫃搬很遠 | 個位數公尺的距離對微秒級延遲影響很小（訊號每公尺約 5 ns）；真正的延遲在運算與介面，所以距離有空間 |
| **負載快速變動造成電源暫態**，經共用配電影響量子側 | 解碼機櫃走獨立的匯流排與 UPS 分層（#1 的「運算」層） |
| **需求量不明**：解碼要多少運算，取決於錯誤更正碼與硬體進展 | 不開新產品，只做驗證與應用指南；這項可以提前到第一階段做，投入很小 |

## 12. 跨項目的共同困難

| 共同困難 | 說明 | 可能的解法 |
|---|---|---|
| **市場小而且時程不確定** | 目前全球量子電腦的裝機量很少，單一項目很難用營收回收 | 每個項目都從既有平台衍生；第一階段的三項（#1–#3）以「取得數據與位置」為目標；設定明確的檢查點再決定第二階段投入 |
| **需求藏在 NDA 後面** | 真正的規格在冷凍機廠與系統廠手上 | 以量測服務與共同開發換取資訊；優先經營 2–3 個深度夥伴，而不是廣撒 |
| **缺少「電源 → 量子位元」的驗證能力** | 沒有這個，產品的價值無法證明 | 和有量子位元的實驗室建立長期合作；這是所有項目共用的基礎建設，應該最早啟動 |
| **客戶在意的指標和電源產業的指標不同** | 效率、功率密度、成本不是第一優先；雜訊、漏電流、磁場才是 | 用 QGP 把客戶的語言變成內部可執行的規格 |
| **跨領域人才** | 需要同時懂電力電子、精密類比量測與量子硬體的人 | 小型專責團隊，加上駐點在合作實驗室的工程師 |
| **技術路線可能改變** | 低溫 CMOS、光纖連結、不同量子位元平台都會改變供電需求 | 優先做對各路線都成立的項目（#1、#2、#3、#6、#11）；路線相依的項目（#8、#9）維持小規模 |
