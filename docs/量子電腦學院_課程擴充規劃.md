## 1. 參考格式：父子科技學院沿用哪些規則

從 `academy/curriculum/catalog.json`、`lessons/L046/brief.md` 與 `episodes/academy/l046-battery-explainer/` 歸納出的格式，本課表全部照用：

1. **模組結構**：每模組 16 堂；每 3 個模組一個階段（父子學院是每年 3 模組）。
2. **每堂 2 小時、7 段固定流程**

   | 分鐘 | 段落 |
   |---|---|
   | 00–10 | 任務開場（看課前短片、提出今天的問題） |
   | 10–25 | 概念示範（3D 場景操作＋簡報） |
   | 25–65 | 父子共同實作（動手任務） |
   | 65–75 | 休息／走動／聊天 |
   | 75–105 | 孩子獨立改造（改一個參數、加一個條件、自己出題） |
   | 105–115 | 角色互換：孩子教爸爸操作與原理 |
   | 115–120 | 錄音總結、作品命名、版本存檔 |

3. **每堂必填欄位**：課程主題、學習目標、動手任務、**好玩機制**（沿用父子學院的詞彙：闖關、偵探辦案、Boss 戰、盲測、故障注入、工程答辯…）、**當堂作品**、生活技能支線、家長課前準備、課後延伸、**驗收標準**、**錄音提問**（4 題：在解決什麼？我怎麼做？哪裡容易錯？生活中哪裡用到？）、難度 1–5、建議 YouTube 標題。
4. **每堂交付包**（之後製作時才做，本次不做）：
   - 課前教學影片（L046 實測 5.5 分鐘，含 60 秒片頭）＋ 字幕、章節、YouTube 說明
   - 原生可編輯 PPTX（L046 為 12 頁）
   - `classroom.zip` 教材：示範、列印包 PDF、紀錄表 CSV、任務說明
   - 旁白稿、來源清單、事實查核、QC 紀錄
5. **製作紀律**：只做使用者指定的課次；每堂完成後驗收、記錄、commit 再做下一堂；YouTube 由使用者自己上傳。

### 需要調整的地方

父子學院的對象是親子、從零基礎開始；本 repo 現有內容是**給同仁的工程級技術分享**。所以課表分三個階段，難度逐步拉高：

| 階段 | 模組 | 難度 | 對象與上課方式 |
|---|---|---|---|
| 一、量子直覺 | QM01 | 1–2 | 親子共學，不用公式，只用 3D 場景和遊戲 |
| 二、硬體怎麼做 | QM02–QM03 | 2–4 | 高中以上；爸爸主講、孩子操作場景並提問 |
| 三、操作、平台與未來 | QM04–QM06 | 3–5 | 高中理組／大學／工程同仁；現有技術分享的主力內容 |

### 2.4 現有內容的缺口

1. **沒有入門層**：最淺的內容（C 的 p5–10）仍假設聽眾懂複數與矩陣，親子無法直接用。
2. **沒有動手作業**：都是「講＋看」，沒有作品、驗收或列印教材。
3. **平台不完整**：只有超導、離子阱、中性原子；光子、半導體自旋、拓樸、NV 色心都沒有。
4. **錯誤更正只有一頁表面碼**；沒有重複碼、邏輯閘、魔術態。
5. **應用面很薄**：C 的 p44–45 只有一張應用地圖；VQE/QAOA、量子化學、量子密碼、後量子密碼、量子感測都沒有。
6. **沒有可寫程式的環境**：只有 Qiskit 截圖（C p27），沒有可直接執行的範例或免安裝線路編輯器。
