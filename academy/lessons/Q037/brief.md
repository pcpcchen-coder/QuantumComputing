# Q037 單發判別與保真度

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 4／5｜好玩機制：盲測

**學習目標**：用閾值判別單發讀取，計算保真度，認識 T₁ 造成的錯誤

## 120 分鐘流程

```
00–10 任務開場：單發判別與保真度
10–25 概念示範：用閾值判別單發讀取，計算保真度，認識 T₁ 造成的錯誤
25–65 父子共同實作：在場景移動閾值，記錄兩種錯誤率並算保真度
65–75 休息／走動／聊天
75–105 孩子獨立改造：開啟 T₁ 效應與放大器，比較保真度變化
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「保真度計算表」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：讀取時間拉長會改善分離度，但 T₁ 衰減也會增加）。

## 錄音提問

請孩子回答：1. 單發判別與保真度在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
