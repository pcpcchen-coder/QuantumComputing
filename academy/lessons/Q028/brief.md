# Q028 量子位元家族圖鑑

QM02 超導量子位元：從超導到 transmon｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：解鎖成就（圖鑑卡）

**學習目標**：比較 transmon、fluxonium、電荷與相位量子位元的結構與優缺點

## 120 分鐘流程

```
00–10 任務開場：量子位元家族圖鑑
10–25 概念示範：比較 transmon、fluxonium、電荷與相位量子位元的結構與優缺點
25–65 父子共同實作：為四種量子位元各做一張圖鑑卡：結構、頻率、優點、弱點
65–75 休息／走動／聊天
75–105 孩子獨立改造：自己設計一張「理想量子位元」卡，說明它要跟誰借優點
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
