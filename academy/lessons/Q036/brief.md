# Q036 IQ 平面：把微波變成一個點

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 4／5｜好玩機制：臨摹挑戰

**學習目標**：知道外差解調把微波訊號變成 I、Q 兩個數字

## 120 分鐘流程

```
00–10 任務開場：IQ 平面：把微波變成一個點
10–25 概念示範：知道外差解調把微波訊號變成 I、Q 兩個數字
25–65 父子共同實作：用旋轉的手電筒與牆上投影示範相位；在場景手繪 IQ 圖
65–75 休息／走動／聊天
75–105 孩子獨立改造：解釋為什麼兩團點的距離比單看振幅更有用
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
