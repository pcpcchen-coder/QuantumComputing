# Q083 重複碼：最簡單的錯誤更正

QM06 錯誤更正、應用與未來｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：偵探辦案

**學習目標**：理解 3 位元翻轉碼、症狀量測與多數決解碼

## 120 分鐘流程

```
00–10 任務開場：重複碼：最簡單的錯誤更正
10–25 概念示範：理解 3 位元翻轉碼、症狀量測與多數決解碼
25–65 父子共同實作：用三枚硬幣當一個邏輯位元，爸爸偷翻一枚，孩子只看「兩兩是否相同」找出來
65–75 休息／走動／聊天
75–105 孩子獨立改造：如果同時翻兩枚會怎樣？算出邏輯錯誤率
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

症狀解碼表

## 家長課前準備

硬幣；新場景

## 驗收

完成「症狀解碼表」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：量子不能複製（不可複製定理）；症狀量測只比較，不讀出資料本身）。

## 錄音提問

請孩子回答：1. 重複碼：最簡單的錯誤更正在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？

## 素材

- 沒有可直接沿用的現有頁面或場景。
- 需新增：◆ 新簡報：重複碼
- 需新增：★ 重複碼場景

生活技能支線：用冗餘保護重要資訊。課後延伸：15–30 分鐘自由改造；寫三句學習日誌：我做了什麼、哪裡卡住、下次想加什麼。

課前教學影片與兩小時課堂分開管理；影片長度依實測旁白，不等於 120 分鐘。
