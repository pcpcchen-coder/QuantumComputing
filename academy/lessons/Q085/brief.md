# Q085 低於門檻

QM06 錯誤更正、應用與未來｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：效能競賽

**學習目標**：知道物理錯誤率低於門檻時，碼距越大邏輯錯誤越少

## 120 分鐘流程

```
00–10 任務開場：低於門檻
10–25 概念示範：知道物理錯誤率低於門檻時，碼距越大邏輯錯誤越少
25–65 父子共同實作：用場景的蒙地卡羅跑不同碼距與錯誤率，畫門檻曲線
65–75 休息／走動／聊天
75–105 孩子獨立改造：解讀一份公開的「低於門檻」實驗結果圖
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「門檻曲線」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：高於門檻時，碼距越大反而越糟）。

## 錄音提問

請孩子回答：1. 低於門檻在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
