# Q088 量子化學與材料

QM06 錯誤更正、應用與未來｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：科學實驗

**學習目標**：知道分子模擬為什麼適合量子電腦，以及 H₂ 能量曲線怎麼算

## 120 分鐘流程

```
00–10 任務開場：量子化學與材料
10–25 概念示範：知道分子模擬為什麼適合量子電腦，以及 H₂ 能量曲線怎麼算
25–65 父子共同實作：用模擬器算 H₂ 在不同鍵長的能量，畫出曲線
65–75 休息／走動／聊天
75–105 孩子獨立改造：查一個真實的材料或藥物題目，評估它要多大的量子電腦
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「H₂ 能量曲線」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：小分子古典電腦就算得很準；量子優勢要在大型強關聯系統才會出現）。

## 錄音提問

請孩子回答：1. 量子化學與材料在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
