# Q024 JJ 是非線性電感

QM02 超導量子位元：從超導到 transmon｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：科學實驗（單擺大小振幅）

**學習目標**：知道 JJ 的電感會隨電流改變，這個非線性是做出量子位元的關鍵

## 120 分鐘流程

```

75–105 孩子獨立改造：用 transmon-3d 場景找出能階間距開始變小的地方
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
