# Q131 冷卻鏈不斷電與壓縮機驅動

QM09 量子電腦的供電與機房工程｜第四階段 深化與產業｜難度 4／5｜好玩機制：真實任務

**學習目標**：認識超導平台最優先的切入點：冷卻鏈不斷電整套方案、壓縮機變頻驅動與安靜電源

## 120 分鐘流程

```
00–10 任務開場：冷卻鏈不斷電與壓縮機驅動
10–25 概念示範：認識超導平台最優先的切入點：冷卻鏈不斷電整套方案、壓縮機變頻驅動與安靜電源
25–65 父子共同實作：畫出冷卻鏈的供電架構，標出 UPS、精密空調、冷卻水蓄冷的位置
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較壓縮機直接接市電與加變頻驅動的差別
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

冷卻鏈供電架構圖

## 家長課前準備

供電簡報 p28–29；產品開發計畫第 1、4 項

## 驗收

完成「冷卻鏈供電架構圖」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：壓縮機停太久冷凍機會回溫；備援時間要依回溫曲線決定）。

## 錄音提問

請孩子回答：1. 冷卻鏈不斷電與壓縮機驅動在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
