# Q078 半導體自旋量子位元

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：偵探辦案

**學習目標**：認識量子點、電子自旋與 CMOS 製程的關係

## 120 分鐘流程

```
00–10 任務開場：半導體自旋量子位元
10–25 概念示範：認識量子點、電子自旋與 CMOS 製程的關係
25–65 父子共同實作：用場景把電子一顆顆放進量子點，觀察自旋操作
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較自旋量子位元與 transmon 的尺寸與工作溫度
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
