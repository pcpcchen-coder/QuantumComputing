# Q117 範例 4：GHZ——CNOT 一路串下去

QM08 動手寫量子電路：從八個範例到自己的線路｜第四階段 深化與產業｜難度 3／5｜好玩機制：闖關

**學習目標**：把糾纏擴展到三、四顆位元，看每一步多綁一顆

## 120 分鐘流程

```
00–10 任務開場：範例 4：GHZ——CNOT 一路串下去
10–25 概念示範：把糾纏擴展到三、四顆位元，看每一步多綁一顆
25–65 父子共同實作：做 3 顆與 4 顆 GHZ，記錄量測結果只有全 0 與全 1
65–75 休息／走動／聊天
75–105 孩子獨立改造：故意少接一條 CNOT，預測結果再驗證
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
