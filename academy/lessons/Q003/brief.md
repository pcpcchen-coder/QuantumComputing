# Q003 一看就變：測量與 shots

QM01 量子直覺：不用公式看懂量子｜第一階段 量子直覺｜難度 1／5｜好玩機制：科學實驗

**學習目標**：理解測量只會得到 0 或 1、測量後狀態改變，以及為什麼要跑很多次

## 120 分鐘流程

```
00–10 任務開場：一看就變：測量與 shots
10–25 概念示範：理解測量只會得到 0 或 1、測量後狀態改變，以及為什麼要跑很多次
25–65 父子共同實作：擲硬幣 100 次和場景跑 1000 shots，比較統計結果與預測機率
65–75 休息／走動／聊天
75–105 孩子獨立改造：改變角度做三組實驗，畫出「角度 vs 0 的比例」
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

shots 統計表與長條圖

## 家長課前準備

硬幣、計數表；operation.html#qubit 的連續測量模式

## 驗收

完成「shots 統計表與長條圖」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：一次測量得到 1，不代表原本「就是 1」；要看很多次的比例）。

## 錄音提問

請孩子回答：1. 一看就變：測量與 shots在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
