# Q077 光子量子電腦

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：闖關

**學習目標**：認識分光鏡、相位器、單光子偵測，以及玻色取樣與測量式量子計算

## 120 分鐘流程

```
00–10 任務開場：光子量子電腦
10–25 概念示範：認識分光鏡、相位器、單光子偵測，以及玻色取樣與測量式量子計算
25–65 父子共同實作：用鏡子與分光片（或場景）組一個兩路干涉儀，預測輸出
65–75 休息／走動／聊天
75–105 孩子獨立改造：加一個光子，觀察 Hong–Ou–Mandel 現象
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

光路設計圖

## 家長課前準備

新場景；鏡子、透明壓克力片（安全光源）

## 驗收

完成「光路設計圖」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：光子不怕熱，但很難讓兩個光子直接作用；損耗是主要挑戰）。

## 錄音提問

請孩子回答：1. 光子量子電腦在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？

## 素材

- 沒有可直接沿用的現有頁面或場景。
- 需新增：◆ 新簡報：光子平台
- 需新增：★ 光子干涉儀／玻色取樣場景

生活技能支線：用光傳遞資訊。課後延伸：15–30 分鐘自由改造；寫三句學習日誌：我做了什麼、哪裡卡住、下次想加什麼。

課前教學影片與兩小時課堂分開管理；影片長度依實測旁白，不等於 120 分鐘。
