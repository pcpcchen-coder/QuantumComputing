# Q064 模組專題：在模擬器跑我的線路

QM04 操作量子電腦與演算法｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：Release 任務

**學習目標**：依操作檢查表完成一次「定義問題 → 線路 → 轉譯 → 執行 → 解讀」

## 120 分鐘流程

```
00–10 任務開場：模組專題：在模擬器跑我的線路
10–25 概念示範：依操作檢查表完成一次「定義問題 → 線路 → 轉譯 → 執行 → 解讀」
25–65 父子共同實作：挑一個學過的演算法，加入雜訊模型跑完整流程並寫實驗報告
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較兩種轉譯最佳化等級，說明結果差異
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

模擬器實驗報告

## 家長課前準備

本機模擬器；操作檢查表

## 驗收

完成「模擬器實驗報告」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：模擬器的雜訊模型是假設；要寫清楚用了哪些參數）。

## 錄音提問

請孩子回答：1. 模組專題：在模擬器跑我的線路在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
