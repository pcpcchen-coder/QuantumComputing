# Q122 Grover 三位元：轉太多會轉過頭

QM08 動手寫量子電路：從八個範例到自己的線路｜第四階段 深化與產業｜難度 3／5｜好玩機制：效能競賽

**學習目標**：用 3 顆位元跑 1–3 輪，看成功機率先升後降，理解 √N

## 120 分鐘流程

```
00–10 任務開場：Grover 三位元：轉太多會轉過頭
10–25 概念示範：用 3 顆位元跑 1–3 輪，看成功機率先升後降，理解 √N
25–65 父子共同實作：記錄 1、2、3 輪的成功機率並畫圖
65–75 休息／走動／聊天
75–105 孩子獨立改造：算出 N = 1024 時大約要幾輪
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
