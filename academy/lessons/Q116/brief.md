# Q116 範例 3：Bell 態——四種糾纏

QM08 動手寫量子電路：從八個範例到自己的線路｜第四階段 深化與產業｜難度 3／5｜好玩機制：解鎖成就（四個 Bell 態）

**學習目標**：知道 CNOT 把機率搬到 |11⟩，四個 Bell 態只差開頭的 X 與 Z

## 120 分鐘流程

```
00–10 任務開場：範例 3：Bell 態——四種糾纏
10–25 概念示範：知道 CNOT 把機率搬到 |11⟩，四個 Bell 態只差開頭的 X 與 Z
25–65 父子共同實作：逐步做 Φ⁺、Φ⁻、Ψ⁺、Ψ⁻，各量測 1000 次
65–75 休息／走動／聊天
75–105 孩子獨立改造：看「單看某一顆位元」的 Bloch 球，說明為什麼向量變短
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
