# Q052 微波脈衝：面積與相位

QM04 操作量子電腦與演算法｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：闖關

**學習目標**：知道脈衝面積決定旋轉角度、相位決定旋轉軸

## 120 分鐘流程

```
00–10 任務開場：微波脈衝：面積與相位
10–25 概念示範：知道脈衝面積決定旋轉角度、相位決定旋轉軸
25–65 父子共同實作：在場景設計 π、π/2 脈衝，並用相位做出繞 Y 軸的旋轉
65–75 休息／走動／聊天
75–105 孩子獨立改造：加入失諧，觀察旋轉軸怎麼傾斜
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「脈衝設計紀錄」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：面積相同、形狀不同的脈衝，頻譜與洩漏不同）。

## 錄音提問

請孩子回答：1. 微波脈衝：面積與相位在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
