# Q126 加入雜訊：八個範例在真實世界會怎樣

QM08 動手寫量子電路：從八個範例到自己的線路｜第四階段 深化與產業｜難度 4／5｜好玩機制：故障注入

**學習目標**：在本機模擬器加入雜訊模型，觀察 Bell、GHZ、Grover 的結果如何變差

## 120 分鐘流程

```
00–10 任務開場：加入雜訊：八個範例在真實世界會怎樣
10–25 概念示範：在本機模擬器加入雜訊模型，觀察 Bell、GHZ、Grover 的結果如何變差
25–65 父子共同實作：用同一條線路跑理想與有雜訊兩種模擬，比較直方圖
65–75 休息／走動／聊天
75–105 孩子獨立改造：把雜訊加倍，找出哪個範例最先看不出答案
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

理想 vs 雜訊比較圖

## 家長課前準備

本機模擬器（qiskit-aer 雜訊模型）

## 驗收

完成「理想 vs 雜訊比較圖」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：模擬器的雜訊模型是假設，參數要寫清楚）。

## 錄音提問

請孩子回答：1. 加入雜訊：八個範例在真實世界會怎樣在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
