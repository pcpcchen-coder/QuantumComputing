# Q086 邏輯閘與魔術態

QM06 錯誤更正、應用與未來｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：工程答辯

**學習目標**：知道 Clifford 閘容易做、T 閘需要魔術態，以及蒸餾的資源成本

## 120 分鐘流程

```
00–10 任務開場：邏輯閘與魔術態
10–25 概念示範：知道 Clifford 閘容易做、T 閘需要魔術態，以及蒸餾的資源成本
25–65 父子共同實作：估算一個演算法需要的 T 閘數與魔術態工廠數
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較兩種資源估算結果，找出主要成本
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

資源估算表

## 家長課前準備

新場景；資源估算表

## 驗收

完成「資源估算表」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：容錯時代的成本主要在 T 閘，不在 Clifford 閘）。

## 錄音提問

請孩子回答：1. 邏輯閘與魔術態在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
