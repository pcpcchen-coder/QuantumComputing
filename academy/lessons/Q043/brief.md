# Q043 稀釋冷凍原理

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 4／5｜好玩機制：闖關（Q̇ 計算）

**學習目標**：知道 ³He 溶入 ⁴He 時吸熱，冷卻功率與 T² 成正比

## 120 分鐘流程

```
00–10 任務開場：稀釋冷凍原理
10–25 概念示範：知道 ³He 溶入 ⁴He 時吸熱，冷卻功率與 T² 成正比
25–65 父子共同實作：用場景的 Q̇ = 84ṅT² 計算不同溫度下的冷卻功率
65–75 休息／走動／聊天
75–105 孩子獨立改造：算出溫度減半時，可承受的熱負載剩多少
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「冷卻功率計算」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：越冷越難冷：冷卻功率隨溫度平方下降）。

請孩子回答：1. 稀釋冷凍原理在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
