# Q046 控制電子與時脈

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：角色扮演（人肉控制鏈）

**學習目標**：理解上傳 → 觸發 → 驅動 → 讀取 → 判別 → 回饋的控制鏈與 10 MHz 參考時脈

## 120 分鐘流程

```
00–10 任務開場：控制電子與時脈
10–25 概念示範：理解上傳 → 觸發 → 驅動 → 讀取 → 判別 → 回饋的控制鏈與 10 MHz 參考時脈
25–65 父子共同實作：全家扮演控制鏈各站，用拍手當時脈傳遞一個 shot
65–75 休息／走動／聊天
75–105 孩子獨立改造：故意讓一站慢半拍，觀察結果怎麼出錯
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
