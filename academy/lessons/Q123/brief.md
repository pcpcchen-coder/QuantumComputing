# Q123 古典 vs 量子：要查幾次？

## 120 分鐘流程

```
00–10 任務開場：古典 vs 量子：要查幾次？
10–25 概念示範：整理 Deutsch、BV、Grover 的古典與量子查詢次數，分辨加速大小
25–65 父子共同實作：做一張查詢次數比較表並用動畫驗證其中三格
65–75 休息／走動／聊天
75–105 孩子獨立改造：找一個量子沒有優勢的問題，說明原因
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
