# Q054 任意旋轉 = 三個旋轉

QM04 操作量子電腦與演算法｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：程式對決

**學習目標**：理解 ZYZ 分解：任何單位元操作都能拆成三個旋轉

## 120 分鐘流程

```
00–10 任務開場：任意旋轉 = 三個旋轉
10–25 概念示範：理解 ZYZ 分解：任何單位元操作都能拆成三個旋轉
25–65 父子共同實作：用場景把 H、S、T 分解成旋轉序列並驗證
65–75 休息／走動／聊天
75–105 孩子獨立改造：給爸爸一個指定旋轉，比賽誰先拆出來
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

請孩子回答：1. 任意旋轉 = 三個旋轉在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
