# Q033 讀取要快、準、不破壞

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：冒險任務

**學習目標**：說出讀取量子位元的三個條件：時間 ≪ T₁、高保真度、量子非破壞

## 120 分鐘流程

```
00–10 任務開場：讀取要快、準、不破壞
10–25 概念示範：說出讀取量子位元的三個條件：時間 ≪ T₁、高保真度、量子非破壞
25–65 父子共同實作：把「快、準、不破壞」各寫成一個可量測的指標與目標數字
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較三種讀取方式（直接、色散、螢光）各滿足哪幾個條件
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

## 錄音提問

請孩子回答：1. 讀取要快、準、不破壞在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
