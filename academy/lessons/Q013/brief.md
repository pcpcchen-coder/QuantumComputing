# Q013 Grover：16 個抽屜找寶藏

QM01 量子直覺：不用公式看懂量子｜第一階段 量子直覺｜難度 2／5｜好玩機制：尋寶

**學習目標**：理解振幅放大、為什麼大約 √N 次，以及轉太多次反而變差

## 120 分鐘流程

```
00–10 任務開場：Grover：16 個抽屜找寶藏
10–25 概念示範：理解振幅放大、為什麼大約 √N 次，以及轉太多次反而變差
25–65 父子共同實作：16 個信封藏一個寶藏，比較隨機翻與照場景的 Grover 輪數
65–75 休息／走動／聊天
75–105 孩子獨立改造：改成 64 個抽屜，預測最佳輪數再驗證
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
