# Q141 從 1,000 到 10,000：MW 級與低溫電源轉換

## 120 分鐘流程

```
00–10 任務開場：從 1,000 到 10,000：MW 級與低溫電源轉換

105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
