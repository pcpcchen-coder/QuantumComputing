# Q030 晶片長什麼樣子

QM02 超導量子位元：從超導到 transmon｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：尋寶（在晶片圖找元件）

**學習目標**：在 Xmon 晶片上找出量子位元、讀取腔、饋線與控制線，理解頻率多工

## 120 分鐘流程

```
00–10 任務開場：晶片長什麼樣子
10–25 概念示範：在 Xmon 晶片上找出量子位元、讀取腔、饋線與控制線，理解頻率多工
25–65 父子共同實作：在晶片圖與場景中尋寶，標出每個元件並寫出用途
65–75 休息／走動／聊天
75–105 孩子獨立改造：設計一條饋線串 4 個讀取腔的頻率表，相鄰間隔要夠大
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
