# Q009 量子線路像樂譜

QM01 量子直覺：不用公式看懂量子｜第一階段 量子直覺｜難度 2／5｜好玩機制：臨摹挑戰

**學習目標**：會讀量子線路圖：線是量子位元、方塊是閘、儀表是測量，由左往右執行

## 120 分鐘流程

```
00–10 任務開場：量子線路像樂譜
10–25 概念示範：會讀量子線路圖：線是量子位元、方塊是閘、儀表是測量，由左往右執行
25–65 父子共同實作：照場景臨摹 3 條線路，並說出每一步箭頭怎麼變
65–75 休息／走動／聊天
75–105 孩子獨立改造：自己畫一條 3 步的線路，請爸爸預測結果
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

手繪 3 條線路

## 驗收

完成「手繪 3 條線路」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：線路由左往右執行；同一條線上的閘順序不能隨便交換）。

## 錄音提問

請孩子回答：1. 量子線路像樂譜在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
