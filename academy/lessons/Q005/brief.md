# Q005 相位：看不見卻最重要

QM01 量子直覺：不用公式看懂量子｜第一階段 量子直覺｜難度 2／5｜好玩機制：盲測

**學習目標**：知道兩個狀態可以有相同機率、不同相位，而相位會改變後續結果

## 120 分鐘流程

```
00–10 任務開場：相位：看不見卻最重要
10–25 概念示範：知道兩個狀態可以有相同機率、不同相位，而相位會改變後續結果
25–65 父子共同實作：爸爸偷偷加或不加 Z 閘，孩子只能用 H 加測量判斷有沒有加
65–75 休息／走動／聊天
75–105 孩子獨立改造：設計一個需要兩步才能看出相位差的關卡
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 錄音提問

請孩子回答：1. 相位：看不見卻最重要在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
