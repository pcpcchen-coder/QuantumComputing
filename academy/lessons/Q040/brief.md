# Q040 量子電腦 ≠ 量子晶片

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：尋寶

**學習目標**：認識機房全景與 7 類連接（氦氣、冷卻水、混合氣、真空、微波、資料、電力）

## 120 分鐘流程

```
00–10 任務開場：量子電腦 ≠ 量子晶片
10–25 概念示範：認識機房全景與 7 類連接（氦氣、冷卻水、混合氣、真空、微波、資料、電力）
25–65 父子共同實作：在場景切換各類連接，列出所有設備與連線清單
65–75 休息／走動／聊天
75–105 孩子獨立改造：挑一條連接，說明它斷掉會發生什麼事
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
