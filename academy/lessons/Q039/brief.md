# Q039 讀取設計的取捨

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 5／5｜好玩機制：工程答辯

**學習目標**：權衡 κ、χ、Purcell 效應與讀取速度

## 120 分鐘流程

```
00–10 任務開場：讀取設計的取捨
10–25 概念示範：權衡 κ、χ、Purcell 效應與讀取速度
25–65 父子共同實作：用讀取參數計算器設計一組參數並為它答辯
65–75 休息／走動／聊天
75–105 孩子獨立改造：在 Purcell 濾波器有／無兩種情況下重新設計
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

讀取參數卡

## 家長課前準備

讀取參數計算器

## 驗收

完成「讀取參數卡」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：κ 大讀得快，但 Purcell 效應會讓 T₁ 變短）。

## 錄音提問

請孩子回答：1. 讀取設計的取捨在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
