# Q073 裝載與重排

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：競速（最少搬運步數）

**學習目標**：理解隨機裝載約一半機率，以及用 AOD 搬成無缺陷陣列

## 120 分鐘流程

```
00–10 任務開場：裝載與重排
10–25 概念示範：理解隨機裝載約一半機率，以及用 AOD 搬成無缺陷陣列
25–65 父子共同實作：用棋盤與棋子隨機擺放，比賽誰用最少步驟排成整齊陣列
65–75 休息／走動／聊天
75–105 孩子獨立改造：寫出自己的重排規則，在場景驗證
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

重排演算法紀錄

## 家長課前準備

棋盤、棋子；atoms.html#tweezer

## 驗收

完成「重排演算法紀錄」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：搬運有機率掉原子；步數越多，掉的機會越大）。

## 錄音提問

請孩子回答：1. 裝載與重排在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
