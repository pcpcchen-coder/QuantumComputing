# Q007 兩顆、三顆、五十顆：2ⁿ 有多大

QM01 量子直覺：不用公式看懂量子｜第一階段 量子直覺｜難度 2／5｜好玩機制：競速（算記憶體爆炸）

**學習目標**：知道 n 個量子位元需要 2ⁿ 個振幅，理解古典模擬的極限

## 120 分鐘流程

```
00–10 任務開場：兩顆、三顆、五十顆：2ⁿ 有多大
10–25 概念示範：知道 n 個量子位元需要 2ⁿ 個振幅，理解古典模擬的極限
25–65 父子共同實作：用米粒或骰子模擬 1 到 5 個位元的狀態數，再算 50 個位元需要多少記憶體
65–75 休息／走動／聊天
75–105 孩子獨立改造：查自己家電腦記憶體，算出最多能精確模擬幾個量子位元
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

2ⁿ 記憶體對照表

## 家長課前準備

米粒、杯子、計算機；operation.html#register

## 驗收

完成「2ⁿ 記憶體對照表」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：2ⁿ 個振幅不等於能讀出 2ⁿ 個答案；一次測量只得到 n 個位元）。

## 錄音提問

請孩子回答：1. 兩顆、三顆、五十顆：2ⁿ 有多大在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
