# Q084 表面碼

QM06 錯誤更正、應用與未來｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：Bug 獵人

**學習目標**：認識資料位元、測量位元、症狀與最小權重配對解碼

## 120 分鐘流程

```
00–10 任務開場：表面碼
10–25 概念示範：認識資料位元、測量位元、症狀與最小權重配對解碼
25–65 父子共同實作：在場景放錯誤、看症狀，自己手動配對再和解碼器比較
65–75 休息／走動／聊天
75–105 孩子獨立改造：找出一個解碼器會配錯的錯誤組合
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「解碼練習單」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：一個邏輯位元要用數百到上千個實體位元）。

## 錄音提問

請孩子回答：1. 表面碼在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
