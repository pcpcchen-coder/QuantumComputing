# Q045 低溫佈線與熱負載

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 4／5｜好玩機制：基準測試

**學習目標**：知道每條線都會把熱帶下去，量子位元越多冷卻越吃緊

## 120 分鐘流程

```
00–10 任務開場：低溫佈線與熱負載
10–25 概念示範：知道每條線都會把熱帶下去，量子位元越多冷卻越吃緊
25–65 父子共同實作：用場景估算 50、100、1000 顆量子位元的熱負載
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較不鏽鋼與超導線材，算出能多接幾條線
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「熱負載預算表」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：線材導電好通常導熱也好；低溫佈線要在兩者間取捨）。

## 錄音提問

請孩子回答：1. 低溫佈線與熱負載在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
