# Q032 模組發表：設計我的 transmon

QM02 超導量子位元：從超導到 transmon｜第二階段 硬體怎麼做｜難度 4／5｜好玩機制：工程答辯

**學習目標**：選定頻率、非諧性、E_J／E_C，說明每個數字背後的取捨

## 120 分鐘流程

```
00–10 任務開場：模組發表：設計我的 transmon
10–25 概念示範：選定頻率、非諧性、E_J／E_C，說明每個數字背後的取捨
25–65 父子共同實作：用參數設計器做一張 transmon 參數卡，並在場景驗證能階
65–75 休息／走動／聊天
75–105 孩子獨立改造：替參數卡加一個讀取腔頻率，並說明失諧為什麼要這麼大
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

transmon 參數卡

## 家長課前準備

參數設計器；index.html#potential

## 驗收

完成「transmon 參數卡」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：參數卡是設計目標；製程誤差會讓實際頻率偏移）。

## 錄音提問

請孩子回答：1. 模組發表：設計我的 transmon在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
