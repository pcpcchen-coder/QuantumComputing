# Q047 軟體、監控與聯鎖

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：故障注入

**學習目標**：認識軟體堆疊、校準資料庫與告警聯鎖

## 120 分鐘流程

```
00–10 任務開場：軟體、監控與聯鎖
10–25 概念示範：認識軟體堆疊、校準資料庫與告警聯鎖
25–65 父子共同實作：在場景觸發冷卻水中斷、真空洩漏、流阻堵塞三種情境，寫出處置步驟
65–75 休息／走動／聊天
75–105 孩子獨立改造：為家裡的一台設備（冰箱、熱水器）寫一張異常處置卡
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

異常處置卡

## 家長課前準備

peripherals.html#software、#monitor；docs/周邊系統連接與啟動指南.md

## 驗收

完成「異常處置卡」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：聯鎖會自動保護設備；處置時先確認人員安全再處理機器）。

## 錄音提問

請孩子回答：1. 軟體、監控與聯鎖在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
