# Q109 第 11 課：表面碼——穩定子與匹配解碼

QM07 超導量子電腦深入：師生對話十三課｜第四階段 深化與產業｜難度 5／5｜好玩機制：Bug 獵人

**學習目標**：理解 d = 3 表面碼的穩定子、CZ 順序、錯誤與邊界，以及最小權重完美匹配

## 120 分鐘流程

```
00–10 任務開場：第 11 課：表面碼——穩定子與匹配解碼
10–25 概念示範：理解 d = 3 表面碼的穩定子、CZ 順序、錯誤與邊界，以及最小權重完美匹配
25–65 父子共同實作：在自由實驗點位元注入錯誤，看症狀與解碼器配對
65–75 休息／走動／聊天
75–105 孩子獨立改造：找出兩個錯誤造成邏輯錯誤的例子
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
