# Q119 範例 6：Deutsch——紅綠球搖獎機

QM08 動手寫量子電路：從八個範例到自己的線路｜第四階段 深化與產業｜難度 3／5｜好玩機制：偵探辦案

**學習目標**：用《量子金魚》紅綠球比喻與四種黑盒，理解一次查詢分辨常數或平衡

## 120 分鐘流程

```
00–10 任務開場：範例 6：Deutsch——紅綠球搖獎機
10–25 概念示範：用《量子金魚》紅綠球比喻與四種黑盒，理解一次查詢分辨常數或平衡
25–65 父子共同實作：先用古典方式搖球，再用 Deutsch 線路一次判斷，四種黑盒全部跑
65–75 休息／走動／聊天
75–105 孩子獨立改造：設計一個 8 顆球的版本，說明相長與相消
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
