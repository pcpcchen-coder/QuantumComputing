# Q042 脈衝管與壓縮機

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：科學實驗（壓縮與膨脹）

**學習目標**：知道脈衝管靠壓力波與蓄冷器把溫度降到約 3 K

## 120 分鐘流程

```
00–10 任務開場：脈衝管與壓縮機
10–25 概念示範：知道脈衝管靠壓力波與蓄冷器把溫度降到約 3 K
25–65 父子共同實作：用打氣筒（壓縮變熱）與噴霧罐（膨脹變冷）體驗溫度變化，對照場景
65–75 休息／走動／聊天
75–105 孩子獨立改造：解釋為什麼脈衝管沒有在冷端移動的零件是一個優點
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 家長課前準備

## 驗收

完成「實驗紀錄」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：除塵罐倒置會噴出極冷液體，由家長操作、不對人噴）。

## 錄音提問

請孩子回答：1. 脈衝管與壓縮機在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
