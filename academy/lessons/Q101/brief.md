# Q101 第 3 課：迷思修正——Z 線不是把位元調成一樣

QM07 超導量子電腦深入：師生對話十三課｜第四階段 深化與產業｜難度 4／5｜好玩機制：偵探辦案

**學習目標**：修正「Z 線是把每顆位元調成相同」的迷思，理解失諧與耦合

## 120 分鐘流程

```
00–10 任務開場：第 3 課：迷思修正——Z 線不是把位元調成一樣
10–25 概念示範：修正「Z 線是把每顆位元調成相同」的迷思，理解失諧與耦合
25–65 父子共同實作：在案例章把三顆位元的頻率調近再調開，觀察耦合何時打開
65–75 休息／走動／聊天
75–105 孩子獨立改造：寫一段 30 秒的迷思修正說明
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

迷思修正卡

## 家長課前準備

師生對話第 3 課；transmon-3d#case

## 驗收

完成「迷思修正卡」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：頻率太近會發生碰撞與串擾；配置時要刻意錯開）。

## 錄音提問

請孩子回答：1. 第 3 課：迷思修正——Z 線不是把位元調成一樣在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
