# Q069 離子鏈的集體振動

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：角色扮演（人肉離子鏈）

**學習目標**：知道離子鏈的正規模是讓離子彼此溝通的「量子匯流排」

## 120 分鐘流程

```
00–10 任務開場：離子鏈的集體振動
10–25 概念示範：知道離子鏈的正規模是讓離子彼此溝通的「量子匯流排」
25–65 父子共同實作：全家排成一列手拉手，示範質心模與呼吸模
65–75 休息／走動／聊天
75–105 孩子獨立改造：在場景增加離子數，觀察模式頻率怎麼擠在一起
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「正規模觀察表」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：離子越多，模式越擠，閘越難做得又快又準）。

## 錄音提問

請孩子回答：1. 離子鏈的集體振動在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
