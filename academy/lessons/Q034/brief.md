# Q034 電路 QED：量子位元＋諧振腔

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：角色扮演

**學習目標**：知道讀取是透過共振腔「間接」看量子位元

## 120 分鐘流程

```
00–10 任務開場：電路 QED：量子位元＋諧振腔
10–25 概念示範：知道讀取是透過共振腔「間接」看量子位元
25–65 父子共同實作：用兩個音叉或兩條橡皮筋示範耦合；在場景指出量子位元與讀取腔
65–75 休息／走動／聊天
75–105 孩子獨立改造：畫出量子位元、讀取腔、饋線三者的連接圖
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
