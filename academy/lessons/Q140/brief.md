# Q140 低溫熱預算：熱帳怎麼變成電

QM09 量子電腦的供電與機房工程｜第四階段 深化與產業｜難度 5／5｜好玩機制：基準測試

**學習目標**：逐層估算低溫熱負載，理解冷卻功率如何換成室溫用電

## 120 分鐘流程

```
00–10 任務開場：低溫熱預算：熱帳怎麼變成電
10–25 概念示範：逐層估算低溫熱負載，理解冷卻功率如何換成室溫用電
25–65 父子共同實作：在熱預算場景逐層加總熱負載
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較不同線材或多工方案對熱預算的影響
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「逐層熱預算表」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：越低溫，每瓦冷卻要付出的室溫電力越多）。

## 錄音提問

請孩子回答：1. 低溫熱預算：熱帳怎麼變成電在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
