# Q060 動態線路

QM04 操作量子電腦與演算法｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：冒險任務

**學習目標**：理解中途量測與依結果即時回饋，例如主動重置

## 120 分鐘流程

```
00–10 任務開場：動態線路
10–25 概念示範：理解中途量測與依結果即時回饋，例如主動重置
25–65 父子共同實作：在模擬器做一個「量到 1 就翻回 0」的主動重置線路
65–75 休息／走動／聊天
75–105 孩子獨立改造：用中途量測做一個簡單的重複碼症狀量測
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 家長課前準備

本機模擬器；atoms.html#zoned（中途量測）

## 驗收

完成「主動重置線路」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：回饋要在相干時間內完成；延遲本身就會造成錯誤）。

## 錄音提問

請孩子回答：1. 動態線路在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
