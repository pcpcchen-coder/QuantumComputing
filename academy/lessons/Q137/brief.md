# Q137 中性原子的供電：保護熱穩態

QM09 量子電腦的供電與機房工程｜第四階段 深化與產業｜難度 4／5｜好玩機制：資料偵探

**學習目標**：知道中性原子整套最省電，但雷射最敏感，要保護的是熱穩態

## 120 分鐘流程

```
00–10 任務開場：中性原子的供電：保護熱穩態
10–25 概念示範：知道中性原子整套最省電，但雷射最敏感，要保護的是熱穩態
25–65 父子共同實作：整理中性原子供電需求，與離子阱比較
65–75 休息／走動／聊天
75–105 孩子獨立改造：推論中性原子擴大後會卡在哪裡
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
