# Q074 芮德堡阻斷與 CZ

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：闖關

**學習目標**：知道距離小於阻斷半徑時兩顆原子不能同時被激發，進而做出 CZ

## 120 分鐘流程

```
00–10 任務開場：芮德堡阻斷與 CZ
10–25 概念示範：知道距離小於阻斷半徑時兩顆原子不能同時被激發，進而做出 CZ
25–65 父子共同實作：在場景改變原子距離，記錄阻斷何時發生，再走一次 CZ 協定
65–75 休息／走動／聊天
75–105 孩子獨立改造：解釋為什麼 |00⟩ 經過協定後多一個負號
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
