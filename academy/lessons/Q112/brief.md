# Q112 模組發表：換你當老師

QM07 超導量子電腦深入：師生對話十三課｜第四階段 深化與產業｜難度 4／5｜好玩機制：角色交換

**學習目標**：孩子當老師，用師生對話形式講一課，並用 3D 動畫示範

## 120 分鐘流程

```
00–10 任務開場：模組發表：換你當老師
10–25 概念示範：孩子當老師，用師生對話形式講一課，並用 3D 動畫示範
25–65 父子共同實作：挑十三課其中一課，改寫成自己的師生對話並錄音
65–75 休息／走動／聊天
75–105 孩子獨立改造：替這課加三題課後練習與解答
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

自編師生對話一課

## 家長課前準備

師生對話紀錄；錄音設備

## 驗收

完成「自編師生對話一課」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：引用動畫畫面時註明出處）。

## 錄音提問

請孩子回答：1. 模組發表：換你當老師在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？

課前教學影片與兩小時課堂分開管理；影片長度依實測旁白，不等於 120 分鐘。
