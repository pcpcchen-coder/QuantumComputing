# Q006 干涉：波可以互相抵消

QM01 量子直覺：不用公式看懂量子｜第一階段 量子直覺｜難度 2／5｜好玩機制：科學實驗（水盆與光）

**學習目標**：用水波與雙狹縫理解「振幅相加」，知道機率不能直接相加

## 120 分鐘流程

```
00–10 任務開場：干涉：波可以互相抵消
10–25 概念示範：用水波與雙狹縫理解「振幅相加」，知道機率不能直接相加
25–65 父子共同實作：用水盆與雷射筆（或手機光源＋梳子）觀察干涉條紋，再對照場景中的兩條路徑
65–75 休息／走動／聊天
75–105 孩子獨立改造：改變路徑相位，預測輸出會變亮還是變暗
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

干涉實驗照片＋一句說明

## 家長課前準備

淺水盆、兩支筆、手電筒或低功率雷射筆（家長操作）

## 驗收

完成「干涉實驗照片＋一句說明」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：雷射筆不可直視、不照人；量子加速靠的是干涉，不是「同時試」）。

## 錄音提問

請孩子回答：1. 干涉：波可以互相抵消在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
