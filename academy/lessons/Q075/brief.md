# Q075 分區架構與成像讀取

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：真實任務

**學習目標**：認識儲存、糾纏、讀取三區與相機成像判讀

## 120 分鐘流程

```
00–10 任務開場：分區架構與成像讀取
10–25 概念示範：認識儲存、糾纏、讀取三區與相機成像判讀
25–65 父子共同實作：替一條線路排出分區搬運時程；在場景判讀相機影像
65–75 休息／走動／聊天
75–105 孩子獨立改造：加入中途量測，重新安排時程
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
