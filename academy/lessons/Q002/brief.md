# Q002 硬幣與箭頭：位元 vs 量子位元

QM01 量子直覺：不用公式看懂量子｜第一階段 量子直覺｜難度 1／5｜好玩機制：角色扮演（人肉 Bloch 球）

**學習目標**：知道疊加是「箭頭指向的方向」，不是「同時是 0 又是 1」

## 120 分鐘流程

```
00–10 任務開場：硬幣與箭頭：位元 vs 量子位元
10–25 概念示範：知道疊加是「箭頭指向的方向」，不是「同時是 0 又是 1」
25–65 父子共同實作：用紙盤、竹籤做一顆 Bloch 球，照場景擺出 |0⟩、|1⟩、|+⟩ 三種方向
65–75 休息／走動／聊天
75–105 孩子獨立改造：自己決定一個角度，預測測量到 0 的機率，再用場景驗證
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

紙做的 Bloch 球

## 家長課前準備

紙盤、竹籤、膠帶、彩色筆；先開好 operation.html#qubit

## 驗收

完成「紙做的 Bloch 球」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：Bloch 球上的方向不是空間中的真實方向；北極與南極是 |0⟩ 與 |1⟩，不是相反方向的兩個「東西」）。

## 錄音提問

請孩子回答：1. 硬幣與箭頭：位元 vs 量子位元在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
