# Q080 平台大比較與供電分析

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：產品評審

**學習目標**：從時間尺度、連接性、錯誤率、設施、供電比較各平台

## 120 分鐘流程

```
00–10 任務開場：平台大比較與供電分析
10–25 概念示範：從時間尺度、連接性、錯誤率、設施、供電比較各平台
25–65 父子共同實作：替六個平台打分數並說明權重
65–75 休息／走動／聊天
75–105 孩子獨立改造：換一組權重（例如重視耗電），看排名怎麼變
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
