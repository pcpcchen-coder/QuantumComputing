# Q072 磁光阱與光鑷

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 3／5｜好玩機制：科學實驗（光的力）

**學習目標**：知道 MOT 先把原子冷下來，光鑷再用聚焦雷射抓住單顆原子

## 120 分鐘流程

```
00–10 任務開場：磁光阱與光鑷
10–25 概念示範：知道 MOT 先把原子冷下來，光鑷再用聚焦雷射抓住單顆原子
25–65 父子共同實作：用吸管與乒乓球（吹風機氣流）體驗「被力場抓住」；對照場景光路
65–75 休息／走動／聊天
75–105 孩子獨立改造：解釋 SLM 與 AOD 各負責什麼
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

光鑷原理圖

## 家長課前準備

吹風機、乒乓球；atoms.html#atomsys、#tweezer

## 驗收

完成「光鑷原理圖」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：光鑷用的是光學偶極力，不是把原子「夾住」）。

## 錄音提問

請孩子回答：1. 磁光阱與光鑷在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
