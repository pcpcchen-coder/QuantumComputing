# Q044 降溫一次要幾天

QM03 讀取量子位元與周邊系統｜第二階段 硬體怎麼做｜難度 3／5｜好玩機制：時間機器

**學習目標**：認識抽真空 → 預冷 → 凝結 → 循環的流程與時間

## 120 分鐘流程

```
00–10 任務開場：降溫一次要幾天
10–25 概念示範：認識抽真空 → 預冷 → 凝結 → 循環的流程與時間
25–65 父子共同實作：把降溫步驟排成時間軸，標出每一步在等什麼
65–75 休息／走動／聊天
75–105 孩子獨立改造：規劃一次換樣品的完整時程（升溫＋降溫）
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「降溫時間軸」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：升溫和降溫都要時間；換一次樣品常要好幾天）。

## 錄音提問

請孩子回答：1. 降溫一次要幾天在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
