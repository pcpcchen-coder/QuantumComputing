# Q055 兩位元閘：CZ 與交叉共振

QM04 操作量子電腦與演算法｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：角色扮演

**學習目標**：知道兩位元閘怎麼在硬體上做出來：CZ（磁通調頻）與交叉共振（ZX）

## 120 分鐘流程

```
00–10 任務開場：兩位元閘：CZ 與交叉共振
10–25 概念示範：知道兩位元閘怎麼在硬體上做出來：CZ（磁通調頻）與交叉共振（ZX）
25–65 父子共同實作：在場景觀察 |11⟩–|20⟩ 迴避交叉產生條件相位，再看交叉共振
65–75 休息／走動／聊天
75–105 孩子獨立改造：整理各家原生兩位元閘對照表
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
