# Q056 轉譯：邏輯線路到硬體

QM04 操作量子電腦與演算法｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：效能競賽（最少 SWAP）

**學習目標**：理解分解、配置、路由（插 SWAP）與最佳化

## 120 分鐘流程

```
00–10 任務開場：轉譯：邏輯線路到硬體
10–25 概念示範：理解分解、配置、路由（插 SWAP）與最佳化
25–65 父子共同實作：在耦合圖上幫一條線路找位置，比賽誰插入的 SWAP 最少
65–75 休息／走動／聊天
75–105 孩子獨立改造：換一種耦合圖（線形、方格、重六角），比較 SWAP 數量
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

路由比賽紀錄

## 家長課前準備

耦合圖紙板與代幣

## 驗收

完成「路由比賽紀錄」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：一個 SWAP 等於三個 CNOT，會大幅增加錯誤）。

## 錄音提問

請孩子回答：1. 轉譯：邏輯線路到硬體在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？

## 素材

- 簡報：如何操作量子電腦（slides/QC_Operation_Talk.pptx）p26
- 需新增：★ 耦合圖路由場景

生活技能支線：在限制下規劃路徑。課後延伸：15–30 分鐘自由改造；寫三句學習日誌：我做了什麼、哪裡卡住、下次想加什麼。

課前教學影片與兩小時課堂分開管理；影片長度依實測旁白，不等於 120 分鐘。
