# Q061 QFT 與相位估計

QM04 操作量子電腦與演算法｜第三階段 操作、平台與未來｜難度 5／5｜好玩機制：解鎖成就

**學習目標**：把量子傅立葉轉換理解成相位的干涉，知道相位估計的精度和位元數有關

## 120 分鐘流程

```
00–10 任務開場：QFT 與相位估計
10–25 概念示範：把量子傅立葉轉換理解成相位的干涉，知道相位估計的精度和位元數有關
25–65 父子共同實作：在場景跑 QFT 線路；用模擬器做 3、4、5 位元相位估計並比較精度
65–75 休息／走動／聊天
75–105 孩子獨立改造：選一個不能整除的相位，觀察估計結果的分布
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

QPE 精度實驗

## 家長課前準備

operation.html#circuit（QFT）；本機模擬器

## 驗收

完成「QPE 精度實驗」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：QFT 本身不是加速來源；它要搭配有結構的問題才有用）。

## 錄音提問

請孩子回答：1. QFT 與相位估計在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
