# Q134 接地與共模：上百台儀器一起漏電

QM09 量子電腦的供電與機房工程｜第四階段 深化與產業｜難度 4／5｜好玩機制：偵探辦案

**學習目標**：理解接地迴路與共模雜訊在大型系統中如何放大

## 120 分鐘流程

```
00–10 任務開場：接地與共模：上百台儀器一起漏電
10–25 概念示範：理解接地迴路與共模雜訊在大型系統中如何放大
25–65 父子共同實作：在接地場景增加儀器數，觀察共模電流變化
65–75 休息／走動／聊天
75–105 孩子獨立改造：提出一種接地拓樸改善方案並說明取捨
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
