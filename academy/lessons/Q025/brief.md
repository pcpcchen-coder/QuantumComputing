# Q025 E_J 與 E_C：兩個能量尺度

QM02 超導量子位元：從超導到 transmon｜第二階段 硬體怎麼做｜難度 4／5｜好玩機制：設計改造

**學習目標**：知道 E_J／E_C 比值決定量子位元的性格，以及電荷色散為什麼會被壓下來

## 120 分鐘流程

```
00–10 任務開場：E_J 與 E_C：兩個能量尺度
10–25 概念示範：知道 E_J／E_C 比值決定量子位元的性格，以及電荷色散為什麼會被壓下來
25–65 父子共同實作：在場景掃描 E_J／E_C，記錄非諧性與電荷色散的變化
65–75 休息／走動／聊天
75–105 孩子獨立改造：找出一個「非諧性夠、電荷雜訊又小」的折衷點並說明理由
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```
