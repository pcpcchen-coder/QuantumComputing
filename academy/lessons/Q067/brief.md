# Q067 離子阱系統全景

QM05 各種量子電腦平台｜第三階段 操作、平台與未來｜難度 3／5｜好玩機制：尋寶

**學習目標**：認識真空腔、原子源、雷射、成像與電子系統如何連在一起

## 120 分鐘流程

```
00–10 任務開場：離子阱系統全景
10–25 概念示範：認識真空腔、原子源、雷射、成像與電子系統如何連在一起
25–65 父子共同實作：在場景切換各類連接，畫出系統方塊圖
65–75 休息／走動／聊天
75–105 孩子獨立改造：比較離子阱與超導的設施需求差異
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 驗收

完成「系統方塊圖」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：離子阱不需要稀釋冷凍，但需要超高真空與多道穩頻雷射）。

## 錄音提問

請孩子回答：1. 離子阱系統全景在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
