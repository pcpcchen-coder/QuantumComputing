# Q093 產業地圖與發展路線

QM06 錯誤更正、應用與未來｜第三階段 操作、平台與未來｜難度 4／5｜好玩機制：家庭投票

**學習目標**：知道 NISQ → 早期容錯 → 大規模容錯三個階段與各家路線

## 120 分鐘流程

```
00–10 任務開場：產業地圖與發展路線
10–25 概念示範：知道 NISQ → 早期容錯 → 大規模容錯三個階段與各家路線
25–65 父子共同實作：把各家公司與平台放到路線圖上，標出公開的里程碑
65–75 休息／走動／聊天
75–105 孩子獨立改造：全家投票：你認為哪一年會出現真正有用的量子電腦？寫下理由
105–115 角色互換：孩子教爸爸操作與原理
115–120 錄音總結、作品命名、版本存檔
```

## 當堂作品

發展路線圖

## 家長課前準備

路線圖模板（每年更新）

## 驗收

完成「發展路線圖」；能不用看稿說出核心原理；能指出至少一個錯誤、限制或注意事項（例如：公司路線圖是目標，不是保證；要看已發表的實驗）。

## 錄音提問

請孩子回答：1. 產業地圖與發展路線在解決什麼？2. 我怎麼做？3. 哪裡容易錯？4. 生活中或真實的量子電腦哪裡會用到？
