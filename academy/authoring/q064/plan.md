# Q064 模組專題：在模擬器跑我的線路

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（兩顆格羅弗加雜訊、換題目：多伊奇問題、三顆格羅弗的理想值）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂的加速等級、模組回顧（Q049–Q063）；Release 任務 |
| 10–25 | 概念示範：操作檢查表五關，用兩顆 Grover 找 11 走一次「定義問題 → 線路 → 轉譯 → 執行 → 解讀」 |
| 25–65 | 父子共同實作：挑一個學過的演算法（Bell、GHZ、Deutsch、Grover），加入雜訊模型跑完整流程，寫實驗報告 v1.0；爸爸做重現測試 |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：比較最佳化等級 0 與 3（三顆 Grover：cx 51 vs 39、101 出現 458 vs 550 次），說明結果差異 |
| 105–115 | 孩子教爸爸：五關、為什麼閘少錯就少、雜訊模型是假設 |
| 115–120 | 錄音總結、作品命名、存 v1.0／v1.1 |

旁白用語：Qiskit 念「開源量子程式套件」、Grover 念「格羅弗搜尋」、Deutsch 念「多伊奇」、Release 念「發布」、seed 念「亂數種子」、shots 念「重複次數」、
transpile 念「轉譯」、optimization level 念「最佳化等級」、rz／sx／x／cx 念「繞垂直軸旋轉／半個翻轉閘／翻轉閘／受控反閘」、H 念「哈達瑪閘」；投影片保留英文。

教材：可執行的 `my_circuit_release.ipynb` 與同內容的 `my_circuit_release.py`（本機模擬器，不需帳號；會自動寫出 `report_<題目>_v1.0.md`）、
操作檢查表、實驗報告單、最佳化等級比較表、重現測試與說明卡、解答（`academy/authoring/q064/classroom.py`）。
