# Q058 量測基底與期望值

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（先轉再量、從柱子算期望值、盲測練習），都在 operation.html（場景 7 讀取與統計、場景 1 狀態與測量、場景 2 單位元閘）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂的計數表只回答上下軸；今天量別的方向、把計數變成一個數字 |
| 10–25 | 概念：硬體只量 Z；量 X 先 H、量 Y 先 S† 再 H；取樣與期望值兩種輸出；⟨Z⟩ = P(0) − P(1)；看 operation.html#readout |
| 25–65 | 父子在場景 7 準備 θ = 90°（接近 \|+⟩），分別用 Z、X 基底量測並比較；玩盲測（四個狀態，Z、X 各一組統計），填基底判讀表 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：用 basis_lab.py（或任何本機模擬器）算 \|0⟩、\|+⟩、倒下 60° 的 ⟨Z⟩、⟨X⟩，和場景讀數對照 |
| 105–115 | 孩子教爸爸：為什麼要先轉、期望值怎麼算、量 X 前要先做 H |
| 115–120 | 錄音總結、作品命名、存檔 |

旁白用語：Z 基底念「零一基底／零一方向」、X 基底念「正負基底／正負方向」、Y 基底念「虛數方向」、|+⟩／|−⟩ 念「加態／減態」、S† 念「反向的四分之一圈相位閘」、Grover 念「格羅弗搜尋」；投影片保留符號。

教材：基底對照卡與盲測規則、盲測題卡（可剪）、基底判讀表、說明卡、解答、可執行的 basis_lab.py（`academy/authoring/q058/classroom.py`）。
