# Q048 從零到上線

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（機房配置、模擬停電、啟動與校準）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：把整套量子電腦搬進空房間 |
| 10–25 | 概念：一套約 25 kW、配置四原則、市電直供 vs UPS、冷卻水／防振／接地 |
| 25–65 | 真實任務：在方格紙畫機房配置圖（工程師），照五階段檢查表逐項驗收（驗收員） |
| 65–75 | 休息 |
| 75–105 | 在場景模擬停電，修改配置（冷卻鏈接 UPS＋發電機）並再演練 |
| 105–115 | 孩子教爸爸：四大需求與每台設備的位置理由 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：機房配置圖方格紙、設備剪貼卡與用電表、上線檢查表（五階段×四項）、停電演練卡、說明卡、解答（`academy/authoring/q048/classroom.py`）。
