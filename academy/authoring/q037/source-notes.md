## 簡報（slides/JJ_Microwave_Readout_Talk.pptx）

- p26「讀取要滿足什麼條件？」：「快速 / 讀取時間 ≪ T1；典型 100–500 ns。量子糾錯需要每個週期都讀取」「高保真度 / 單發（single-shot）就能判斷 0/1，誤判率 < 1 %」。
  備註：「第二，準：單發讀取，也就是只量一次就能判斷 0 或 1，錯誤率要低於百分之一。」
- p31「單發判別：IQ 叢集與讀取保真度」：「模擬：每個狀態 3000 次單發量測（含 3 % 讀取期間 T1 衰減）」「F = 1 − [P(1|0) + P(0|1)] / 2 / SNR = |μ1 − μ0| / 2σ」
  「誤差來源 / 重疊誤差：放大器雜訊使兩團變寬 → 用量子極限放大器、加長積分 / T1 衰減：|1⟩ 在讀取中掉到 |0⟩ → 讀取要快 / 狀態製備誤差：殘留熱激發 → 主動重置 / 預選 /
  讀取誘發躍遷：光子數過高 → 洩漏到 |2⟩ 以上 / 用閾值（垂直平分線）判別；也可用 ML 分類器」。
  備註：「把量子位元先準備在 |0⟩ 量幾千次，點會聚成一團高斯分佈；準備在 |1⟩，聚成另一團。高斯的寬度來自放大器雜訊，中心的距離來自色散相位差。」
  「判別方法很簡單：在兩團中心的垂直平分線畫一條閾值，落在哪一邊就判成哪個狀態。」「兩團之間有一條紅色拖尾，那是準備在 |1⟩ 但在讀取過程中 T1 衰減掉到 |0⟩ 的事件。」
  「讀取保真度定義是 1 減去兩種誤判機率的平均。訊雜比是兩團中心距離除以兩倍標準差。」
  「誤差來源有四類：兩團重疊、讀取中的 T1 衰減、一開始就沒準備好的熱激發、以及光子數太高造成的讀取誘發躍遷。」
  「試著關掉「量子極限放大器」，兩團會變得很寬、互相重疊，保真度明顯下降；加長積分時間會變好，但 T1 衰減的拖尾也會增加——這就是讀取的根本權衡。」

## 學程筆記（notes/dispersive-readout.md）

- §2.5 第 4 步：「積分：把訊號積分一段時間 τ（約 100 ns–1 μs），每量一次（single shot）得到一個 (I, Q) 點。」
  第 5 步：「判別：重複幾千次之後，|0⟩ 和 |1⟩ 會形成兩團高斯分布。中間畫一條閾值線，就能判斷每一次量到的是 0 還是 1。」
- §3 表：「讀取時間與 T1 互相拉扯 | 讀得越久越準，但位元也越可能在讀取途中衰減（|1⟩ → |0⟩） | — | 提高 κ（搭配 Purcell 濾波器）、使用量子極限放大器、最佳化積分權重」。
  「目前的業界水準是在約 100–300 ns 內做到 99% 以上的讀取保真度。」
- §5 第 6 步：「單發直方圖：在 IQ 平面上畫出兩團分布，算出指派保真度矩陣 P(0|0)、P(1|1)。」
  「讀取錯誤的主要來源：讀取途中的 T1 衰減、殘留熱激發（初始態不是純 |0⟩）、放大器雜訊（量測效率 η 不夠高），以及功率過高引起的能階躍遷。」

## 師生對話教學紀錄第 6 課（docs/超導量子電腦師生對話教學紀錄.md）

- 「五、積分與判別。每個 shot 積分 τ（約 100 ns–1 μs）得到一個 IQ 點，雜訊隨 1/√τ 縮小；重複幾千次形成兩團高斯，中間畫閾值。
  錯誤來源：分布重疊、讀取途中 T₁ 衰減、初始熱激發、讀取功率太高。τ 太短雜訊大、太長衰減多；業界約 100–300 ns 可達 99% 以上。」
