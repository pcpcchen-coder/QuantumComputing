# Q037 單發判別與保真度

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂 IQ 平面接到「這個點算 0 還是 1、會判錯多少」，盲測任務 |
| 10–25 | 概念：單發讀取（一次一個 IQ 點、兩團高斯雲）、判別閾值（垂直平分線）、兩種判錯、保真度 F = 1 − [P(1|0) + P(0|1)] / 2、T₁ 造成的錯誤；常見誤解（讀越久越準？） |
| 25–65 | 父子實作：operation.html#readout，爸爸偷偷移動判別閾值並遮住畫面，孩子只看兩種錯誤率猜偏向，填保真度計算表（十回合） |
| 65–75 | 休息 |
| 75–105 | 孩子改造：index.html#iq，量子極限放大器與 T1 衰減兩個開關的四種組合，比較保真度 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替保真度計算表取名字、保存 |

教材：保真度計算表、四種組合比較表、計算練習單、說明卡（列印）、解答、可執行的 `fidelity_calc.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q037/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q037.py`（移動判別閾值、衰減與積分時間：兩段用 operation.html#readout；放大器和衰減開關：index.html#iq）。
