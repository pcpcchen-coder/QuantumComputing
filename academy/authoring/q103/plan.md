# Q103 能階、共振與拉比振盪

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
課綱形式為「師生對話」第 5 課；影片沿用父子課堂的口吻與結構，對話內容依 `docs/超導量子電腦師生對話教學紀錄.md` 第 5 課整理，未虛構師生或孩子的發言。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：沒有 JJ 會怎樣？ |
| 10–25 | 概念：能階的實體意義、共振條件（相鄰能階的躍遷頻率） |
| 25–65 | transmon-3d 第 3、4 章：有 JJ／沒有 JJ 送 π 脈衝、持續驅動 40 ns（實驗員與記錄員） |
| 65–75 | 休息 |
| 75–105 | 孩子解釋：為什麼持續驅動 40 ns 轉一圈回到 \|0⟩ |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、作品命名、保存 |

教材：可執行的 `rabi_ladder.py`（numpy，與動畫相同參數的 14 能階模擬）、預測卡、觀察紀錄表、一圈拉比振盪作圖格、解釋卡與解答（`academy/authoring/q103/classroom.py`）。
