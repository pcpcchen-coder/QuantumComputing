# Q036 IQ 平面：把微波變成一個點

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂「狀態改變穿透訊號的振幅與相位」接到「把微波變成平面上一個點」，臨摹挑戰 |
| 10–25 | 概念：讀取鏈（AWG、IQ 混頻器、LO、冷凍機與放大器、ADC、FPGA）、外差降到約 100 MHz 中頻與多工、手電筒類比、解調（乘 cos、sin 再積分，匹配濾波）、一個點＝振幅＋相位、兩團與判別線；常見誤解 |
| 25–65 | 父子實作：手電筒畫圓、喊停量光點；開 index.html#iq 臨摹，手繪 IQ 圖 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：解釋為什麼兩團點的距離比單看振幅更有用（正中間探測振幅一樣、方向不同；訊雜比＝距離 ÷ 兩倍團寬） |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替手繪圖取名字、保存 |

教材：手電筒紀錄、手繪 IQ 圖（方格＋12 個練習點）、改造單、說明卡（列印）、解答、可執行的 `iq_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q036/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q036.py`（探測頻率一變點就沿著一圈走，用 index.html#dispersive 右下小圖；每讀一次落下一個點、距離要比團寬大，用 index.html#iq）。
這是依課綱製作的課前教學版，不是實際上課錄音。
