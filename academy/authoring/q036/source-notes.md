## 簡報（slides/JJ_Microwave_Readout_Talk.pptx）

- p29「讀取原理：穿透訊號的振幅與相位」：「3 探測於兩峰中點：相位差最大、振幅相同」「5 放大、解調 → 得到 (I, Q)」。
  備註：「如果我們把探測頻率放在兩峰正中間……兩個狀態的振幅一樣，但相位差了 90 度。」「右下角是 IQ 平面，掃頻時穿透係數畫出一個圓，兩個點是兩個狀態在探測頻率下的位置。」
- p30「外差解調：從微波到 (I, Q)」：方塊「AWG / IF 脈衝 (~100 MHz)」「IQ 混頻器 / 上變頻」「冷凍機 / 樣品 + 放大」「IQ 混頻器 / 下變頻」「ADC / ~1 GS/s」「FPGA / 數位解調」「LO」
  「同一個本地振盪源（ω_LO = ω_r − ω_IF）」「I = ∫ s(t) w(t) cos(ωIF t) dt / Q = ∫ s(t) w(t) sin(ωIF t) dt」「s(t)：數位化後的訊號；w(t)：積分權重（matched filter）」
  「要點 / 外差：用 LO 把 7 GHz 降到 ~100 MHz 的中頻，便於數位化 / 一條 ADC 通道可同時解調多個 IF 頻率（多工） / 加權積分（匹配濾波）考慮諧振腔充能與 T1 衰減，可提升 SNR / 結果是每次量測一個複數點 (I, Q)」。
  備註：「量子位元的資訊藏在微波的相位裡，我們要把它轉換成數字。」「室溫端用 AWG 產生一個中頻約 100 MHz 的脈衝，經過 IQ 混頻器和本地振盪源 LO 上變頻到 7 GHz，送進冷凍機。
  從冷凍機出來、放大之後的訊號，再用同一個 LO 下變頻回中頻，由 ADC 以大約每秒十億次取樣數位化，最後在 FPGA 裡做數位解調。」
  「把訊號乘上中頻的 cos 和 sin，再乘上一個權重函數積分，就得到 I 和 Q。權重函數可以設計成匹配濾波器，考慮諧振腔充能的過程和 T1 衰減，能讓訊雜比最好。」
  「一條 ADC 通道可以同時處理很多個中頻頻率，所以多顆量子位元共用一條讀取線時，只要給每個諧振腔不同的中頻就能分開解調。」「每一次量測會得到複數平面上的一個點 (I, Q)。」
- p31「單發判別：IQ 叢集與讀取保真度」：「F = 1 − [P(1|0) + P(0|1)] / 2 / SNR = |μ1 − μ0| / 2σ」「重疊誤差：放大器雜訊使兩團變寬 → 用量子極限放大器、加長積分」「用閾值（垂直平分線）判別」。
  備註：「把量子位元先準備在 |0⟩ 量幾千次，點會聚成一團高斯分佈；準備在 |1⟩，聚成另一團。高斯的寬度來自放大器雜訊，中心的距離來自色散相位差。」
  「在兩團中心的垂直平分線畫一條閾值」「訊雜比是兩團中心距離除以兩倍標準差。」
  「【切換到 3D 場景 10】每條細線是一次量測的積分軌跡，從上方 t=0 開始，一開始被雜訊淹沒到處亂跑，積分越久越收斂，最後落到 IQ 平面上。試著關掉「量子極限放大器」，兩團會變得很寬、互相重疊，保真度明顯下降」。

## 簡報（slides/QC_Peripheral_Systems_Talk.pptx）

- p20「控制系統架構」：「LO + IQ 混頻器 / 上變頻到 4–8 GHz（外差架構）」「ADC + 下變頻 / 讀取訊號數位化（數 GSa/s）」「FPGA / 序列播放、解調、判別、即時回饋」。
- p21「外差 IQ 混頻 vs 直接射頻合成」：「外差 IQ 混頻 / AWG 產生中頻（~100 MHz）I/Q / LO + 類比 IQ 混頻器上變頻 / 需校正 IQ 不平衡、LO 洩漏、鏡像 / 元件成熟、成本較低」
  「直接射頻合成 / 高速 DAC 直接合成 GHz 訊號 / 數位上變頻（NCO），無類比混頻器 / 免 IQ 校正、通道一致性好 / 近年主流（RFSoC、新一代儀器）」。
  備註：「直接射頻合成：用每秒數十億次的高速 DAC 直接合成 GHz 訊號，在數位端做上變頻，沒有類比混頻器，因此不需要 IQ 校正」。

## 學程筆記（notes/dispersive-readout.md）

- §2.5 第 3 步：「下變頻成 IQ：輸出訊號經過放大、下變頻後，拆成 I（同相）和 Q（正交）兩個分量，在 IQ 平面上就是一個點。」
  第 4 步：「積分：把訊號積分一段時間 τ（約 100 ns–1 μs），每量一次（single shot）得到一個 (I, Q) 點。」第 5 步：「重複幾千次之後，|0⟩ 和 |1⟩ 會形成兩團高斯分布。中間畫一條閾值線」。
- §3 表「多顆位元」列：「頻率多工：每顆位元配一個不同頻率的諧振腔，共用一條饋入線；室溫端用一組 ADC 同時解調多個頻率」。
- §4 讀取鏈：「MXC ─── 環行器/隔離器（2–3 級）← JPA / TWPA」「4 K ─── HEMT 低雜訊放大器」「【室溫】 室溫 LNA（+30~40 dB）→ IQ 混頻器（下變頻，與上變頻共用同一個 LO）→ 濾波 → ADC 數位化 → FPGA（解調、加權積分、閾值判斷、即時回饋）」。
- §4.1 表：「微波訊號源（LO） | 上變頻與下變頻共用同一個 LO，相位才會一致」「AWG/DAC | 產生中頻（IF）讀取脈衝包絡」「IQ 混頻器 | 做上變頻和下變頻；新一代 RFSoC 可以直接數位合成 GHz 訊號，省掉混頻器」。
