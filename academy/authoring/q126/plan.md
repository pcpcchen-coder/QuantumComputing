# Q126 加入雜訊：八個範例在真實世界會怎樣

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第十四課：同一條線路跑理想與有雜訊兩種模擬（qiskit-aer 雜訊模型），看 Bell、GHZ、Grover 的結果怎麼變差。
雜訊模型的三個旋鈕（假設值）：單位元閘去極化 1%、雙位元閘 2%、讀取 3%。錯誤預算（QC_Operation_Talk p47）：做對的機會連乘，閘越多越吃虧；0.3% → 約 230 個雙位元閘剩一半。
觀察：Bell → GHZ → Grover 跑掉的比例依序變大；讀錯一顆最常見，所以 Grover 的錯誤結果 01、10 比 00 多；疊加被打亂還是一半一半（看不出雜訊），隱形傳態的 75% 往 50% 靠攏。
注意事項：雜訊模型是假設，參數要寫清楚；統計誤差不是雜訊；答案還是最高不代表雜訊不重要。
孩子獨立改造：MY_SCALE = 2、4、8 把雜訊一路加倍，找出最先跑掉一半的範例（BV、Grover）；延伸零雜訊外插（p48）。好玩機制「故障注入」，作品是理想 vs 雜訊比較圖，生活技能「理論和現實的差距」。
