# Q020 磁通量子化 Φ₀ = h/2e

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的電子成對、整塊超導體只要一個相位，接到超導環 |
| 10–25 | 概念：磁通是什麼、相位像時鐘指針、繞一圈必須回到原點、磁通只能一格一格、Φ₀ = h/2e、為什麼分母是 2e、地磁場換算一格有多小 |
| 25–65 | 父子共同實作：用繩圈與相位時鐘貼紙，示範繞一圈相位必須回到原點（每張 45° 接得起來、22.5° 接不起來） |
| 65–75 | 休息 |
| 75–105 | 孩子改造：用計算機算出 Φ₀，換算地磁場穿過多大的面積；畫環形相位圖 |
| 105–115 | 孩子教爸爸：相位為什麼回到原點、磁通為什麼一格一格、分母為什麼是 2e |
| 115–120 | 錄音總結、替環形相位圖取名字、保存 |

好玩機制「解鎖成就」：每完成一項（繩圈接得起來、找到接不起來的角度、算出 Φ₀、算出面積、畫完相位圖、教會爸爸 2e）就在說明卡上打勾。
教材：繩圈與相位時鐘貼紙紀錄（列印與 CSV）、環形相位圖、Φ₀ 計算卡、說明卡、解答、可執行的 `flux_scale.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q020/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q020.py`（index.html#jj 的相位鐘；index.html#squid 兩段：磁通箭頭與環流、每隔一個磁通量子回到原樣）。
課綱「需新增：★ 磁通量子化場景」尚未製作；本集借用現有的 JJ 與 SQUID 場景，並在旁白說明 SQUID 環夾有接面、外加磁通可連續調整。
