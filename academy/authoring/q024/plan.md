# Q024 JJ 是非線性電感

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的超導三明治，接到「接面在電路裡像電感」 |
| 10–25 | 概念：接面為什麼像電感、電感隨電流變大、什麼叫非線性、位能多出四次方項讓能階變擠、無耗散又很小、不是線圈那種電感 |
| 25–65 | 父子實作：一公尺單擺，十度與六十度各數十次來回，記下秒數，比較大小角度 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：在 transmon-3d 位能井那一章，找出能階間距開始變小的地方，並和線性電路比較 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替紀錄取名字、保存 |

教材：單擺週期紀錄表、角度卡與計時卡（列印）、能階間距紀錄、說明卡、解答、可執行的 `pendulum_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q024/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q024.py`（transmon-3d.html#junction 拖相位差滑桿看電感變大、lc-vs-jj.html#s5 四次方項、transmon-3d.html#potential 有接面與沒有接面的能階間距）。
