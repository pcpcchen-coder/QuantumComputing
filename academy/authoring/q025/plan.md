# Q025 E_J 與 E_C：兩個能量尺度

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的非線性電感，接到描述電路的兩個能量 |
| 10–25 | 概念：約瑟夫森能量、充電能量、比值決定性格、背景電荷與電荷色散、指數對冪次、比值越大不是越好 |
| 25–65 | 父子實作：在 transmon-3d 大十字電容分頁拉電容滑桿，記錄比值、非諧性與電荷色散，畫成掃描圖 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：訂兩條標準、圈出範圍、挑一個折衷點並說明取捨 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替掃描圖取名字、保存 |

教材：比值掃描記錄表、掃描圖方格紙、折衷點工作單、說明卡（列印）、解答、可執行的 `ejec_scan.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q025/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q025.py`（index.html#potential 一段：電荷色散小圖在比值五十、一、十時的樣子；transmon-3d.html#capacitor 兩段：電容拉到兩百飛法拉、拉到二十飛法拉再回到七十七點五）。
