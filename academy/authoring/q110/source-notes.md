## Lattice surgery（Wikipedia，oldid=1386404961）

- 「In quantum computing, '''lattice surgery''' is a method for executing logical gates between two error-corrected qubits. Lattice surgery introduces the concepts of "merging" and "splitting" logical qubits. Managed properly, these operations can execute a logical CNOT gate between two logical qubits. Originally defined for surface code quantum error correction, the technique was later extended to other codes such as quantum low density parity check (QLDPC) codes.」（連結標記與參考文獻已去除）
- 「However, every surface code is only designed to encode a single qubit. In order to actually do computation, these individual qubits must be able to talk to one another, and that is the purpose of lattice surgery.」
- 「Lattice surgery has been experimentally demonstrated in trapped ions, superconducting qubits, and neutral atoms.」

## Magic state distillation（Wikipedia，oldid=1374675256）

- 「'''Magic state distillation''' is a method for creating more accurate quantum states from multiple noisy ones, which is important for building fault tolerant quantum computers.」
- 「The technique was first proposed by Emanuel Knill in 2004, and further analyzed by Sergey Bravyi and Alexei Kitaev the same year.」
- 「Thanks to the Gottesman–Knill theorem, it is known that some quantum operations (operations in the Clifford group) can be perfectly simulated in polynomial time on a classical computer. In order to achieve universal quantum computation, a quantum computer must be able to perform operations outside this set.」
- 「The Clifford group consists of a set of n-qubit operations generated by the gates {H, S, CNOT} … called Clifford gates.」「This set of gates with a non-Clifford operation is universal for quantum computation.」
- 「A non-Clifford gate can be generated by combining (copies of) magic states with Clifford gates.」

## Gottesman–Knill theorem（Wikipedia，oldid=1354309521）

- 「the '''Gottesman–Knill theorem''' is a theoretical result by Daniel Gottesman and Emanuel Knill that states that stabilizer circuits—circuits that only consist of gates from the normalizer of the qubit Pauli group, also called Clifford group—can be perfectly simulated in polynomial time on a probabilistic classical computer. The Clifford group can be generated solely by using the controlled NOT, Hadamard, and phase gates (CNOT, H and S)」

## Eastin–Knill theorem（Wikipedia，oldid=1353641779）

- 「In other words, no quantum error correcting code can transversely implement a universal gate set that contains only unitary gates, where a transversal logical gate is one that can be implemented on a logical qubit by the independent action of separate physical gates on corresponding physical qubits.」
- 「Transversal gates … can be used to perform fault tolerant but not universal quantum computation because they guarantee that errors don't spread uncontrollably through the computation.」
- 「The theorem is named after Bryan Eastin and Emanuel Knill, who published it in 2009.」
- 繞過方法清單含「Teleportation of gates」「Magic state distillation」。

## Clifford gate（Wikipedia，oldid=1309382074）

- 「Quantum circuits that consist of only Clifford gates can be efficiently simulated with a classical computer due to the Gottesman–Knill theorem.」
- 「The Clifford group is generated by three gates: Hadamard, phase gate S, and CNOT.」「Since all Pauli matrices can be constructed from the phase and Hadamard gates, each Pauli gate is also trivially an element of the Clifford group.」
- 「S = [[1, 0], [0, e^{iπ/2}]] = [[1, 0], [0, i]] = √Z」

## 學程內部文件：docs/超導量子電腦師生對話教學紀錄.md 第 12 課

- 「表面碼解決了「存」，要「算」還得在邏輯位元上做閘：**Clifford 閘**用 lattice surgery，**非 Clifford（T）**靠魔術態。」
- 「最安全的是**橫向閘**（每顆實體位元各做一次），但 **Eastin–Knill 定理**：沒有任何碼能讓一組通用閘全部橫向。」
- 「**Gottesman–Knill 定理**：只有 Clifford 閘＋Pauli 量測的電路，古典可以有效模擬。第 7 章的 Bell、兩位元 Grover、Deutsch 與第 9 章的 BV，**全都只用 Clifford 閘**」「**T = diag(1, e^{iπ/4})**（Z 軸轉 45°）是非 Clifford；Shor 的 QFT 需要拆成很多 H 和 T。**少了 T，就沒有量子優勢。**」
- 「不移動任何位元，只改變「哪些穩定子要量」：1. **合併** … 2. 接縫上新穩定子的量測結果**相乘剛好等於 X_A ⊗ X_B（或 Z_A ⊗ Z_B）** … 3. 維持 **d 輪**防量測錯誤。4. **拆開**：把接縫位元逐一量掉，補 Pauli 修正（記在 Pauli frame）。」「硬體動作仍是表面碼週期（重設、4 層 CZ、中途量測），差別只在打開哪些穩定子。」
- 「**用聯合量測組 CNOT**（輔助補丁 A 準備在 |+⟩）：① 量 Z_控制 ⊗ Z_A；② 量 X_A ⊗ X_目標；③ 量 A 的 Z；④ 依結果補 Pauli。約 2～3d 輪。」
- 「**閘傳送**：準備 |T⟩ = T|+⟩ → lattice surgery 量 Z_資料 ⊗ Z_魔術 → 量魔術態的 X → 一半機率直接得到 T，另一半補一個 S（Clifford）。**T 閘 = 1 顆魔術態 ＋ Clifford 運算。**」
- 「**注入**：把一顆實體位元轉到 |T⟩ 再長大成補丁，錯誤率約 p ≈ 10⁻³，不夠。」「**15-to-1 蒸餾**（Bravyi–Kitaev 2005）：15 顆錯誤率 p 的魔術態，跑只用 Clifford 的電路（來自 [[15, 1, 3]] Reed–Muller 碼），檢查全過才保留，輸出 1 顆、錯誤率約 **35p³**。」表格：「1｜10⁻³｜≈ 3.5×10⁻⁸｜15 顆」「2｜3.5×10⁻⁸｜≈ 10⁻²¹｜225 顆」。
- 「**工廠**：演算法成本常用 T 數或 Toffoli 數衡量，工廠產能決定整體時間。」
- 成本表：「X、Z｜Pauli frame｜幾乎免費」「多位元 Pauli 量測｜lattice surgery｜約 d μs」「CNOT、H、S｜lattice surgery 組合、補丁變形｜數倍 d μs」「**T**｜魔術態＋閘傳送；蒸餾或培育｜**最貴**」。
- 課後練習：「注入錯誤率 p = 10⁻⁴，蒸餾一輪後約多少？」答「35 × (10⁻⁴)³ = 3.5×10⁻¹¹」；「Lattice surgery 合併時為什麼要量 d 輪而不是 1 輪？」答「量測本身也會出錯，需要多輪資料讓解碼器在時間方向上抓錯」。
