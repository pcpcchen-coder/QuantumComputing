# Q100 第 2 課：transmon 怎麼寫入狀態

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 加三段動畫展示（transmon-3d.html #chip、#control、#case 各一）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：學生問怎麼寫入、SQUID 做什麼 |
| 10–25 | 概念：晶片分工、寫入四步、脈衝三個旋鈕、非諧性、SQUID 兩個身分 |
| 25–65 | 送 π 脈衝、比較 π／π/2／不同軸、拖 Z 線磁通；闖關 |
| 65–75 | 休息 |
| 75–105 | 畫「哪條線做什麼」的接線圖（XY／Z 線分工圖） |
| 105–115 | 孩子教爸爸：怎麼寫入、Z 線做什麼 |
| 115–120 | 錄音總結、保存 |

教材：動畫操作步驟、闖關題目、實驗紀錄、分工圖畫框、說明卡、解答（`academy/authoring/q100/classroom.py`）。
