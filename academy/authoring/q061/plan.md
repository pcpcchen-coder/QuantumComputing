# Q061 QFT 與相位估計

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（量子傅立葉轉換線路：operation.html#circuit；一個位元的相位估計：operation.html#interference；梳子變尖峰：operation.html#shor 只到 QFT 那一步）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂動態線路；今天要讀出藏在相位裡的數字 |
| 10–25 | 概念：QFT 是振幅的傅立葉轉換、把數字寫進相位；相位估計四步；看 operation.html#circuit 的 QFT 範例 |
| 25–65 | 父子在本機模擬器做 3、4、5 位元相位估計（θ = 3/8 與 1/3），記錄最多次的 y、換算相位與誤差；玩解鎖成就 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：選不能整除的相位（例如 0.3），畫三種位元數的直方圖，觀察分布 |
| 105–115 | 孩子教爸爸：原理、精度和位元數的關係、QFT 本身不是加速來源 |
| 115–120 | 錄音總結、作品命名、存檔 |

旁白用語：QFT 念「量子傅立葉轉換」、QPE 念「相位估計」、H 念「哈達瑪閘」、CP 念「受控相位閘」、SWAP 念「交換」、Shor 念「秀爾」；投影片保留符號。

教材：精度實驗表、解鎖成就卡、分布記錄表、說明卡、解答、可執行的 qpe_lab.py（純 Python 精確公式，或 Qiskit＋Aer 實跑）（`academy/authoring/q061/classroom.py`）。
