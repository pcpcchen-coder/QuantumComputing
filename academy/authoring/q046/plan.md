# Q046 控制電子與時脈

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從冷凍機回到室溫，看指揮晶片的那一櫃控制儀器 |
| 10–25 | 概念：晶片只聽得懂微波、機櫃裡的四類儀器、外差混頻 vs 直接合成、控制鏈六個站、10 MHz 參考時脈 |
| 25–65 | 人肉控制鏈：全家扮演上傳、觸發、驅動、讀取、判別、回饋六個站，用拍手當時脈傳遞一次測量（硬幣當量子位元） |
| 65–75 | 休息 |
| 75–105 | 一站慢半拍：分別讓驅動、讀取、回饋站出錯；兩個節拍器各打各的；算時間差造成的相位差 |
| 105–115 | 孩子教爸爸：六個站、為什麼要同一個參考時脈、常見誤解 |
| 115–120 | 錄音總結、流程圖命名、存檔 |

教材：控制鏈角色卡、排練紀錄表、控制鏈流程圖底稿、相位計算卡、可執行的 `phase_drift.py`（時間差→相位差、頻率差→相位累積、兩個節拍器的拍差）、說明卡與解答（`academy/authoring/q046/classroom.py`）。

動畫展示段（`academy/authoring/v2/demos_extra/q046.py`）：控制電子場景的機櫃、驅動波形與「直接射頻合成」切換；控制電子場景放慢走一次上傳→觸發→驅動→讀取→判別→回饋→回傳；微波脈衝場景示範第二個脈衝相位差 90° 時結果從一變成一半一半。
