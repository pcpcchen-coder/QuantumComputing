# Q144 畢業專題：替一台量子電腦寫供電規格書

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。144 堂課綱的最後一堂：結尾改為結業祝福，不預告下一堂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：畢業工作坊——把整個模組寫成一份供電規格書 |
| 10–25 | 概念：為什麼要寫成規格書、參考架構（前提）、公開數據 vs 推論 |
| 25–65 | 選平台與位元數（超導 1,000 位元），寫用電、備援、接地、磁場、熱預算五章；審查委員逐個數字追問 |
| 65–75 | 休息 |
| 75–105 | 加第六章「文獻缺口與我們的機會」 |
| 105–115 | 孩子教爸爸：五章各在回答什麼、章與章怎麼互相牽動 |
| 115–120 | 錄音總結、作品命名、存檔 |

動畫展示段（v2）：全景讀三個總數字＋痛點 2＋運算不接 UPS（第 6 頁後）；全景痛點 3、6、5 對接地、磁場、熱預算三章（第 8 頁後）；開發計畫第 ① 項困難表與綠框（第 10 頁後）。

教材：規格書模板（五章＋第六章，每章欄位與「公開數據／推論」來源欄）、參考答案範例、審查追問卡、文獻缺口工作單、說明卡與解答（`academy/authoring/q144/classroom.py`）。
