# Q019 Cooper pair 與能隙

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的零電阻與磁鐵懸浮往裡看，電子為什麼會成對 |
| 10–25 | 概念：晶格與電子、晶格扭曲四步、Cooper pair 的特徵、能隙保護什麼、鋁的能量尺度、臨界溫度與 10 mK |
| 25–65 | 角色扮演：全家當人肉晶格，一人走過時大家靠近，讓第二個人被「吸」過來；再演有能隙與沒能隙的小擾動 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：畫能隙示意圖，比較有能隙與沒能隙時小擾動造成的差別，標出三個能量 |
| 105–115 | 孩子教爸爸：電子為什麼成對、能隙保護什麼 |
| 115–120 | 錄音總結、替示意圖取名字、保存 |

教材：人肉晶格劇本與觀察紀錄（列印與 CSV）、能隙示意圖、能量尺度卡、說明卡、解答、可執行的 `gap_scale.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q019/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q019.py`（index.html#cooper 三段：超導態的電子對、切到正常態看能隙消失、拖溫度滑桿看電阻與配對比例）。
