# Q027 SQUID：用磁場轉頻率

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂洗衣板的偏壓電流，接到磁場這個新旋鈕 |
| 10–25 | 概念：兩個接面並聯成環、兩條路的干涉、磁通 → 約瑟夫森能量 → 頻率、磁通控制線、甜蜜點、可調的代價 |
| 25–65 | 父子實作：在 index.html#squid 闖關調到指定頻率，記點畫調頻曲線，找出甜蜜點 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：拉接面不對稱度，比較對稱與不對稱 SQUID 的調頻範圍與磁通敏感度 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替調頻曲線取名字、保存 |

教材：調頻闖關記錄表、調頻曲線方格紙、對稱與不對稱比較工作單、說明卡（列印）、解答、可執行的 `squid_tuning.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q027/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q027.py`（index.html#squid 三段：闖關調到 5.5 GHz、找甜蜜點與磁通敏感度、拉接面不對稱度看曲線變平）。
這是依課綱製作的課前教學版，不是實際上課錄音。
