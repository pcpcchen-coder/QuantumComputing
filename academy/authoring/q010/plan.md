# Q010 第一個量子程式：貝爾態

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：把線路寫成程式 |
| 10–25 | 概念：模擬器、貝爾態線路四格、兩枚硬幣 vs 貝爾態 |
| 25–65 | 寫程式、跑模擬器 1024 次（或瀏覽器動畫 1,000 次）、截圖並解釋（程式員與成就官） |
| 65–75 | 休息 |
| 75–105 | 改出另一種貝爾態，記錄直方圖差異 |
| 105–115 | 孩子教爸爸：操作與為什麼只有 00、11 |
| 115–120 | 錄音總結、保存 |

教材：可執行的 `bell_simulator.py`（本機模擬器，不需帳號）、成就卡、直方圖格、四種貝爾態改造表、說明卡、解答（`academy/authoring/q010/classroom.py`）。
