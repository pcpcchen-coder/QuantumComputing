## animations/js/operation/08_interference.js

- 「φ = 0 時通往 |1⟩ 的兩支箭頭方向相反 → 抵消，結果 100% 是 0；φ = 180° 時反過來。」
- 「若中途「偷看」走哪一條路（測量），干涉消失，變成 50/50。」
- 控制項：`ui.slider('A：相位 φ', 0, 360, 1, phi, …)`、`ui.toggle('A：自動掃描 φ', false, …)`、`ui.toggle('A：中途偵測路徑（破壞干涉）', false, …)`
- 插圖：`'結果 P(0) 與 φ 的關係（干涉條紋）'`；紅虛線 0.5；`P.dot(g, X(phi), Y(which ? 0.5 : Math.cos((phi * Math.PI) / 360) ** 2), 5, '#fff')`
- `s.visible = !which;`（白色總和箭頭）、`eye.visible = which;`（發紅光小球，位置 (-1, 0, 0.3)）
