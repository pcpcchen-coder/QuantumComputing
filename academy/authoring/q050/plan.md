# Q050 初始化與校準

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（重設的時間軸與主動重設、微波脈衝的面積與失諧、啟動與校準的量測圖）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：每一輪怎麼歸零？閘怎麼轉對角度？ |
| 10–25 | 概念：被動重置 vs 主動重置；九步校準分四關 |
| 25–65 | 闖關：孩子（校準工程師）排九張校準卡並寫下每步調好什麼，爸爸（關主）抽問理由 |
| 65–75 | 休息 |
| 75–105 | 拿掉一張卡，預測哪個結果會出錯，再用動畫驗證 |
| 105–115 | 孩子教爸爸：兩種重置與九步順序 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：九張校準卡（剪貼）、校準流程卡、重置比較表、少一步會怎樣預測卡、說明卡、解答、可執行的 reset_budget.py（`academy/authoring/q050/classroom.py`）。
