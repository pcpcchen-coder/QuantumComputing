# Q102 頻率配置與頻率碰撞

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從「頻率要錯開」到「錯開多少」 |
| 10–25 | 概念：三個物理原因、鄰居的五個禁區、棋盤格 vs 各有地址 |
| 25–65 | 替三顆位元排頻率，在 transmon-3d#case 自由實驗檢查（排頻師與頭目） |
| 65–75 | 休息 |
| 75–105 | 紙上挑戰五顆位元，禁區表＋碰撞檢查程式驗收 |
| 105–115 | 孩子教爸爸：怎麼排、為什麼會撞 |
| 115–120 | 錄音總結、保存 |

教材：可執行的 `collision_checker.py`（Python 標準函式庫，不需安裝套件、不需帳號）、禁區計算卡、三顆配置表、五顆挑戰表、說明卡、解答（`academy/authoring/q102/classroom.py`）。
