# Q005 相位：看不見卻最重要

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：兩支測起來一樣的箭頭 |
| 10–25 | 概念：同樣機率不同相位、相位翻轉閘、先轉再量 |
| 25–65 | 盲測：爸爸偷偷加或不加 Z，孩子只用 H 加測量破案（出題者與偵探） |
| 65–75 | 休息 |
| 75–105 | 設計兩步的關卡：把 Z 拆成兩個 S |
| 105–115 | 孩子教爸爸：為什麼直接測量看不到相位 |
| 115–120 | 錄音總結、保存 |

教材：盲測規則、相位猜猜看紀錄表、兩步關卡設計單、解答與閘對照表（`academy/authoring/q005/classroom.py`）。
