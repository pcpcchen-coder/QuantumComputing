# Q095 畢業專題製作

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 加一段動畫展示（operation.html#workflow ×1，插在第 6 頁「驗證：先預測再對答案」之後）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：怎麼做出來、怎麼證明是對的 |
| 10–25 | 概念：每天一個可展示版本、一天四步、先預測再對答案 |
| 25–65 | 依提案製作，收工前留下能展示的版本 |
| 65–75 | 休息 |
| 75–105 | 加一個測試或驗證，故意弄錯看測試抓不抓得到 |
| 105–115 | 展示日：孩子教爸爸操作與原理 |
| 115–120 | 錄音總結、保存 |

教材：每日版本紀錄、先預測再對答案的驗證表、展示日評審卡與素材來源表、說明卡、解答（`academy/authoring/q095/classroom.py`）。
