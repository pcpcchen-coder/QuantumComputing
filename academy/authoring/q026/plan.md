# Q026 傾斜洗衣板

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的兩個能量，接到傾斜的洗衣板 |
| 10–25 | 概念：電阻電容分路接面模型、相位粒子困在山谷（零電壓態、電漿頻率、位障）、超過臨界電流出現電壓、遲滯與回捕電流、電流電壓曲線、相位粒子只是類比 |
| 25–65 | 父子實作：在 index.html#washboard 一格一格推偏壓電流，記錄小球何時滑出；用彈珠與波浪紙板模擬 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：推過 1 再慢慢往回調，記下停住的電流，用速度、摩擦、山谷解釋遲滯 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替觀察紀錄取名字、保存 |

教材：洗衣板觀察紀錄（往上推）、往回調紀錄與彈珠實驗、遲滯解釋工作單、說明卡（列印）、解答、可執行的 `washboard_sim.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q026/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q026.py`（index.html#washboard 三段：偏壓電流 0.30 → 0.90 時位障變矮、仍是零電壓態；推到 1.10 再降到 0.50、0.10、加回 0.50 的遲滯；掃描按鈕畫出電流電壓曲線）。
這是依課綱製作的課前教學版，不是實際上課錄音。
