# Q014 量子態很怕吵：雜訊與退相干

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從沒有雜訊的理想動畫到真實世界 |
| 10–25 | 概念：資訊漏到環境、布洛赫球上箭頭變短、能量弛豫（T1）和失相（T2）、為什麼要冷到 10 mK、冷不是為了跑更快 |
| 25–65 | 一起做雜訊卡：每張寫一種干擾、畫出箭頭怎麼變；玩故障卡，抽卡後用 index.html#bloch 的 T1、Ramsey 模式對照 |
| 65–75 | 休息 |
| 75–105 | 孩子設計防雜訊方法卡：選一種雜訊、想一個擋法、寫清楚擋住哪一種 |
| 105–115 | 孩子教爸爸：兩種壞法、為什麼要冷、一個限制 |
| 115–120 | 錄音總結、作品命名、保存 |

教材：雜訊卡空白卡、故障卡遊戲紀錄、防雜訊方法卡設計頁、說明卡、解答、可執行的 `noise_numbers.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q014/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q014.py`（index.html#bloch 三段：一態掉回零態、箭頭在赤道上縮短、用動畫對照雜訊卡）。
