# Q011 隱形傳態：傳狀態不傳東西

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從貝爾態到隱形傳態 |
| 10–25 | 概念：三個角色、四步線路、為什麼要打電話、不能超光速、不可複製 |
| 25–65 | 三人角色扮演（愛麗絲、鮑伯、信差），照線路一步一步傳送；最後一回合「信差迷路」 |
| 65–75 | 休息 |
| 75–105 | 畫六格傳送漫畫，圈出一定要打電話的那一格 |
| 105–115 | 孩子教爸爸：需要什麼、傳了什麼、限制 |
| 115–120 | 錄音總結、保存 |

教材：名牌、祕密狀態卡（時鐘箭頭）、鮑伯的四個信封與修正表、傳送任務板、六格漫畫格、說明卡、解答、動畫導覽（`academy/authoring/q011/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q011.py`（basic-circuits.html#teleport 兩段、operation.html#circuit 一段）。
