# Q094 畢業專題提案

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 加一段動畫展示（operation.html#grover ×1，作為範例專題的驗收示範）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從學生變成提案人 |
| 10–25 | 概念：一頁提案的五個格子、成功標準三特點、縮小範圍 |
| 25–65 | 寫一頁提案、五分鐘簡報、產品評審 |
| 65–75 | 休息 |
| 75–105 | 依回饋修改，縮小範圍到兩週做得完 |
| 105–115 | 孩子教爸爸：提案怎麼寫、成功標準怎麼訂 |
| 115–120 | 錄音總結、保存 |

教材：一頁提案模板、範例提案、產品評審表、兩週計畫、說明卡、解答（`academy/authoring/q094/classroom.py`）。
