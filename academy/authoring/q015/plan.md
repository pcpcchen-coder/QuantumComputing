# Q015 迷你專案：量子逃脫室

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從雜訊到逃脫室，五個概念串起來 |
| 10–25 | 概念：關卡設計表五格、示範關卡書（斜斜的箭頭、兩條路、雙胞胎、十六個抽屜）、好關卡的三條規則 |
| 25–65 | 魔王戰：父子各設計兩關、填關卡設計表、交換破關；出題的人當關主 |
| 65–75 | 休息 |
| 75–105 | 孩子設計魔王關：兩個概念才能破，自己先在動畫裡破一次 |
| 105–115 | 孩子教爸爸：每一關的概念、操作、原理 |
| 115–120 | 錄音總結、替關卡書取名字、保存 |

教材：關卡設計表（列印與 CSV）、示範關卡書、魔王關設計與試玩紀錄、說明卡、解答、可執行的 `escape_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q015/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q015.py`（operation.html 三段：#qubit 第一關驗證、#register 第三關驗證、#gates 魔王關驗證）。
