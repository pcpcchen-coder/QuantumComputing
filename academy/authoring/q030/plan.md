# Q030 晶片長什麼樣子

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂做出的約瑟夫森接面拉遠，看整張晶片 |
| 10–25 | 概念：十字電容板與 SQUID、XY 驅動線與 Z 磁通線、讀取腔與饋線、頻率多工、頻率間隔、示意圖的限制 |
| 25–65 | 父子實作：紙本晶片圖尋寶，五色圈出量子位元、讀取腔、饋線、兩條控制線並寫用途，再用 3D 動畫對照 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：設計一條饋線串四個讀取腔的頻率表（6–8 GHz、相鄰至少 50 MHz），用 freq_plan.py 檢查 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替晶片圖取名字、保存 |

教材：晶片尋寶圖（列印）、元件用途表、頻率表工作單、說明卡、解答、可執行的 `freq_plan.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q030/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q030.py`（transmon-3d.html#chip 一顆量子位元的地圖；index.html#chip 四顆量子位元共用饋線、放大第二號；穿透頻譜四個凹陷與切換第二號）。
注意：晶片圖與動畫都是示意，不按比例；真實佈局尺寸與元件數依廠商而不同。
這是依課綱製作的課前教學版，不是實際上課錄音。
