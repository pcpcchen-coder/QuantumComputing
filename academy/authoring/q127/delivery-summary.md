這是依課綱製作的課前教學版，不是實際上課錄音。

父子科技學院量子電腦學程第一百二十七堂：專題——設計自己的線路。跑過八個範例之後，換孩子當設計師：用學過的閘設計一條能說明一個概念的線路，先寫目標、畫線路、寫下預測，再用模擬器驗證，最後做一個「故意出錯」的版本，說明差在哪裡。

這一集會學到
・專題四步：目標 → 線路 → 預測（先寫再跑）→ 模擬器驗證
・從目標反推設計：先決定證據，再挑閘
・工具箱：哈達瑪閘、翻轉閘、相位翻轉閘、四分之一圈與八分之一圈相位閘、受控反閘、受控相位翻轉閘
・範例甲：四個八分之一圈相位閘等於一個相位翻轉閘
・範例乙：不用受控反閘，用受控相位翻轉閘做出貝爾態
・故意出錯：少一個閘，干涉就沒有完全抵消；先寫預測，避免看結果才找理由

主要來源：維基百科 Quantum logic gate、HARKing、Backward design；本學程「如何操作量子電腦」簡報第 18、22、28、52 頁，以及 operation.html 場景 4「多量子位元與糾纏」、場景 6「量子線路」互動動畫；本機 Python 與 Qiskit 2.6.2、qiskit-aer 0.18.4 實跑紀錄。

教材用法（classroom.zip）
先讀「00_爸爸先讀」，照「01_操作步驟」在 operation.html#register 用按鈕組範例甲、乙，再執行 my_circuit.py（或開 專題模板.ipynb，需 pip install qiskit qiskit-aer），把自己的目標、線路、預測填進專題模板；下半場做故意出錯版並寫差別說明。沒有 Qiskit 時用 tiny_sim.py（只要 Python 3）。課堂 120 分鐘另計。
