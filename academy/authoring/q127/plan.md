# Q127 專題：設計自己的線路

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第十五課：用學過的閘設計一條能說明一個概念的線路，並在模擬器驗證。
專題四步：目標 → 線路 → 預測（先寫、寫好不改）→ 模擬器驗證；生活技能「從目標反推設計」（目標 → 證據 → 挑閘）。
工具箱（QC_Operation_Talk p18、p22）：H、X、Z、S（S² = Z）、T（T² = S）、CNOT、CZ（對稱）。
範例甲：H、T×4、H → 1 = 100%（T⁴ = Z，HZH = X）。範例乙：H H、CZ、q0 再 H → 00、11 各 50%（CNOT = (I⊗H)·CZ·(I⊗H)）。
故意出錯：只放三個 T → 0 14.6%、1 85.4%；忘了最後的 H → 四種各 25%（糾纏還在只是量不出來）。
注意事項：先寫預測再跑，避免看結果才找理由（事後假設，HARKing）。好玩機制「Maker 挑戰」（旁白念創客挑戰），作品是自己的線路與驗證報告。
