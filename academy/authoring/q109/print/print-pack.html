三個容易錯的地方

  • 以為表面碼會量資料位元：其實只量相鄰位元的奇偶，疊加不被破壞
  • 以為碼距越大一定越好：前提是實體錯誤率低於門檻（真實電路約 1%）
  • 以為 d = 3 能修所有錯誤：只保證修 1 個，兩個錯誤就可能騙過解碼器

數一數

d = 3：＿＿ 顆資料 + ＿＿ 顆量測 = ＿＿ 顆　　d = 5：2d² − 1 = ＿＿ 顆，最多修 ＿＿ 個錯誤

一個週期：重設 → ＿＿ 層 CZ → 量測；青色格子的順序：左上 → ＿＿ → ＿＿ → 右下

解碼器的原則：□ 錯誤最多的解釋　□ 總路徑最短（最少錯誤）的解釋
