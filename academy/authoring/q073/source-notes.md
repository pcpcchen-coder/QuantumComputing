## 離子阱與中性原子量子電腦（slides/Ion_NeutralAtom_Talk.pptx）

第 24 頁「從原子氣體到冷原子：磁光阱（MOT）」
- 「3D MOT ~100 μK 原子雲」「裝進光鑷 單顆原子」
- 「真空 ~10⁻¹¹ mbar：原子在光鑷中可存活數十秒～分鐘（Caltech 2025：~23 分鐘）」

第 25 頁「光鑷：用聚焦雷射抓住單顆原子」
- 「碰撞阻斷：一格只會有 0 或 1 顆」
- 「光鑷很小，兩顆原子進去會在光照下碰撞、一起被踢出」「結果：每格隨機 約 50 % 有一顆原子」
- 表格：SLM「在相位上『畫』出整個光鑷圖案」「慢（~10 ms 換圖）」「靜態陣列（儲存）」；AOD「RF 頻率 → 光的偏折角度」「快（μs 級），可平滑移動」「搬運原子、重排、分區架構」
- 「一台光鑷系統 = SLM 做『停車格』 + AOD 做『搬運車』；光鑷雷射常需數十瓦。」

第 26 頁「裝載、成像與重排：做出無缺陷陣列」
- 「① 裝載：從 MOT 裝進光鑷，每格 ~50 %」
- 「② 成像：拍一張螢光照片（~10 ms），知道哪些格有原子」
- 「③ 重排：FPGA 算路徑，AOD 把原子搬到目標區（數十 ms）」
- 「④ 再成像確認 → 開始計算」
- 「不重排：100 顆全部到位的機率是 0.5¹⁰⁰ ≈ 10⁻³⁰；重排後幾乎每次成功 —— 這是 2016 年後陣列快速變大的關鍵。」

## animations/js/atoms/08_tweezer.js

- subtitle：「每支光鑷只有約一半機率抓到原子；拍照找出空位，再用移動光鑷把原子搬過去」
- desc：「光鑷太小，兩顆原子會因光誘發碰撞一起被踢出（碰撞阻斷），所以每支光鑷最後是 0 或 1 顆，機率約 50–60 %。」
- desc：「FPGA 在毫秒內算出搬運路徑，AOD 產生的移動光鑷（洋紅色）沿光鑷之間的『通道』把儲備區的原子搬到目標區空位。」
- desc：「Caltech 2025 年做出 6100 顆原子的陣列，相干時間 12.6 s。大型陣列還要連續補充原子來彌補真空碰撞造成的損失。」
- `let T = 6, p = 0.5, G = T + 4;`；目標區偏移 `(G - T) / 2`
- plan()：空位 `sort((a, b) => a.P.distanceTo(center) - b.P.distanceTo(center))`；儲備原子取 `Math.abs(r.i - e.i) + Math.abs(r.j - e.j)` 最小；路徑「先斜移半格到通道，再水平、垂直，最後放進目標」
- 每次搬運 `mt += dt / 0.9`（約 0.9 s）；legend「FPGA 規劃 N 次搬運 → AOD 移動光鑷逐一搬運（實際約數十 μs–1 ms / 次，可多支並行）」
- 完成：「完成：T×T 無缺陷陣列（n 次搬運）」；不足：「原子不夠：目標區還缺 k 顆 → 需要更大的儲備區或重新裝載」
- 控制項：`ui.button('① 裝載')`、`'② 成像'`、`'③ 重排'`、`'全部重來'`；`ui.slider('陣列大小（目標 T×T）', 4, 8, 1, …)`；`ui.slider('裝載機率 p', 0.4, 0.7, 0.05, …)`
- 插圖「目標區全部填滿的機率（log₁₀）」：紅線 `n * log10(p)`（下限 −30），綠線 (√N+4)² 支光鑷中至少 N 顆的二項分佈尾端機率
