## animations/js/atoms/12_imaging.js

- 「推出（push-out）：用與 |1⟩（F=2）共振的光把 |1⟩ 的原子推出光鑷，|0⟩（F=1）不受影響。」
- 「成像：開 780 nm 冷卻光，留下的原子不斷散射光子；高 NA 物鏡收集約 1–5 % 的光子，送到 sCMOS / EMCCD 相機。」
- 「每個光鑷位置的像素光子數超過閾值 → 判為『有原子』= |0⟩。」
- 「曝光約 1–20 ms；保真度 > 99 %（Caltech 2025：成像保真度 > 99.99 %、成像後存活率 99.99 %）。」
- 「原子損失會被讀成『沒有亮點』→ 誤判為 |1⟩。」
- 「雙原子種類（例如 Rb 當資料位元、Cs 當輔助位元，讀取光互不干擾）」
- 模型：`bright = 3.0 * expo`、`dark = 0.12 * expo + 0.6`；`statsCalc()` 選使兩種錯誤平均最小的閾值；成像中示意損失 1%
- 控制項：`ui.button('準備隨機態' / '① 推出 |1⟩' / '② 成像' / '重置')`、`ui.slider('曝光時間 (ms)', 1, 20, 1, 10)`、`ui.toggle('非破壞讀取（另一種做法）')`
