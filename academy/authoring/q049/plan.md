# Q049 一次量子計算的生命週期

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（跟著工作走六站、時間預算插圖、四十奈秒的翻轉閘與零時間的虛擬相位轉動）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從使用者角度送出一個工作 |
| 10–25 | 概念：六站（程式 → 轉譯 → 脈衝 → 控制電子 → shots → 結果）與每站耗時；一個 shot＝重置、閘、讀取 |
| 25–65 | 時間機器：孩子當駕駛員在 `operation.html#workflow` 一站一站走，爸爸當計時員填時間預算表、換算放慢一百萬倍後的時間 |
| 65–75 | 休息 |
| 75–105 | 找出最慢的一站，提出縮短方法（主動重置、打包工作、調整 shots），用預算表算省下多少 |
| 105–115 | 孩子教爸爸：六站順序、哪一站最花時間、常見誤解 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：時間預算表（六站＋看不見的等待）、時間機器換算尺、瓶頸改造卡、說明卡與最後一關、可執行的 time_budget.py、解答（`academy/authoring/q049/classroom.py`）。
