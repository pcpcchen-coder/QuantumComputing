# Q013 格羅弗搜尋：16 個抽屜找寶藏

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從一次看穿到尋寶 |
| 10–25 | 概念：古典一個一個翻、振幅柱子、一輪兩步（標記＋擴散）、一輪一輪的機率、為什麼約 √N、轉太多反而變差 |
| 25–65 | 尋寶比賽：16 個信封，隨機隊一個一個翻、量子隊用動畫做三輪再測量；量子隊再故意做四輪、五輪 |
| 65–75 | 休息 |
| 75–105 | 改成 64 個抽屜：先用口訣預測最好的輪數，再用動畫（或 grover_rounds.py）驗證 |
| 105–115 | 孩子教爸爸：一輪兩步、為什麼三輪最好、限制 |
| 115–120 | 錄音總結、作品命名、保存 |

教材：尋寶比賽規則與預測、尋寶比賽結果表、64 個抽屜改造表、說明卡、解答、可執行的 `grover_rounds.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q013/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q013.py`（operation.html#grover 三段：一輪兩步、轉過頭、64 個抽屜）。
