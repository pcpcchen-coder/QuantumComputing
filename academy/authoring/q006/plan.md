# Q006 干涉：波可以互相抵消

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：看不見的相位怎麼變成亮和暗 |
| 10–25 | 概念：水波相加、雙狹縫、振幅相加而不是機率相加 |
| 25–65 | 實驗一水盆兩支筆點水（拍照）＋實驗二 3D 場景兩條路徑（實驗員與安全官；光源由家長操作） |
| 65–75 | 休息 |
| 75–105 | 改變路徑相位，先預測出口零變亮或變暗，再用 3D 場景驗證 |
| 105–115 | 孩子教爸爸：為什麼波可以互相抵消 |
| 115–120 | 錄音總結、作品命名、保存 |

教材：實驗步驟、水盆觀察與照片說明頁、光源安全卡、3D 場景相位預測表、亮暗曲線格、解答（`academy/authoring/q006/classroom.py`）。
