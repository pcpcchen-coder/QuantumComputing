# Q116 範例 3：Bell 態——四種糾纏

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第四課，八個範例的範例 3：|00⟩ → H（q0）→ CNOT（q0 → q1），CNOT 不改柱子高度，只把 |01⟩ 那根搬到 |11⟩，得到 Φ⁺；同一條線路開頭先加 X(q0)、X(q1) 或兩個都加，就得到 Φ⁻、Ψ⁺、Ψ⁻（X(q0) 再 H 等於 H 再 Z(q0)，所以也可說只差開頭的 X 與 Z）。Φ 永遠相同、Ψ 永遠相反，負號直接量測看不出；單看任何一顆，Bloch 向量都縮到球心——那是糾纏，不是位元壞掉。用「解鎖成就」收集四種，作品是 Bell 態圖鑑。
