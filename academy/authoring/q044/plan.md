# Q044 降溫一次要幾天

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：裝好晶片之後要等多久 |
| 10–25 | 概念：降溫四步（抽真空、預冷、凝結、循環）與典型時間；升溫也要一到兩天 |
| 25–65 | 父子共同實作：用時間機器（動畫時間滑桿）排出降溫時間軸，標出每一步在等什麼（時光旅人與值班工程師） |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：規劃換一次樣品的完整時程（升溫＋開罐＋降溫＋校準）；加碼：停電情境 |
| 105–115 | 孩子教爸爸：四步、為什麼預冷最久、一個限制 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：時間機器任務卡、降溫時間軸格（0–36 小時）、換樣品時程規劃表、說明卡與最後一關、解答（`academy/authoring/q044/classroom.py`）。
