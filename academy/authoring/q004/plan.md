# Q004 量子閘就是轉箭頭

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：怎麼把箭頭轉到想要的方向 |
| 10–25 | 概念：量子閘就是旋轉；X 繞前後軸、H 繞斜軸、Z 繞直立軸；閘可逆、測量不可逆 |
| 25–65 | 父子闖六關：用最少的閘，把箭頭從北極轉到指定方向（關主與挑戰者） |
| 65–75 | 休息 |
| 75–105 | 孩子當關主：出兩關給爸爸破，並寫參考解 |
| 105–115 | 孩子教爸爸：三種閘怎麼轉 |
| 115–120 | 錄音總結、保存 |
