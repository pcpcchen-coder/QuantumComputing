# Q042 脈衝管與壓縮機

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從 10 mK 回到第一段降溫 |
| 10–25 | 概念：壓縮變熱、膨脹變冷、蓄冷器；四個零件；一個循環的三步；兩級冷端 |
| 25–65 | 打氣筒（壓縮變熱）與除塵罐（膨脹變冷，家長操作）實驗、寫實驗紀錄、對照脈衝管動畫 |
| 65–75 | 休息 |
| 75–105 | 孩子獨立解釋：為什麼冷端沒有會動的零件是一個優點 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、作品命名、保存 |

教材：安全須知與預測卡、實驗紀錄表、脈衝管循環對照圖與電費帳計算、解說卡與最後一關檢核（`academy/authoring/q042/classroom.py`）。
安全：除塵罐只能正放、由家長操作、不對人噴；倒置會噴出極冷液體，可能凍傷。
