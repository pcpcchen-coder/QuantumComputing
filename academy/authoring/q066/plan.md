# Q066 Paul 阱：旋轉鞍形電場

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；
v2 動畫展示 3 段，都用 atoms.html#paul（翻面的鞍形：射頻開關；翻轉參數的界線：0.40 → 0.95 → 0.70；線性保羅阱：射頻頻率 30 → 50 MHz）。
atoms.html#ionsys 留給 Q067 系統全景。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂真的原子；怎麼把一顆離子抓在真空中間 |
| 10–25 | 概念示範：恩紹定理（固定電場只有鞍點）、保羅的解法（射頻讓鞍形翻面、平均成碗）、翻轉參數 q < 0.908 |
| 25–65 | 父子共同實作：旋轉鞍面滾球（轉盤＋鞍形紙板），不轉／慢轉／快轉各三次，先預測再錄影，填實驗紀錄表 |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：在 atoms.html#paul 從 q = 0.10 起每次加 0.05，記錄標籤與軌跡圖，找出界線（0.90 穩定、0.95 不穩定）；關掉射頻看看 |
| 105–115 | 孩子教爸爸：為什麼固定電場抓不住、翻面怎麼平均成碗、轉速為什麼要合適 |
| 115–120 | 錄音總結、替鞍面實驗影片命名、存檔 |
