# Q038 讀取鏈：衰減、環行器、放大器

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂「一個點算 0 還是 1」接到「讀取微波怎麼下去、怎麼回來」，闖關任務 |
| 10–25 | 概念：冷凍機的溫層與兩條線、熱光子（7 GHz：300 K ≈ 890、10 mK ≈ 10⁻¹⁵）、輸入線層層衰減（4 K、100 mK、10 mK 各 −20 dB）、分貝與 0.0009 個熱光子、輸出線環行器與放大器順序（量子極限放大器 → HEMT → 室溫）；常見誤解（衰減是浪費訊號？） |
| 25–65 | 父子實作：index.html#fridge，從室溫沿輸入線往下、沿輸出線往上，每個元件一關，畫讀取鏈接線圖並寫上目的 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：算出 300 K 熱雜訊經過三個衰減器後剩幾個熱光子；挑戰只放兩個衰減器 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替讀取鏈接線圖取名字、保存 |

教材：讀取鏈接線圖（闖關卡）、熱光子計算表、分貝練習單、說明卡（列印）、解答、可執行的 `thermal_photons.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q038/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q038.py`（輸入線一層一層衰減、訊號功率的山谷、輸出線先隔離再放大：三段都用 index.html#fridge）。
