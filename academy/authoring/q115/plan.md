# Q115 範例 2：干涉——H‑Z‑H = X

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第三課，八個範例的範例 2：|0⟩ → H → Z → H 一步一步看振幅，Z 只給 |1⟩ 加負號、機率不變，第二個 H 讓到 |0⟩ 的兩條路徑 +½、−½ 抵消、到 |1⟩ 的 +½、+½ 加強，結果 100% 是 1（H·Z·H = X）；拿掉 Z 則 H·H 回到 100% 的 0。用「科學實驗」只改一個變因比較，作品是路徑加總表，核心誤解是「干涉發生在振幅，不是機率」。
