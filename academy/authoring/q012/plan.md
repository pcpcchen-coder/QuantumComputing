# Q012 多伊奇–喬薩：一次看穿

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從隱形傳態到黑盒子偵探 |
| 10–25 | 概念：常數與平衡的保證、古典最壞翻五張、量子三步、八支箭頭的干涉 |
| 25–65 | 爸爸出題、孩子翻牌判案；每案再用干涉場景看量子一次判定（出題人與偵探） |
| 65–75 | 休息 |
| 75–105 | 設計三位元平衡函數：填八格、畫箭頭、和內建平衡函數比較、dj_check.py 驗證 |
| 105–115 | 孩子教爸爸：問題、原理、限制 |
| 115–120 | 錄音總結、保存 |

教材：八張函數卡與出題單、判案紀錄、平衡函數設計單、說明卡、解答、判案小程式 `dj_check.py`（只用 Python 內建功能）、動畫導覽（`academy/authoring/q012/classroom.py`）。
