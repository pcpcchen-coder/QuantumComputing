# Q012 事實查核

查核日：2026-11-18。查核者：製作代理（Claude）。逐字引文見 `source-notes.md`。
方法：維基百科 Deutsch–Jozsa algorithm（英文）與多伊奇-喬薩演算法（中文）由製作代理直接開啟並摘錄；學程簡報（如何操作量子電腦 p39、《量子金魚》008 p5–25、量子電路入門 p18–20）的文字與講者備註、三個互動動畫的程式由製作代理讀取；機率由製作代理實際執行 `dj_check.py`（Python 3.13，只用標準函式庫）。
限制：本集只用紙卡、瀏覽器動畫與純 Python 計算，不連雲端、不用帳號；未錄影試拍。
