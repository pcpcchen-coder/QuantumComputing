# Q003 一看就變：測量與重複次數

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：測量時會發生什麼 |
| 10–25 | 概念：只得到零或一、塌縮、重複次數與誤差 |
| 25–65 | 實驗一擲硬幣 100 次＋實驗二 3D 場景跑 1000 次（實驗員與檢查員） |
| 65–75 | 休息 |
| 75–105 | 自己選三個角度，每個跑 1000 次，畫角度與比例圖 |
| 105–115 | 孩子教爸爸：為什麼要重複很多次 |
| 115–120 | 錄音總結、保存 |

教材：實驗步驟、擲硬幣正字紀錄與長條圖格、3D 場景紀錄表、三角度實驗與折線圖格、誤差表與解答（`academy/authoring/q003/classroom.py`）。
