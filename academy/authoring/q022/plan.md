# Q022 量子諧振子：等距的梯子

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的 LC 電路走到量子，今天的三關 |
| 10–25 | 概念：能階與零點能、等距的梯子（每階約 5 GHz）、量子位元只要兩階、一路往上爬、常見誤會（等距不是高低）、解法預告（不等距梯子） |
| 25–65 | 父子實作：在能階場景切到 LC 模式，抄下每一階的間距；畫等距梯子圖，用箭頭畫出一路往上爬 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：畫出不等距梯子（例 4.74、4.45、4.13 GHz），說明為什麼能只在 0 與 1 之間跳 |
| 105–115 | 孩子教爸爸：怎麼操作場景、為什麼等距不能用 |
| 115–120 | 錄音總結、替梯子圖取名字、保存 |

教材：間距紀錄表（列印與 CSV）、能階梯子圖、不等距梯子改造卡、說明卡、解答、可執行的 `ladder_table.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q022/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q022.py`（index.html#potential 切到 LC 模式看等距間距並換大電感；lc-vs-jj.html #s4 一路往上爬；#s3 拋物線對餘弦、滑桿拉到 80）。
