# Q134 接地與共模：上百台儀器一起漏電

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：偵探辦案——量子位元的偏壓在抖，嫌疑犯藏在地線裡 |
| 10–25 | 概念：三條電流路徑（Y 電容、同軸屏蔽、隔離電容）、共模電流的四站、100 vs 1,000 位元、三種接地拓樸 |
| 25–65 | 在 `power1000.html#ground` 增加儀器數，記錄地線電流、地電位差、共模尖峰；爸爸當證人提供線索 |
| 65–75 | 休息 |
| 75–105 | 提出一種接地拓樸改善方案，畫進比較圖並寫出取捨 |
| 105–115 | 孩子教爸爸：為什麼儀器越多，地電位差越大；單點接地的限制 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：接地拓樸比較圖底稿、儀器數記錄表、證人線索卡、說明卡、解答（`academy/authoring/q134/classroom.py`）。
