# Q059 shots、統計誤差與讀取誤差緩解

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（四倍次數誤差減半、校準就是先考儀器、打開讀取誤差緩解），分別在 operation.html 場景 1、index.html 場景 10、operation.html 場景 7。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂留下的問題「要重複幾次才夠準」；今天當資料偵探 |
| 10–25 | 概念：統計誤差 σ = √(P(1−P)/N)、次數 ×4 誤差 ÷2；讀取誤差與混淆矩陣；看 operation.html#readout |
| 25–65 | 父子用模擬器（error_lab.py 或 Qiskit）跑 100、1000、10000 次，畫出誤差變化；跑校準線路、做一次混淆矩陣校正，填前後比較表 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：用 N = P(1−P) ÷ 誤差² 算出 ±1% 要幾次（P = 0.5 → 2,500；P = 0.1 → 900），再跑模擬驗證 |
| 105–115 | 孩子教爸爸：兩種誤差怎麼分、怎麼校準、緩解的限制 |
| 115–120 | 錄音總結、作品命名、存檔 |

旁白用語：shots 念「重複次數」、σ 念「誤差」、M⁻¹ 念「混淆矩陣的反矩陣」、T₁ 念「能量弛豫時間」、X 閘念「翻轉閘」；投影片保留符號。
教材：誤差速查卡與偵探規則、偵探案件卡（可剪）、誤差緩解前後比較表、說明卡、解答、可執行的 error_lab.py（只用標準函式庫）與選用的 qiskit_readout.py（`academy/authoring/q059/classroom.py`）。
