# Q143 三階段路線圖與 11 個開發項目

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：時間機器——把開發計畫撥到第 6、12、18 個月回頭檢查 |
| 10–25 | 概念：三階段路線圖、項目依賴、照階段排 vs 照依賴排、建議啟動順序、檢查點 |
| 25–65 | 整理項目依賴圖（11 個圓圈＋箭頭＋檢查點）；爸爸操作時間機器、宣布檢查結果 |
| 65–75 | 休息 |
| 75–105 | 挑一個項目，寫出它的完成判準 |
| 105–115 | 孩子教爸爸：為什麼 ②③ 最先做、路線圖為什麼不是承諾 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：項目卡（11 張）、依賴圖底稿、時間機器檢查卡、完成判準工作單、說明卡、解答（`academy/authoring/q143/classroom.py`）。
