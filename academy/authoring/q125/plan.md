# Q125 量測 1 次與 1000 次

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第十三課：用 basic-circuits.html 量測卡的「量測 1 次」「量測 1,000 次」「清除」，分辨單次結果與統計結果。
量一次只給一個結果（比例只有 0% 或 100%）；理論機率集中在一個答案的範例（干涉、Deutsch、BV、兩顆 Grover）量一次就夠，一半一半或 75／25 的範例要量很多次。
統計誤差 σ = √(P(1−P)/N)（QC_Operation_Talk p32）：1000 次一半一半約 ±1.6%、75% 約 ±1.4%、100% 為 0；約三次有兩次落在 ±σ 內。估到 ±2% 要 625 次（一半一半）、約 470 次（75%）；±1% 約 2,500 次。
注意事項：連續幾個 0 不會「該輪到 1」（大數法則不是自動補回平衡）；多量只縮小隨機誤差，讀取判錯的偏差不會消失（op#readout）。
孩子獨立改造：用公式估次數，再用 shots_lab.py 把 625 次重複 200 輪，數幾輪落在 ±2% 內（理論約三分之二）。好玩機制「科學實驗」，作品是量測比較表，生活技能「重複實驗」。
