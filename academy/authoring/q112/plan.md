# Q112 模組發表：換你當老師

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
課綱屬「模組發表」型（QM07 超導量子電腦深入：師生對話十三課的總結發表，好玩機制「角色交換」）；影片沿用父子課堂的口吻與結構，以 docs/超導量子電腦師生對話教學紀錄.md 全篇（使用方式、課程地圖、第 2 課、附錄 A、D）為底，示範如何把其中一課改寫成自己的師生對話，不虛構對話紀錄。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：十三課走完，今天角色交換；作品是自編師生對話一課 |
| 10–25 | 概念示範：十三課地圖、一課五個部分（自編對話模板）、以第 2 課示範、好老師三招、三種題型、註明出處 |
| 25–65 | 父子共同實作：挑十三課其中一課，照模板改寫成自己的師生對話並錄音 |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：替這課加三題課後練習與解答（teach_helper.py 出題、檢查對話稿） |
| 105–115 | 角色互換：孩子教爸爸操作與原理 |
| 115–120 | 錄音總結、作品命名、版本存檔 |

教材：自編對話模板（課綱「需新增：自編對話模板」）、可執行的 `teach_helper.py`（純 Python，不需套件）、十三課對照表、三題練習出題卡、錄音四問、最後一關檢核表、解答（`academy/authoring/q112/classroom.py`）。
