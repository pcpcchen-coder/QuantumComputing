## 離子阱與中性原子量子電腦（slides/Ion_NeutralAtom_Talk.pptx）

第 29 頁「量子位元編碼：四種選擇」
- 「芮德堡態 |r⟩ 平常不用來存資訊，只在做兩位元閘的瞬間「借用」。」

第 30 頁「單位元閘：全域旋轉 + 局部定址」
- 「AOD 打出聚焦光束 → 光位移（AC Stark）只改變被照到的原子頻率 → 局部 Z 旋轉」

第 31 頁「芮德堡原子：把原子「吹大」」
- 「軌道半徑 / ∝ n² / ~0.4 μm（基態 ~0.0003 μm）」「輻射壽命（含室溫黑體） / ∝ n³（量級） / ~100–150 μs」
- 「基態原子之間幾乎沒有交互作用（中性、很小）」「激發到芮德堡態 → 偶極交互作用增加 10¹² 倍以上」「用雷射「開關」交互作用：要做閘時才打開」
- 「V(r) = C6 / r6」「雙光子激發：420 nm + 1013 nm（⁸⁷Rb）」
- 「閘時間（~0.3 μs）遠短於芮德堡態壽命（~100 μs）→ 衰變錯誤約 0.1 % 量級。」

第 32 頁「芮德堡阻斷：兩位元閘的核心」
- 「距離 < Rb：V ≫ Ω，|rr⟩ 被推離共振 → 兩顆不能同時被激發」「只剩「其中一顆」被激發，集體 Rabi 頻率 √2 Ω」
- 「Rb = (C6 / ħΩ)1/6 ≈ 5–10 μm」「光鑷間距 3–5 μm → 鄰近的原子都在阻斷區內」

第 33 頁「從阻斷到 CZ 閘」
- 「|00⟩ / 兩顆都在 |0⟩ → 雷射只對 |1⟩ 共振 → 都不動 / 相位 0」
- 「|01⟩、|10⟩ / 只有一顆被激發 → 完整繞一圈回來 / 單顆相位 φ」
- 「|11⟩ / 兩顆都想被激發 → 被阻斷，只能集體 √2Ω 振盪 / 相位 ≠ 2φ」
- 「Levine 2019：兩個脈衝 + 中間相位跳躍」「加單位元 Z 修正 → 標準 CZ」
- 「Harvard/MIT/QuEra（Nature 2023）：99.5 %，60 顆原子並行」
- 「|11⟩ 被阻斷 → 累積的相位和其他態不同 → 條件相位 = 受控 Z（CZ）；全域雷射一閃就能並行做很多對。」

## Wikipedia: Neutral atom quantum computer
