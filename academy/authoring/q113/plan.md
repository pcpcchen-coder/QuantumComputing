# Q113 讀圖之前：三個約定與今天用到的閘

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第一課：只講讀圖的三個約定（由左往右、q0 位置、振幅正負與機率）和四種閘的符號（H、X、Z、CNOT），不完整示範任何一個範例，八個範例留給 Q114–Q121。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：新模組八個範例；今天先講約定與閘 |
| 10–25 | 概念示範：八個範例地圖、三個約定、三種單位元閘、受控反閘 |
| 25–65 | 父子共同實作：對照簡報約定頁，在 basic-circuits 逐步播放疊加範例並讀出每一步（臨摹挑戰：出題官與臨摹員） |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：自己畫一條兩閘線路，標出位元順序，跑 read_order.py（或 Qiskit）對答案 |
| 105–115 | 角色互換：孩子教爸爸操作與原理 |
| 115–120 | 錄音總結、作品命名、版本存檔 |

教材：讀圖約定卡、臨摹挑戰卡、可執行的 `read_order.py`（純 Python）與選用的 `qiskit_check.py`、解答（`academy/authoring/q113/classroom.py`）。
v2 動畫展示段：basic-circuits.html #superposition（照約定一讀線路）、#bell 只播準備的翻轉閘（編號零寫在最右邊）、#interference 只播前兩步（相位翻轉閘與負振幅），見 `academy/authoring/v2/demos_extra/q113.py`。
