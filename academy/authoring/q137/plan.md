# Q137 中性原子的供電：保護熱穩態

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：資料偵探——中性原子的供電需求和離子阱哪裡不一樣 |
| 10–25 | 概念：整套最省電、雷射最敏感；四類用電；斷電時離子阱 vs 中性原子；T1／T2／T3／可中斷分層；恢復時間花在熱平衡 |
| 25–65 | 整理中性原子供電需求表（每格標出處或「推論」）；檔案員（爸爸）拿離子阱資料逐列追問 |
| 65–75 | 休息 |
| 75–105 | 推論中性原子擴大後卡在哪：雷射功率、物鏡受熱、即時解碼 GPU |
| 105–115 | 孩子教爸爸：為什麼要保護的是熱穩態 |
| 115–120 | 錄音總結、作品命名、存檔 |

動畫展示段（v2）：`atoms.html#atomsys`（只看設施＋用電分配；雷射與機櫃對回分層）、`atoms.html#tweezer`（裝載 → 成像 → 重排）。

教材：需求表底稿、和離子阱逐列比較表、擴大瓶頸推論單、說明卡、解答（`academy/authoring/q137/classroom.py`）。
