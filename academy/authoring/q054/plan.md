# Q054 任意旋轉 = 三個旋轉

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（兩步追上哈達瑪閘、相位閘就是繞垂直軸、一場程式對決）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂的虛擬 Z；量子閘那麼多種，硬體要每種都準備嗎？ |
| 10–25 | 概念：方向只要兩個角度；U = e^(iγ)Rz(φ)Ry(θ)Rz(λ)，由右往左作用；整體相位看不見 |
| 25–65 | 父子一起在 operation.html#gates 把 H、S、T（加 Z、X、√X）拆成旋轉序列，用兩個起點驗證，填分解練習單 |
| 65–75 | 休息 |
| 75–105 | 程式對決：孩子出題（例如 Rx(60°)、H 接 T），和爸爸比誰先拆出三個角度，再到動畫驗證 |
| 105–115 | 孩子教爸爸：三個旋轉的原理、拆法、受控時整體相位不能丟 |
| 115–120 | 錄音總結、作品命名、存檔 |
