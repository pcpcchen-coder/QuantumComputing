# Q062 Shor：用干涉找週期

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（從疊加到尖峰、第二關魔王二十一、魔王反擊與再戰，全部在 operation.html#shor）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂的量子傅立葉轉換；今天的魔王戰（分解 15、21） |
| 10–25 | 概念：分解轉成找週期；量子三步（疊加＋模指數、量第二組得到梳子、干涉出尖峰）；連分數與最大公因數；看 operation.html#shor |
| 25–65 | 父子在場景分解 N = 15（a = 7）與 N = 21（a = 2），每一步寫在分解推導單；玩魔王戰（爸爸出題、孩子破關、遇到反擊換 a） |
| 65–75 | 休息 |
| 75–105 | 孩子改造：解釋為什麼找週期就能分解（7⁴ − 1 = 48 × 50，gcd 撈出 3 和 5） |
| 105–115 | 孩子教爸爸：五步、尖峰怎麼來、限制 |
| 115–120 | 錄音總結、作品命名、存檔 |

旁白用語：Shor 念「秀爾演算法」、H 念「哈達瑪閘」、QFT 念「量子傅立葉轉換」、gcd 念「最大公因數」、mod 念「除以…的餘數」、RSA 念「網路上常用的一種公開金鑰加密」、Boss 念「魔王」；投影片保留符號。

教材：分解推導單（15、21 各一張）、魔王戰關卡卡、為什麼能分解解說卡、說明卡、解答、可執行的 shor_lab.py（純 Python，模擬 6 顆計數位元的週期尋找）（`academy/authoring/q062/classroom.py`）。
