# Q017 為什麼要做「人造原子」

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：進入第二階段硬體篇，要拿什麼做量子位元 |
| 10–25 | 概念：二態系統的三個要求、迪文森佐五條件、硬幣和燈泡、原子、LC 電路到約瑟夫森接面、超導量子位元的弱點 |
| 25–65 | 冒險任務：孩子當檢核員、爸爸當考官，用五條件檢核硬幣、燈泡、原子、transmon |
| 65–75 | 休息 |
| 75–105 | 孩子改造：找一個生活中的二態系統，檢核它缺哪一條、要補什麼 |
| 105–115 | 孩子教爸爸：五條件與人造原子的原理 |
| 115–120 | 錄音總結、替檢核卡取名字、保存 |

教材：五條件檢核卡（列印與 CSV）、五條件卡、生活二態系統改造單、說明卡、解答、可執行的 `ladder_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q017/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q017.py`（atoms.html#ionqubit 原子的初始化、操控、讀取；index.html#potential 樓梯等不等高；atoms.html#compare 相干時間內能做幾個閘）。
