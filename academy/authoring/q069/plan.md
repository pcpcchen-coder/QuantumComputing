# Q069 離子鏈的集體振動

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；
v2 動畫展示 3 段，都用 atoms.html#modes（質心模和呼吸模：模式編號 1 → 2；徑向模：按「徑向模態」、模式編號 1 → 2；
離子越多模越擠：離子數 5 → 12、頻率比 5 → 10）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂一顆離子量子位元；今天的問題是離子怎麼傳話 |
| 10–25 | 概念示範：離子排成一列（中間密、兩端疏）、正規模、質心模（ω_z）與呼吸模（√3 ω_z）、量子匯流排與全連接 |
| 25–65 | 父子共同實作（角色扮演）：全家排成一列手拉手當人肉離子鏈，指揮喊口令演質心模、呼吸模，畫箭頭填正規模觀察表 |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：在 atoms.html#modes 把離子數 2 → 12，記錄最高軸向、最低徑向頻率；遇到鋸齒形警告就拉高頻率比 |
| 105–115 | 孩子教爸爸：兩個模怎麼動、為什麼是量子匯流排、離子越多為什麼越難 |
| 115–120 | 錄音總結、替觀察表命名、存檔 |

旁白用語：ω_z 念「軸向頻率」、ω_r 念「徑向頻率」、√3 念「根號三」、COM 念「質心模」、breathing 念「呼吸模」、rocking 念「傾斜模」、
zigzag 念「鋸齒形」、Cirac–Zoller 念「西拉克和佐勒」、QCCD 念「搬運」、Mølmer–Sørensen 念「莫爾默索倫森」；投影片保留符號與英文。
全稿避開「長」（箭頭說「大小相同」「越大」，不說「一樣長」）。

教材：爸爸先讀、操作步驟（人肉離子鏈口令與動畫改造）、離子數紀錄表 CSV、`ion_chain_modes.py`（只用 Python 內建功能算平衡位置與正規模頻率）、
列印包 4 頁（正規模觀察表、人肉離子鏈口令卡、離子數紀錄表、說明卡與最後一關）、解答（`academy/authoring/q069/classroom.py`）。
