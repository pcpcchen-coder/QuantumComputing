# Q028 量子位元家族圖鑑

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的可調環，接到同一種接面做出的量子位元家族 |
| 10–25 | 概念：共同點（接面的非線性）、看結構與比值；電荷型、大電容型、超電感型、相位型；沒有全能冠軍 |
| 25–65 | 父子實作：為四種量子位元各做一張圖鑑卡（結構、頻率、優點、弱點），蓋解鎖章，照比值排序 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：設計一張理想量子位元卡，每個優點寫出跟誰借，再寫下代價 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替圖鑑取名字、保存 |

教材：圖鑑卡模板（四張空白卡）、家族比較表、理想量子位元卡、說明卡（列印）、解答、動畫導覽（`academy/authoring/q028/classroom.py`）；不需要帳號，也不需要安裝程式。
動畫展示段：`academy/authoring/v2/demos_extra/q028.py`（index.html#potential：比值五十與一的電荷色散小圖；index.html#washboard：偏壓電流加到零點九零時位障與振動頻率的變化；transmon-3d.html#capacitor：電容拉到二十飛法拉時非諧性與電荷色散的拉扯）。
