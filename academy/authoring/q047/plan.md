# Q047 軟體、監控與聯鎖

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：硬體接好之後，誰把程式變成微波、誰在盯著機器 |
| 10–25 | 概念：軟體堆疊、校準資料庫、告警與聯鎖、監控的三大類數字 |
| 25–65 | 故障注入：在監控場景按冷卻水中斷、真空洩漏、流阻堵塞，記錄徵兆、自動動作、人工處置 |
| 65–75 | 休息 |
| 75–105 | 替家裡的冰箱或熱水器寫異常處置卡（人先安全、看保護、再處理） |
| 105–115 | 孩子教爸爸：軟體堆疊、告警與聯鎖的差別、人先安全 |
| 115–120 | 錄音總結、處置卡命名、存檔 |

教材：故障注入紀錄表、異常處置卡（量子電腦版＋家用版）、軟體堆疊連連看、可執行的 `fault_sim.py`（照監控場景模型逐秒印出三種故障的數值與聯鎖判斷）、說明卡與解答（`academy/authoring/q047/classroom.py`）。
