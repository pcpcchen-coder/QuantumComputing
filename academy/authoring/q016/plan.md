# Q016 成果發表：我的量子小百科

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從逃脫室到小百科，第一階段量子直覺的最後一堂 |
| 10–25 | 概念：發表模板四格（一句話、比喻、哪裡不像、場景畫面）；示範詞卡疊加、干涉、糾纏；每個比喻都有限制 |
| 25–65 | 父子一起寫十張詞卡，辦首映會：孩子發表，家人當觀眾，每個詞給一個讚＋一個問題 |
| 65–75 | 休息 |
| 75–105 | 孩子錄兩分鐘導覽：挑最喜歡的動畫場景，三段（看什麼、按什麼、代表什麼），自己聽一次再錄第二版 |
| 105–115 | 孩子教爸爸：三個名詞、一個比喻與哪裡不像、在動畫裡指出畫面 |
| 115–120 | 錄音總結、替小百科取名字、保存 |

教材：發表模板（十張詞卡，列印與 CSV）、示範詞卡與建議十詞、兩分鐘導覽稿與錄音紀錄、首映會回饋單與說明卡、示範答案、動畫導覽（`academy/authoring/q016/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q016.py`（operation.html 三段：#qubit 疊加詞卡的畫面、#interference 干涉詞卡的畫面、#gates 壞比喻「同時是 0 又是 1」差在哪裡）。
