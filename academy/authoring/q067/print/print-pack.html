最後一關：教爸爸

  • 不看稿說出離子阱的子系統：真空與阱、雷射、成像、電子、控制、設施
  • 說出一輪流程：冷卻 → 初始化 → 量子閘 → 偵測螢光
  • 說出怎麼讀出 0 或 1：看離子亮不亮、數光子
  • 指出一個誤解：離子阱不需要稀釋冷凍，但需要超高真空與多道穩頻雷射
  • 替系統方塊圖取名字、存檔
