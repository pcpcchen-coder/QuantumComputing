# Q035 色散位移 ±χ

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂電路 QED 接到「諧振腔頻率被推了多少」，盲測任務 |
| 10–25 | 概念：色散區（約 5 GHz 對 7 GHz、只互推頻率）、±χ（約 0.77 MHz、相對萬分之二、定義可能差兩倍）、S21 振幅與相位、怎麼判讀、2χ ≈ κ 分得最開；常見誤解 |
| 25–65 | 父子實作：盲測，爸爸設定狀態並遮住答案，孩子只看曲線寫 S21 判讀紀錄（十回合） |
| 65–75 | 休息 |
| 75–105 | 孩子改造：調 χ/κ 與探測頻率，記相位差與分離距離，找最好分辨的組合 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替判讀紀錄取名字、保存 |

教材：S21 判讀紀錄、改造表、判讀練習單、說明卡（列印）、解答、可執行的 `s21_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q035/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q035.py`（兩座山跟著狀態左右移、只看曲線猜狀態、色散位移和線寬怎麼搭；三段都用 index.html#dispersive）。
這是依課綱製作的課前教學版，不是實際上課錄音。
