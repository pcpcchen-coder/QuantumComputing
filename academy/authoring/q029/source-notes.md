## 簡報（slides/JJ_Microwave_Readout_Talk.pptx，python-pptx 擷取）

- p20「Transmon 典型參數」備註：「這裡想強調：JJ 本身其實很小，電容板才是佔面積最大的部分」。
- p21「JJ 製程：Dolan bridge 雙角度蒸鍍」；圖說「3D 場景 7：Lift-off 後留下兩層鋁的重疊區 = JJ」；
  「1 雙層光阻 + 電子束微影：下層 MMA 顯影較快形成底切 → 上層 PMMA 留下懸空「橋」」
  「2 第一次斜角蒸鍍 Al（+θ）：影子使沉積位置平移」「3 原位氧化：不破真空通入 O2，長出 1–2 nm AlOx」
  「4 第二次斜角蒸鍍 Al（−θ）：在橋正下方與第一層重疊」「5 Lift-off：去除光阻，只留下重疊的 Al/AlOx/Al」。
  備註：「JJ 怎麼做出來？最經典的方法是 Dolan bridge 雙角度陰影蒸鍍，這也是很多實驗室和公司在用的方法。」
  「第一步，塗兩層電子束光阻：下層 MMA 顯影比較快，會被挖出一個底切；上層 PMMA 定義圖形，在兩條開口之間留下一座懸空的光阻橋。」
  「第二步，在真空中從一個斜角蒸鍍鋁。因為有角度，鋁原子穿過開口後落在基板上的位置會平移，就像影子一樣。」
  「第三步，不破真空直接通入氧氣，讓鋁表面長出一到兩奈米的氧化鋁。氧氣壓力乘上時間，決定了氧化層厚度，也就決定了穿隧電阻和臨界電流。」
  「第四步，從相反的角度再蒸鍍一次鋁，第二層會往反方向平移，剛好在橋的正下方和第一層重疊——這個重疊區就是 JJ。」
  「第五步，lift-off，把光阻和上面多餘的金屬一起溶掉。」
  「動畫會依序播放這五個步驟，也可以點 1 到 5 的按鈕直接跳到某一步。注意第二和第四步的原子飛行方向是相反的。最後一步相機會拉近，金色閃爍的就是 JJ。」
  「除了 Dolan bridge，另一種常見的是 Manhattan 法，用兩條互相垂直的線條各蒸鍍一次，不需要懸空橋，製程穩定性更好。」
- p22「製程控制：從氧化參數到量子位元頻率」：「氧化壓力×時間／接面面積 → 室溫電阻 Rn → Ic = πΔ / 2eRn → EJ = ħIc / 2e → 量子位元頻率 f₀₁」；
  「f01 ∝ √EJ ∝ 1/√Rn：Rn 差 2 % → 頻率差約 1 %（~50 MHz）」「氧化層厚度只有幾個原子層，面積僅 ~0.02 μm²」
  「固定頻率 transmon 之間若頻率太接近（頻率碰撞）會造成串擾與閘錯誤」；
  業界常見對策「室溫探針量測 Rn：降溫前預測頻率（Ambegaokar–Baratoff）」「雷射 / 熱退火：製作後微調 Rn，把頻率修到目標值」「可調頻設計：SQUID + Z 線」「製程監控」。
  備註：「Ambegaokar–Baratoff 關係告訴我們 Ic 和 Rn 成反比；Ic 決定 EJ；EJ 再決定量子位元頻率。」

## 維基百科 Josephson effect（2026-11-18 取得）

- Al|AlOx|Al 接面是許多超導量子位元的主流；氧化鋁在鋁上自我限制地生長，可穩定把障壁厚度控制在「1–2 nm range」。
