# Q029 晶片怎麼做：雙角度蒸鍍

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂圖鑑卡裡的約瑟夫森接面，問「這麼小的接面怎麼做出來」 |
| 10–25 | 概念：Al／AlOx／Al 三明治與尺寸、雙層光阻與懸空橋、兩次斜角蒸鍍、原位氧化與剝離、從氧化參數到頻率、安全提醒 |
| 25–65 | 父子實作：厚紙剪兩個開口留一條紙橋，手電筒從左右兩個角度各照一次，用兩色筆描出橋下的重合區並拍照 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：改變照射角度，先預測再量出重合寬度，找出「寬度 ≈ 2h·tanθ − 橋寬」 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替影子蒸鍍作品取名字、保存 |

教材：影子蒸鍍記錄表、紙橋製作與預測單、角度改造工作單、說明卡（列印）、解答、可執行的 `shadow_overlap.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q029/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q029.py`（index.html#fab 三段：雙層光阻與懸空橋、正反兩個角度各鍍一次、氧化後剝離找到金色重疊區）。
安全：真實製程在無塵室使用化學藥品與真空設備，家中只做影子模擬；手電筒不要照眼睛，剪刀由爸爸協助。
這是依課綱製作的課前教學版，不是實際上課錄音。
