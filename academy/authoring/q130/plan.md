# Q130 斷電的代價：2 分鐘換 2–5 天

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
課綱屬 QM09「量子電腦的供電與機房工程」第 2 課（對象為工程同仁）；影片沿用父子課堂的口吻與結構，數字依 LRZ／IQM 論文與學程供電簡報、文獻回顧，不虛構對話。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一課的用電全景；停電兩分鐘會怎樣？ |
| 10–25 | 概念示範：冷卻鏈三環、LRZ 四個數字、1 K 分水嶺、時間賽跑 |
| 25–65 | 故障注入：在 power1000.html#outage 模擬 A／B／C 三種備援方案，畫斷電時間軸（出題者與值班工程師） |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：替一間實驗室寫斷電處置卡；跑 outage_timeline.py、改案例 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、作品命名、保存 |

教材：斷電時間軸、可執行的 `outage_timeline.py`（純 Python，不需套件）、實驗室斷電處置卡、備援案例紀錄表、三個容易錯的地方、教爸爸檢核表、解答（`academy/authoring/q130/classroom.py`）。
v2 動畫展示段：peripherals.html#cooldown（重新降溫為什麼要好幾天）、power1000.html#outage（A／B／C 三種方案）、peripherals.html#monitor（冷卻水中斷與聯鎖），見 `academy/authoring/v2/demos_extra/q130.py`。
