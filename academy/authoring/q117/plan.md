# Q117 範例 4：GHZ——CNOT 一路串下去

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第五課，八個範例的範例 4：|000⟩ → H（q0）→ CNOT（q0 → q1）→ CNOT（q1 → q2），每個 CNOT 都只把 q0 = 1 那一根柱子往右搬（001 → 011 → 111），每搬一次就多綁一顆，最後 (|000⟩ + |111⟩)/√2，量起來不是全 0 就是全 1。換成 4 顆只多一個 CNOT（q2 → q3）：綁 N 顆需要 N − 1 個 CNOT。故意少接一條，鏈子就從那裡斷開，後面的位元一直是 0（一環扣一環）。常見誤解：CNOT 的「複製」只對齊 0 和 1，不是複製未知的量子態；動畫是理想模擬，真機位元越多越容易被雜訊破壞。用「闖關」一關多綁一顆，作品是 GHZ 逐步圖。
