父子科技學院量子電腦學程第一百一十七堂（八個量子電路範例的範例 4）：把 Bell 電路的 CNOT 一路串下去，讓三顆、四顆位元一起糾纏，看每一步多綁一顆，量起來不是全 0 就是全 1。

這一集會學到
・範例 4：|000⟩ → H（q0）→ CNOT（q0 → q1）→ CNOT（q1 → q2）；每個 CNOT 只把柱子往右搬：001 → 011 → 111，最後 (|000⟩ + |111⟩)/√2
・換成 4 顆只多一個 CNOT（q2 → q3），16 種結果只剩 0000、1111；綁 N 顆需要 N − 1 個 CNOT
・故意少接一條：3 顆少接最後一條只量到 000、011；4 顆少接中間一條只量到 0000、0011——一環扣一環，斷一環後面就綁不上
・CNOT 的「複製」只是對齊 0 和 1，不是複製未知的量子態
・動畫是理想模擬；真機位元越多、CNOT 越多，越容易被雜訊破壞，所以硬體常用 GHZ 態測試糾纏品質

主要來源：維基百科 Greenberger–Horne–Zeilinger state、Controlled NOT gate、No-cloning theorem；本學程「量子電路入門：八個範例」簡報第 13–14 頁與 basic-circuits.html、operation.html 互動動畫；本機 ghz_lab.py 與 Qiskit 2.6.2 實跑紀錄。
