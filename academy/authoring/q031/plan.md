# Q031 退相干：敵人在哪裡

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂晶片尋寶，換成偵探身分，問「是誰在破壞量子位元」 |
| 10–25 | 概念：兩個證據（T₁、T₂、T₂ ≤ 2T₁）、四個嫌犯（TLS、準粒子與輻射、磁通雜訊、熱光子與 Purcell）、線索配對、先懷疑量測 |
| 25–65 | 父子實作：做四張嫌犯卡，依證據（T₁ 或 T₂ 變短）配對對策，貼成雜訊來源關係圖 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：替一個嫌犯設計量測實驗（量哪個時間、只改一個條件、預期結果） |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替關係圖取名字、保存 |

教材：嫌犯卡模板、雜訊來源關係圖草圖格、量測實驗設計單、說明卡（列印）、解答、可執行的 `suspect_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q031/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q031.py`（index.html#bloch 三段：第一個證據——能量漏掉（T1 模式）、第二個證據——相位亂掉（Ramsey 模式）、先做對照組（Rabi 對照 T1））。
這是依課綱製作的課前教學版，不是實際上課錄音。
