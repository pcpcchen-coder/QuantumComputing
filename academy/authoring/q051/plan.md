# Q051 看懂後端校準資料

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（表上數字從哪來、讀取錯誤從哪來、編譯器依校準資料挑位元）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從校準工程師換到使用者，打開後端校準資料表 |
| 10–25 | 概念：兩種壽命、三種錯誤率、耦合圖；偵探三招 |
| 25–65 | 資料偵探：在虛構後端「犀牛六號」上圈線索，挑出跑貝爾態的兩顆（爸爸當證人追問證據） |
| 65–75 | 休息 |
| 75–105 | 寫後端體檢報告：最弱三處＋比較早上、下午兩份快照＋建議 |
| 105–115 | 孩子教爸爸：怎麼讀表、為什麼挑那兩顆 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：犀牛六號資料表（標示虛構，早上與下午兩份快照）、耦合圖、偵探線索卡、貝爾態搭檔計算表、後端體檢報告、說明卡、解答、可執行的 backend_detective.py（只用 Python 標準函式庫；`academy/authoring/q051/classroom.py`）。
