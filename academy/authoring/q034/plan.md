# Q034 電路 QED：量子位元＋諧振腔

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂「讀取要快、準、不破壞」接到讓量子位元影響諧振腔；角色扮演（量子位元、讀取腔、讀取的人） |
| 10–25 | 概念：借自原子物理（原子腔 QED → 電路 QED）、晶片上的三個零件（十字形量子位元、讀取腔、饋線）、頻率要分開（色散區域）、讀取的路線、頻率多工；常見誤解 |
| 25–65 | 父子實作：用兩支音叉或兩條橡皮筋示範耦合；在 index.html#chip 指出量子位元與讀取腔；角色扮演 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：畫出量子位元、讀取腔、饋線三者的連接圖，標上頻率、g、κ |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替電路 QED 示意圖取名字、保存 |

教材：電路 QED 示意圖、耦合紀錄表、場景尋寶單、說明卡（列印）、解答、可執行的 `cqed_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q034/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q034.py`（晶片上的量子位元、讀取腔和饋線；看讀取腔，間接知道量子位元；一條饋線讀四顆——三段都用 index.html#chip）。
這是依課綱製作的課前教學版，不是實際上課錄音。
