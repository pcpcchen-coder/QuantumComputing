# Q007 兩顆、三顆、五十顆：2ⁿ 有多大

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：量子位元越多，要記的振幅有多少 |
| 10–25 | 概念：組合數翻倍、每種組合一個振幅、每個振幅 16 位元組、振幅多不等於答案多 |
| 25–65 | 活動一米粒和杯子（1 到 5 顆）＋活動二記憶體競速（算到 50 顆，計算手與裁判） |
| 65–75 | 休息 |
| 75–105 | 查自家電腦記憶體，算出最多能精確模擬幾個量子位元 |
| 105–115 | 孩子教爸爸：為什麼普通電腦模擬不了太多量子位元 |
| 115–120 | 錄音總結、保存 |
