# Q128 事實查核

查核日：2026-11-19（檔頭 CHECKED 依派工統一寫 2026-11-18）。查核者：製作代理（Claude）。逐字引文見 `source-notes.md`。
方法：維基百科 Poster session、Curator、Plagiarism 由製作代理取得原始 wikitext 並摘錄（revision id 未取得）；basic-circuits.html 的 SCENES、分頁、量測按鈕、重點卡連結由製作代理讀取，
並以 Node 載入頁面引擎算出八個預設範例的理想機率；operation.html 場景 6（06_circuit.js）、場景 12（12_workflow.js）由製作代理讀取；畫面以 Playwright 單張截圖確認（nice -n 19，未錄影、未跑 QV2_DRY）。
程式由製作代理實際執行：exhibit_helper.py（Python 3.13.18，沒有亂數）、qiskit_check.py（Qiskit 2.6.2 Statevector，沒有亂數）。
限制：只驗證理想模擬；動畫量一千次的比例每次不同，旁白一律不念次數。課綱素材寫「沒有可直接沿用的現有頁面或場景」「需新增：◆ 發表模板」；發表模板由本課教材（列印包第 1 頁、06_發表模板.md、exhibit_helper.py 的 MY_POSTER）補上。
「回答三個問題」課綱沒有規定題目；本課整理成三種常見觀眾問題（為什麼、改一個閘、真機器），在 not_verified 註明是本課的建議。
與先前各課的區隔：Q113–Q127 的 basic-circuits 段都用 hash 直接開某個範例，沒有點過上方八個分頁，也沒讀過重點卡的延伸連結；op#workflow 只有 Q001（自動播放走一遍）與 Q111（時間組成插圖）用過；
op#circuit 的量子傅立葉轉換預設線路沒有任何一課用過。
36 句與 Q001–Q127 的 36 句及所有已收錄課的動畫段逐句比對（SequenceMatcher）：只有開場第一句、時間表與結尾是固定格式而相似（≤ 0.89），其餘最高 0.67（Q112「再指出一個注意事項，例如引用動畫畫面要註明出處…」，句型相同、內容不同），沒有重複句。
所有 48 句以 caption_wrap.wrap_caption 檢查可排成兩行字幕（最長 71 字為開場第一句），沒有英文字母或阿拉伯數字，沒有「長」字。
