這是依課綱製作的課前教學版，不是實際上課錄音。

父子科技學院量子電腦學程第一百二十八堂：模組發表——量子電路展。走完 QM08 的八個範例之後，孩子當策展人，把學過的線路布置成一場展覽：挑一件展品，向家人發表五分鐘（線路、振幅逐步、量測結果），再回答觀眾的三個問題，最後完成一張量子電路展海報。

這一集會學到
・首映會三步：挑展品 → 五分鐘發表 → 回答觀眾三問
・展品目錄：八個範例分成一顆位元、糾纏、演算法三個展區
・五分鐘發表三段：線路、振幅逐步、量測結果（以範例三貝爾態示範）
・觀眾常問的三種問題：為什麼、改一個閘會怎樣、真的量子電腦也一樣嗎
・海報版面與注意事項：截圖與程式要註明出處；模擬結果不是真實機器的實測

主要來源：維基百科 Poster session、Curator、Plagiarism；本學程「量子電路入門」basic-circuits.html 八個範例，以及 operation.html 場景 6「量子線路」、場景 12「完整流程」互動動畫；本機 Python 與 Qiskit 2.6.2 實跑紀錄。

教材用法（classroom.zip）
先讀「00_爸爸先讀」，照「01_操作步驟」用 basic-circuits.html 挑展品、排練五分鐘發表；執行 exhibit_helper.py（只要 Python 3）印出八張展品卡與自己展品的振幅逐步，有 Qiskit 時再跑 qiskit_check.py 重算；照「06_發表模板」寫講稿與海報，下半場根據觀眾問題修改說明。課堂 120 分鐘另計。
