# Q128 模組發表：量子電路展

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM08「動手寫量子電路：從八個範例到自己的線路」的第十六課（模組發表）：孩子當策展人，把八個範例布置成「量子電路展」，挑一件展品向家人發表五分鐘，回答觀眾的三個問題。
首映會三步：挑展品 → 五分鐘發表（線路、振幅逐步、量測結果）→ 回答觀眾三問（為什麼、改一個閘、真機器）。
展品目錄：一顆位元區（範例 1 疊加、2 干涉）、糾纏區（3 Bell、4 GHZ、5 隱形傳態）、演算法區（6 Deutsch、7 BV、8 Grover）。
示範：範例 3 Bell 態——H、CNOT；+1.000|00⟩ → +0.707|00⟩ +0.707|01⟩ → +0.707|00⟩ +0.707|11⟩；00、11 各 50%。
注意事項：截圖與程式要註明出處（Plagiarism）；模擬器是理想機率，不是真實機器的實測。好玩機制「首映會」，作品是量子電路展海報；生活技能「發表與回饋」。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：QM08 回顧、今天當策展人、首映會與作品 |
| 10–25 | 概念示範：展品目錄、五分鐘三段、以範例 3 示範、觀眾三問、海報版面、註明出處 |
| 25–65 | 父子共同實作：basic-circuits.html 每人五分鐘發表、互相提問；exhibit_helper.py 展品卡與振幅逐步、qiskit_check.py |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：根據觀眾問題修改海報說明，再講一次；海報檢查 |
| 105–115 | 角色互換：孩子教爸爸操作與原理 |
| 115–120 | 錄音總結、作品命名、版本存檔 |

教材：發表模板（五分鐘講稿三段＋出處）、海報版面與觀眾三問紀錄卡、改說明紀錄、最後一關檢核表；純 Python `exhibit_helper.py`（八張展品卡、振幅逐步、海報檢查）、`qiskit_check.py`（Qiskit Statevector 重算）、解答（`academy/authoring/q128/classroom.py`）。
