# Q009 量子線路像樂譜

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：量子線路像樂譜 |
| 10–25 | 概念：線是量子位元、方塊是閘、儀表是測量、由左往右；順序不能亂換 |
| 25–65 | 臨摹挑戰：照場景畫 3 條線路（X→測量、H→測量、H–Z–H→測量），說出每一步箭頭怎麼變（畫圖員與核對員） |
| 65–75 | 休息 |
| 75–105 | 自己畫 3 步線路，請爸爸預測，用紙球驗證 |
| 105–115 | 孩子教爸爸讀線路圖 |
| 115–120 | 錄音總結、保存 |

教材：臨摹步驟、三條線路臨摹格（方格紙）、箭頭追蹤表、三步線路作曲卡、27 種三步線路解答表（`academy/authoring/q009/classroom.py`）。
