# Q056 轉譯：邏輯線路到硬體

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（拆成原生閘、不相鄰就插交換閘、換成方格晶片），都在 transmon-3d.html 第 12 章第 9 步自由實驗。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂的兩位元閘；紙上隨便接，晶片只有鄰居能互動 |
| 10–25 | 概念：四道工序（分解、配置、路由、最佳化）；1 個 SWAP = 3 個 CNOT；看動畫第 12 章 |
| 25–65 | 父子在耦合圖紙板上用代幣做題卡，比賽誰插入的 SWAP 最少，填路由比賽紀錄 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：同一題換線形、方格、重六角小片，比較 SWAP 數；挑戰題「一拖四」 |
| 105–115 | 孩子教爸爸：四道工序、怎麼路由、一個 SWAP 的代價 |
| 115–120 | 錄音總結、作品命名、存檔 |

旁白用語：SWAP 念「交換閘」、CNOT 念「受控反閘」、CZ 念「受控相位翻轉閘」、√X 念「半個翻轉閘」、Rz 念「繞垂直軸的旋轉」；投影片保留符號。重六角在旁白說「六角形的耦合圖」（避開破音字）。

教材：耦合圖紙板、題卡（可剪）、路由比賽紀錄、說明卡、解答、可執行的 routing_lab.py（`academy/authoring/q056/classroom.py`）。
