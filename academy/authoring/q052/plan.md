# Q052 微波脈衝：面積與相位

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（面積一格一格加、粉紅色的旋轉軸與失諧、transmon 兩顆四分之一圈按鈕）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：翻轉閘是怎麼做出來的？ |
| 10–25 | 概念：脈衝四個旋鈕；面積決定轉幾度、相位決定繞哪條軸 |
| 25–65 | 闖關：孩子（脈衝設計師）先寫預測、再送出脈衝，完成翻轉、疊加、繞 y 軸、倒帶四關；爸爸（關主）出題蓋章 |
| 65–75 | 休息 |
| 75–105 | 控制變因：固定面積和相位，只改失諧（0、5、10、20 MHz），記錄軸傾角與 P(1) |
| 105–115 | 孩子教爸爸：面積與相位的作用、一個限制 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：脈衝設計紀錄（闖關表）、失諧實驗表、面積加法練習、說明卡、解答、可執行的 pulse_lab.py（`academy/authoring/q052/classroom.py`）。
