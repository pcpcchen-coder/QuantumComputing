# Q039 讀取設計的取捨

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂讀取鏈回到晶片上的讀取腔；讀得快、讀得準、不傷量子位元能不能同時做到；工程答辯任務 |
| 10–25 | 概念：三個旋鈕（線寬 κ、色散位移 χ、讀取光子數）的好處與代價；線寬與珀塞爾效應（γ ≈ κ(g/Δ)²，κ 加倍 T₁ 上限減半）；2χ ≈ κ 分得最開（0.5 或 2 時距離 0.80）；簡報 p37 數值範例（χ ≈ −0.56 MHz、κ ≈ 1.1 MHz、T₁ 上限 ≈ 57 μs、讀取 300–600 ns）；珀塞爾濾波器；常見誤解（線寬越大越好？） |
| 25–65 | 父子實作：用讀取參數計算器設計一組參數，填讀取參數卡，爸爸當審查委員追問，孩子用數字答辯 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：在沒有／有珀塞爾濾波器兩種情況下重新設計，並排比較後寫答辯 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替讀取參數卡取名字、保存 |

教材：讀取參數卡、有／無濾波器對照表、答辯追問卡、說明卡（列印）、解答、可執行的 `readout_calculator.py`（讀取參數計算器，只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q039/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q039.py`（線寬加倍或減半：index.html#dispersive；想讀快一點：operation.html#readout；模擬珀塞爾漏能：index.html#iq）。
