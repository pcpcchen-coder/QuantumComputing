# Q057 Qiskit 實作：Bell 與 GHZ

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 動畫展示 3 段（三顆一起糾纏、四顆與程式碼、加入雜訊）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：上一堂的轉譯、第十堂的貝爾態；Release 任務 |
| 10–25 | 概念：互動筆記本、第一格印版本、GHZ 線路四格、理想 vs 雜訊 |
| 25–65 | 父子照筆記本跑 Bell 態，加入雜訊模型，比較理想與有雜訊的直方圖（發布工程師與品管員） |
| 65–75 | 休息 |
| 75–105 | 孩子改造：GHZ 擴充到 5 個位元，觀察雜訊的變化，更新版本號與更新紀錄 |
| 105–115 | 孩子教爸爸：線路怎麼接、為什麼理想只有全 0、全 1、為什麼要記版本號 |
| 115–120 | 錄音總結、作品命名、存 v1.0／v1.1 |

旁白用語：Qiskit 念「開源量子程式套件」、Aer 念「高效能模擬器」、GHZ 念「格林伯格態」、notebook 念「互動筆記本」、Release 念「發布」、seed 念「亂數種子」、CNOT 念「受控反閘」、H 念「哈達瑪閘」；投影片保留英文。

教材：可執行的 `bell_ghz_release.ipynb` 與同內容的 `bell_ghz_release.py`（本機模擬器，不需帳號）、Release 檢查清單、直方圖紀錄、五顆改造表、更新紀錄與說明卡、解答（`academy/authoring/q057/classroom.py`）。
