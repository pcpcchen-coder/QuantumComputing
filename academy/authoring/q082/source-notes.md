## 如何操作量子電腦（slides/QC_Operation_Talk.pptx）

第 47 頁「錯誤預算：能跑多深的線路？」
- 「兩位元閘錯誤 0.3% → 約 230 個兩位元閘後成功率剩 50%」

第 48 頁「錯誤緩解：現在就能用的方法」（表格：方法｜做法｜代價 / 限制）
- 「讀取誤差緩解｜量混淆矩陣，反推分佈（M3、TREX）｜低；只修讀取」
- 「動態解耦（DD）｜閒置時插入 X–X、XY4 等序列｜幾乎免費；只對低頻雜訊有效」
- 「Pauli twirling｜隨機插入 Pauli 閘，把相干誤差變成隨機雜訊｜需多組隨機線路」
- 「零雜訊外插（ZNE）｜故意放大雜訊（閘折疊、拉長脈衝），外插回雜訊 0｜shots 數倍；外插有偏差」
- 「機率誤差消除（PEC）｜學習雜訊模型，用『負機率』組合抵銷｜shots 隨線路大小指數成長」
- 「後選擇 / 對稱性檢查｜丟掉違反守恆量的結果｜丟棄部分資料」
- 「錯誤緩解改善的是期望值的估計，不保護量子資訊本身；成本隨規模指數上升 → 是通往錯誤更正之前的過渡工具」

## speech/量子電腦操作演講稿.md（第 48 頁段落）

- 「動態解耦在量子位元閒置時插入成對的翻轉脈衝，抵銷低頻雜訊，幾乎免費。」
- 「零雜訊外插 ZNE：故意把雜訊放大一倍、兩倍，例如把閘重複折疊或把脈衝拉長，量出期望值隨雜訊的變化，再外插回雜訊為零。代價是 shots 增加數倍，外插也可能有偏差。IBM 2023 年的 127 位元實驗就用了 ZNE。」
- 「機率誤差消除 PEC：先學習雜訊模型，再用帶負號的機率組合抵銷雜訊，理論上無偏，但 shots 隨線路大小指數成長。」

## docs/超導量子電腦師生對話教學紀錄.md（Q6）

## animations/js/operation/06_circuit.js

- 開關：`ui.toggle('加入雜訊（每閘 1%、讀取 3%）', false, (v) => { noise = v; if (counts) sample(); });`
- 模型：`const pg = noise ? 1 - Math.pow(0.99, gates) : 0, pr = noise ? 0.03 : 0;`；出錯時 `k = Math.floor(Math.random() * K)`；每位元 `if (Math.random() < pr) k ^= 1 << j`
- Grover：`[[H(0), H(1)]], [[CZ(0, 1)]], [[H(0), H(1)]], [[X(0), X(1)]], [[CZ(0, 1)]], [[X(0), X(1)]], [[H(0), H(1)]], M` → 12 個閘；「量測：一次就找到 11」
- 插圖標題：「量測 1000 shots 的結果（青線 = 理想機率）」；播放每 1.3 s 一欄
