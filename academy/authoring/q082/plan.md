# Q082 錯誤緩解

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 加兩段動畫展示（operation.html#circuit 加雜訊、#readout 讀錯）。課綱的「★ 零雜訊外插場景」尚未做出，外插改由本機模擬器與列印包完成。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：承接錯誤預算，帶雜訊也想估準答案 |
| 10–25 | 概念：讀取緩解、零雜訊外插、機率性錯誤消除與代價 |
| 25–65 | 模擬器放大雜訊 1、2、3 倍，畫零雜訊外插圖（資料偵探） |
| 65–75 | 休息 |
| 75–105 | 比較外插前後的期望值與誤差棒 |
| 105–115 | 孩子教爸爸：錯誤緩解在解決什麼、代價在哪 |
| 115–120 | 錄音總結、保存 |

教材：本機模擬器（Python 標準函式庫）、零雜訊外插圖、資料偵探紀錄、誤差棒比較表、說明卡、解答（`academy/authoring/q082/classroom.py`）。
