# Q040 量子電腦 ≠ 量子晶片

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂「讀取設計的取捨」把鏡頭拉遠到整間機房，尋寶任務 |
| 10–25 | 概念：晶片在稀釋冷凍機最底部（約 10 mK）、五大子系統、機房全景、冷卻側四類連接（氦氣、冷卻水、混合氣、真空）、訊號側與電力（微波與直流線、資料與時脈、電力）、典型用電（合計約 26 kW）、系統方塊圖；常見誤解（晶片就是電腦？） |
| 25–65 | 父子實作：peripherals.html#overview 尋寶，找出每台設備、一類一類切換連接，列出機房設備清單與七類連線清單 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：挑一條連接（電力、冷卻水、真空……），說明它斷掉會發生什麼事、恢復順序 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替機房設備清單取名字、保存 |

教材：機房設備清單（尋寶卡）、七類連線清單、「斷掉會怎樣」卡、說明卡（列印）、解答、可執行的 `power_budget.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q040/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q040.py`（走一圈機房全景、冷卻和訊號分開看、電力從哪裡來：三段都用 peripherals.html#overview）。
