# Q033 讀取要快、準、不破壞

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂設計 transmon 接到「算完怎麼讀出答案」，冒險任務三道關卡 |
| 10–25 | 概念：快（讀取時間 ≪ T₁，100–500 ns 對 0.1–1 ms）、準（單發讀取、誤判 < 1 %、F 的算法）、不破壞（QND）；為什麼不直接量電壓、色散讀取、螢光讀取；常見誤解 |
| 25–65 | 父子實作：寫讀取需求表，替快、準、不破壞各寫指標、目標數字、怎麼驗收 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：比較直接、色散、螢光三種讀取各過幾關，每格寫一句理由 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、替讀取需求表取名字、保存 |

教材：讀取需求表、三種讀取比較表、冒險關卡紀錄、說明卡（列印）、解答、可執行的 `readout_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q033/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q033.py`（讀得快，還要讀得準（index.html#iq）、只看諧振腔，不翻動量子位元（index.html#dispersive）、螢光讀取很準，卻把原子推走（atoms.html#imaging））。
