# Q136 離子阱的供電：ppm 與 nV

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：資料偵探——從超導換到離子阱，找出每一路電源要穩到什麼程度 |
| 10–25 | 概念：用電大宗、四路精密電源、超導 vs 離子阱的斷電、三個精密數字（ppm、nV/√Hz、nA）、市電諧波、備援四層 |
| 25–65 | 整理離子阱各子系統的供電需求表；爸爸當證人追問每個數字的出處 |
| 65–75 | 休息 |
| 75–105 | 說明為什麼離子阱要的是毫秒級備援 |
| 105–115 | 孩子教爸爸：三個數字各屬哪一路、為什麼 RF 不能斷 |
| 115–120 | 錄音總結、作品命名、存檔 |

v2 動畫段（`academy/authoring/v2/demos_extra/q136.py`，全部用 `animations/atoms.html`）：
- 第 3 頁後：`#ionsys` 系統全景——典型用電示意、只看設施、只看電子訊號。
- 第 4 頁後：`#qccd` 搬運架構——分段 DC 電極亮起、搬運時間佔最多。
- 第 6 頁後：`#paul` Paul 阱原理——q 參數與 secular 頻率等比例、關掉 RF 離子逃逸。

教材：供電需求表底稿、偵探線索卡、毫秒級備援說明單、說明卡、解答（`academy/authoring/q136/classroom.py`）。
