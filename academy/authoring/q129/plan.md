# Q129 電從哪裡來、到哪裡去

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
QM09「量子電腦的供電與機房工程」第一課；課綱對象是工程同仁，影片沿用父子課堂的口吻與結構，把量子電腦當成一個要供電、要備援的工程系統。
本課只談用電全景（冷凍、控制電子、設施）；斷電後果與回溫天數留給 Q130，不在本課展開。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：電從哪裡來、到哪裡去；尋寶規則 |
| 10–25 | 概念示範：用電三大類、電的路線、一套系統約 26 kW、壓縮機是電老虎、控制電子要乾淨 |
| 25–65 | 父子共同實作：在 power1000.html#overview 點出每一條電路，填用電清單（power_inventory.py 加總） |
| 65–75 | 休息 |
| 75–105 | 孩子獨立改造：比較超導、離子阱、中性原子各自的大用電設備 |
| 105–115 | 孩子教爸爸：操作與原理 |
| 115–120 | 錄音總結、作品命名、保存 |

教材：用電清單（尋寶卡）、用電全景圖畫格、三平台比較表、可執行的 `power_inventory.py`（純 Python，不需套件）、容易錯的地方、教爸爸檢核表、解答（`academy/authoring/q129/classroom.py`）。
v2 動畫展示段：peripherals.html#overview（電力線與典型用電分配）、peripherals.html#pulsetube（壓縮機 10 kW 換 4 K 約 1.5 W）、power1000.html#overview（三條匯流排與痛點 2、4、7），見 `academy/authoring/v2/demos_extra/q129.py`。
