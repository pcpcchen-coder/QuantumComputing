# Q141 從 1,000 到 10,000：MW 級與低溫電源轉換

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。
v2 動畫展示段 3 段：mw（第 5 頁後，`power1000.html#scale`）、conv8（第 7 頁後，`#devplan`）、stage3（第 10 頁後，`#devplan`）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：工程答辯——從 1,000 到 10,000 位元，電用到多少、卡在哪裡 |
| 10–25 | 概念：1,000 位元用電預算與四大塊、1,000 vs 10,000、擴展三條件、低溫電源轉換的設計理念 |
| 25–65 | 父子共同整理 1,000 與 10,000 位元的用電組成比較（擴展用電比較表），評審追問每個數字的依據 |
| 65–75 | 休息 |
| 75–105 | 孩子獨立列出低溫電源轉換的兩個關鍵困難，各寫一個解法與代價 |
| 105–115 | 孩子教爸爸：為什麼萬位元會變成 MW 級、為什麼要高壓低電流送進冷凍機 |
| 115–120 | 錄音總結、作品命名、存檔 |

教材：擴展用電比較表、答辯追問卡、低溫電源轉換困難卡、說明卡、解答（`academy/authoring/q141/classroom.py`）。
所有 1,000 與 10,000 位元的用電數字都是學程文件的推論；萬位元的誤差可能很大。
