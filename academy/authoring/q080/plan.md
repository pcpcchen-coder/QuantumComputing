# Q080 平台大比較與供電分析

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂；v2 加三段動畫展示（atoms.html#compare ×2、power1000.html#outage ×1）。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：誰比較好，要看用哪幾把尺 |
| 10–25 | 概念：時間尺度、比值、連接性、錯誤率、設施與用電、斷電 |
| 25–65 | 替六個平台打分數、產品評審 |
| 65–75 | 休息 |
| 75–105 | 換一組權重（供電 ×3），看排名怎麼變 |
| 105–115 | 孩子教爸爸：怎麼比平台、為什麼快不一定贏 |
| 115–120 | 錄音總結、保存 |

教材：動畫操作步驟、平台評分表、產品評審紀錄、換權重計算表、說明卡、解答（`academy/authoring/q080/classroom.py`）。
