# Q021 彈簧、單擺與 LC 電路

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂的磁通量子化回到彈簧和單擺，為什麼要看會振盪的電路 |
| 10–25 | 概念：彈簧振盪與能量換手、單擺與小角度、LC 電路、類比對照表、週期對照與 5 GHz 例子、小振幅才成立 |
| 25–65 | 父子實作：用碼錶量彈簧和單擺的週期（數十次再除以十），填出力學與 LC 的對照表 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：改變質量或擺長，先預測週期，再量、再比 |
| 105–115 | 孩子教爸爸：怎麼量、為什麼質量對應電感、彈簧對應電容 |
| 115–120 | 錄音總結、替對照表取名字、保存 |

教材：週期紀錄表（列印與 CSV）、類比對照表、改造預測卡、說明卡、解答、可執行的 `oscillation_table.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q021/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q021.py`（lc-vs-jj.html 三段：#s1 小相位時正弦像直線、#s2 小振幅的線性反應、#s2 加大振幅後波形走樣與三倍頻）。
