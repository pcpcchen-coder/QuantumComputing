# Q023 約瑟夫森接面：超導三明治

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：從上一堂等距的梯子，接到需要一個特別的超導元件 |
| 10–25 | 概念：三層結構、庫柏電子對穿隧、相位與相位差、直流與交流約瑟夫森效應、穿隧不是挖洞 |
| 25–65 | 父子實作：兩片吐司夾一張薄紙做接面模型，標出超導、絕緣、相位時鐘與相位差，再寫一個模型的限制 |
| 65–75 | 休息 |
| 75–105 | 孩子改造：寫一段三十秒說明，解釋穿隧不是挖洞穿過去，計時修到剛好 |
| 105–115 | 孩子教爸爸：結構與兩個效應 |
| 115–120 | 錄音總結、替模型取名字、保存 |

教材：模型標註清單、標註貼紙與相位時鐘（列印）、三十秒說明稿紙、說明卡、解答、可執行的 `tunnel_check.py`（只要 Python 3，不需安裝套件）、動畫導覽（`academy/authoring/q023/classroom.py`）。
動畫展示段：`academy/authoring/v2/demos_extra/q023.py`（index.html#jj 三段：三層結構與電子對、接近臨界電流的直流效應、一點四倍臨界電流的電壓態）。
