# Q045 低溫佈線與熱負載

依課綱製作的課前教學版；12 頁原生可編輯簡報（父子科技學院 L001 版型）、36 句旁白、zh-TW-YunJheNeural、原片頭 v2、靜態淡化、無背景音樂。

| 分鐘 | 內容 |
|---|---|
| 00–10 | 開場：晶片在 10 mK，儀器在室溫，指令要沿線送下去 |
| 10–25 | 概念：冷凍機各層與冷卻能力、每顆量子位元的線、輸入線 vs 輸出線、熱的三個來源 |
| 25–65 | 基準測試：在佈線場景讀 50、100 顆的線數與各層熱，自己算 1000 顆，填熱負載預算表 |
| 65–75 | 休息 |
| 75–105 | 比較不鏽鋼、細同軸與超導線材，算出冷板能多接幾條線；用熱預算場景驗證 |
| 105–115 | 孩子教爸爸：為什麼每條線都帶熱、哪一層先吃緊、導電好通常導熱也好 |
| 115–120 | 錄音總結、預算表命名、存檔 |

教材：熱負載預算表、線數計算卡、線材比較表、可執行的 `heat_budget.py`（照佈線場景的估算模型算出各層熱負載）、說明卡與解答（`academy/authoring/q045/classroom.py`）。

動畫展示段（`academy/authoring/v2/demos_extra/q045.py`）：佈線場景聚焦驅動線與讀取輸出線；佈線場景滑桿 50 → 200 顆看冷板變紅；1,000 位元供電動畫的熱預算頁切換細同軸與超導磁通線。
