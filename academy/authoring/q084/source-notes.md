## 如何操作量子電腦（slides/QC_Operation_Talk.pptx）第 49 頁「量子錯誤更正：表面碼」

- 「難題：不能複製量子態，也不能直接量資料（會塌縮）」
- 「解法：只量『奇偶』 d×d 個資料量子位元 + d²−1 個量測量子位元 = 1 個邏輯量子位元」
- 「量測量子位元反覆量測周圍 4 個資料的 Z 奇偶（抓 X 錯誤）與 X 奇偶（抓 Z 錯誤）」「奇偶改變 = 症狀；量子資訊本身不被讀取」
- 「解碼器（古典電腦，需即時）把症狀配對 → 推測錯誤鏈 → 修正」
- 「碼距 d：可修正 ⌊(d−1)/2⌋ 個錯誤；錯誤鏈貫穿整片才會造成邏輯錯誤」
- 備忘稿：「這必須即時完成，因為每一輪大約一微秒。」「這裡的解碼器是真的最小權重配對，不是預錄的。」
- 第 50 頁（只用於「數百到上千」的範圍）：「要到 10−6：d ≈ 27（~1,500 個實體量子位元 / 邏輯位元）」

## animations/transmon-3d.html 第 10 章（#surface）

- 圖例：「圓球＝資料位元（紅 X 錯誤、藍 Z 錯誤、紫 Y 錯誤）；小方塊＝量測位元；青色格子＝Z 穩定子（抓 X 錯誤）、琥珀色格子＝X 穩定子（抓 Z 錯誤）；格子亮起＝該穩定子量到 −1；白線＝解碼器的配對。」
- ①「平常所有穩定子都量到 +1（不亮）。一旦某處出錯，相鄰的穩定子就會『亮』起來」
- ②「每 1 μs 跑一個『表面碼週期』。先把所有量測位元重設到 |0⟩」「接著 4 層 CZ／CNOT…把奇偶加總到自己身上」「資料位元全程不被量測」「和上一輪比較，有變化的地方叫『偵測事件』」
- ③「含 D5 的兩個青色格子（Z 穩定子）亮了」「解碼器只看得到亮點。它把兩個亮點配成一對（白線），最短路徑正好經過 D5」
- ④「Y 錯誤＝同時有 X 和 Z（紫色）。在 D5 注入 Y：兩個青色、兩個琥珀色格子同時亮」「表面碼同時防 X、Z 兩種錯誤，這是 3 位元重複碼做不到的」
- ⑤「落單的亮點，代表錯誤鏈的另一端接在邊界上。解碼器把它配到最近的邊界」
- ⑥「D1、D4 在同一個青色格子裡，兩個翻轉互相抵消，它沒亮；只有左邊界的半圓（含 D4、D7）亮了」「於是在 D7 補 X」「結果 D1、D4、D7 整行都是 X：所有穩定子都不亮，但這正好是邏輯 X——邏輯位元被翻轉了，而且沒人發現！」
- ⑧ 按鈕：`data-d10` 3（17 顆）／5（49 顆）／7（97 顆）、`g10dec`「解碼並修正」、`g10rnd`「隨機錯誤」、`g10clr`「清除錯誤」、`g10mc`「跑 300 次統計」；點資料位元依序 X → Z → Y → 清除
- 控制：`#g10steps`（數字按鈕 1–8）、`#g10auto`「自動接續」（預設勾選）
