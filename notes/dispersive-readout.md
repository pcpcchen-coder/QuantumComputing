## 0. 一句話說明

量子位元不直接量。我們把它耦合到一個微波諧振腔，量子位元的狀態會讓諧振腔的頻率往左或往右偏一點。接著打一個微弱的微波去探測諧振腔，看回來的訊號相位和振幅變了多少，就知道量子位元是 |0⟩ 還是 |1⟩。

可以想成在敲一個鈴：鈴裡面的東西（量子位元）不同，敲出來的音高就不同。我們只聽音高，不去打開鈴。

---

## 1. 為什麼要這樣讀？

- **訊號太小**：transmon 的躍遷頻率約 4–6 GHz，單一光子的能量只有約 20 μeV，直接偵測它的能量幾乎不可能。
- **直接量會破壞狀態**：如果直接從量子位元取出能量，它就會弛豫或被激發到別的能階。
- **色散讀取是 QND 量測**：它不交換能量，只讓頻率偏移，所以是**量子非破壞性量測**（Quantum Non-Demolition）。量完之後，量子位元會停在量到的那個狀態，可以重複再量，也可以直接拿來做錯誤更正的回饋。

## 2. 物理原理

### 2.1 量子位元與諧振腔的耦合：Jaynes–Cummings 模型

晶片上的 transmon 透過電容耦合到一段共平面波導（CPW）諧振腔，通常是 λ/4 型：

$$
H = \hbar\omega_r a^\dagger a + \tfrac{1}{2}\hbar\omega_q \sigma_z + \hbar g\,(a^\dagger\sigma^- + a\,\sigma^+)
$$

| 符號 | 意義 | 典型值 |
|---|---|---|
| ω_r | 諧振腔頻率 | 6–8 GHz |
| ω_q | 量子位元頻率 | 4–6 GHz |
| g | 耦合強度 | g/2π ≈ 50–200 MHz |
| κ | 諧振腔線寬（光子漏到外面傳輸線的速率） | κ/2π ≈ 0.5–10 MHz |

### 2.2 進入「色散區」

條件是失諧量遠大於耦合強度：

$$|\Delta| = |\omega_q - \omega_r| \gg g$$

這時兩者不會真正交換能量（不做真空 Rabi 振盪），只會互相「推」頻率。做二階微擾展開（Schrieffer–Wolff 轉換）後：

$$
\boxed{H \approx \hbar(\omega_r + \chi\sigma_z)\,a^\dagger a + \tfrac{1}{2}\hbar(\omega_q + \chi)\,\sigma_z}
$$

χ 叫做**色散位移**：

- 理想二能階系統：χ = g²/Δ
- transmon 要算進 |2⟩ 能階（α 是非諧性）：

$$\chi = \frac{g^2}{\Delta}\cdot\frac{\alpha}{\Delta+\alpha}$$

> **定義的陷阱**：不同文獻對 χ 的定義會差一個 2 倍。本筆記用「腔頻率 = ω_r ± χ」，兩個狀態之間的總頻率差是 **2χ**。也有論文把總頻率差寫成 χ，看論文時要先確認它用哪一種。

### 2.3 同一個式子的兩種讀法

把 χσ_z a†a 這一項分別歸給諧振腔或量子位元，會得到兩種物理圖像：

| 角度 | 意義 | 後果 |
|---|---|---|
| 從諧振腔看 | 位元在 \|0⟩ 時，腔頻率是 ω_r − χ；在 \|1⟩ 時是 ω_r + χ | **讀取就是靠這個** |
| 從位元看 | 腔裡每多一個光子，位元頻率就偏移 2χ（AC Stark shift） | 讀取光子會讓量子位元去相干（見 2.6） |

### 2.4 數值例子

Δ/2π = 5 − 7 = −2 GHz：

$$
\frac{\chi}{2\pi} = \frac{(0.1)^2}{-2}\cdot\frac{-0.25}{-2.25} \approx -0.556\ \text{MHz}
\qquad\Rightarrow\qquad 2\chi/2\pi \approx -1.11\ \text{MHz}
$$

也就是說，兩個狀態下的諧振腔頻率只差約 **1.1 MHz**，而諧振腔本身在 **7 GHz**，相對差約 1.6 × 10⁻⁴。我們要分辨的正是這麼小的頻率差。

### 2.5 頻率差怎麼變成看得到的訊號？

1. **送探測脈衝**：在兩個頻率（ω_r ± χ）的正中間送入一個微波脈衝。
2. **相位與振幅改變**：諧振腔頻率不同，穿透（S21）或反射（S11）訊號的相位就不同，振幅也可能不同。以穿透量測為例：

   $$S_{21}(\omega_p) = \frac{1}{1 + 2i(\omega_p - \omega_\text{res})/\kappa}$$

   掃頻時，S21 在複數平面上畫出一個圓。探測點放在正中間時，兩個狀態的相位分別是 ±arctan(2χ/κ)。
3. **下變頻成 IQ**：輸出訊號經過放大、下變頻後，拆成 I（同相）和 Q（正交）兩個分量，在 IQ 平面上就是一個點。
4. **積分**：把訊號積分一段時間 τ（約 100 ns–1 μs），每量一次（single shot）得到一個 (I, Q) 點。
5. **判別**：重複幾千次之後，|0⟩ 和 |1⟩ 會形成兩團高斯分布。中間畫一條閾值線，就能判斷每一次量到的是 0 還是 1。

**最佳條件是 2χ ≈ κ**。下表是兩個狀態在 IQ 平面上的距離（S21 圓的直徑設為 1）：

| 2χ/κ | 兩狀態相位差 | IQ 平面距離 |
|---|---|---|
| 0.25 | 28° | 0.47 |
| 0.5 | 53° | 0.80 |
| **1** | **90°** | **1.00（最大）** |
| 2 | 127° | 0.80 |
| 4 | 152° | 0.47 |

直覺上：χ 太小，兩個頻率擠在同一個共振峰裡，看不出差別；κ 太小，兩個共振峰各自很窄，探測點離兩邊都太遠，訊號只會被反射回來。兩者相當時，探測點剛好落在兩個共振峰的半高處，相位差 90°。

在上面的數值例子裡，最佳的 κ/2π ≈ 1.1 MHz。

### 2.6 讀取的代價：量測反作用

腔裡的光子數有量子漲落，這會透過 AC Stark shift 讓量子位元頻率隨機抖動，造成**量測引發的去相干**。在穩態下，

$$\Gamma_m = \frac{\kappa}{2}\,|\alpha_0 - \alpha_1|^2$$

這裡的 α₀、α₁ 是兩個狀態下腔內的相干態振幅。這個式子很有物理意義：**兩個狀態越分得開（越容易讀），量子位元的疊加態就越快被破壞**。資訊被取出的速率和疊加態被破壞的速率是同一件事，這正是量子量測的本質。

以數值例子、腔內約 10 個光子、2χ = κ 計算，Γ_m/2π ≈ 11 MHz，疊加態在約 15 ns 內就被破壞了。也因此，讀取光子在不讀取時一定要徹底清空，否則會一直傷害量子位元的 T2。

## 3. 設計上的取捨與限制

| 問題 | 說明 | 數值例子 | 解法 |
|---|---|---|---|
| 光子數不能太多 | 腔內光子數超過臨界值 n_crit = Δ²/4g² 之後，色散近似會失效，還會引發不想要的能階躍遷（measurement-induced state transitions） | n_crit ≈ 100 | 讀取功率控制在幾個到幾十個光子 |
| Purcell 效應 | 量子位元會經由諧振腔漏能，衰減速率 γ_P ≈ κ(g/Δ)²，會縮短 T1 | κ/2π = 1.1 MHz 時，T1 上限只有約 57 μs | 加 **Purcell 濾波器**（帶通濾波器，只讓讀取頻率通過，擋住量子位元頻率） |
| 訊號極弱 | 晶片端的讀取功率約 −120 到 −130 dBm；HEMT 的雜訊溫度約 3 K，在 7 GHz 相當於約 9 個雜訊光子 | 腔內 10 個光子 ≈ −125 dBm | 第一級改用接近量子極限的放大器（JPA/TWPA），雜訊約 0.5 個光子 |
| 讀取時間與 T1 互相拉扯 | 讀得越久越準，但位元也越可能在讀取途中衰減（\|1⟩ → \|0⟩） | — | 提高 κ（搭配 Purcell 濾波器）、使用量子極限放大器、最佳化積分權重 |
| 熱光子 | 輸入線上殘留的熱光子會讓腔頻率亂跳，造成去相干 | 7 GHz 光子的 hf/k_B ≈ 0.34 K | 輸入線分級衰減，總共約 −60 到 −70 dB |
| 多顆位元 | 每顆都配一條讀取線太浪費 | — | **頻率多工**：每顆位元配一個不同頻率的諧振腔，共用一條饋入線；室溫端用一組 ADC 同時解調多個頻率 |

目前的業界水準是在約 100–300 ns 內做到 99% 以上的讀取保真度。

## 4. 需要哪些設備？（整條讀取鏈）

```
【室溫 ~300 K】
 LO 訊號源 ─┐
 AWG/DAC ──→ IQ 混頻器（上變頻）→ 衰減/濾波
                                      │ 輸入線
【稀釋冷凍機】                         ▼
 50 K  ─────────────── （熱錨定）
 4 K   ─────────────── 衰減器 −20 dB
 Still ─────────────── 衰減器 −10 dB
 MXC ~10 mK ────────── 衰減器 −20 dB → 低通 / Eccosorb 紅外濾波
                                      ▼
                 ┌──── 樣品盒（磁屏蔽）──────┐
                 │ 晶片：饋入線 + 讀取諧振腔 │
                 │ + Purcell 濾波器 + transmon│
                 └───────────────────────────┘
                                      │ 輸出線
 MXC ─── 環行器/隔離器（2–3 級）← JPA / TWPA（需泵浦訊號、磁通偏壓）
                                      │ NbTi 超導同軸線
 4 K ─── HEMT 低雜訊放大器（約 +40 dB，雜訊溫度約 2–4 K）
                                      ▼
【室溫】 室溫 LNA（+30~40 dB）→ IQ 混頻器（下變頻，與上變頻共用同一個 LO）
        → 濾波 → ADC 數位化 → FPGA（解調、加權積分、閾值判斷、即時回饋）
```

設計原則是：**輸入線「讓訊號下去、讓熱雜訊上不來」；輸出線「讓訊號上去、讓放大器的雜訊回不來」**。

### 4.1 晶片端（讀取元件本身）

| 元件 | 說明 |
|---|---|
| 讀取諧振腔 | CPW λ/4 或 λ/2 諧振腔，常用 Nb、Al 或 TiN 薄膜做在藍寶石或高阻矽基板上 |
| 饋入線（feedline） | 多個讀取諧振腔共用的傳輸線，方便頻率多工 |
| Purcell 濾波器 | 抑制量子位元經由讀取腔漏能 |
| 耦合電容 | 決定 g（位元–腔）與 κ（腔–饋入線） |
| 樣品盒與封裝 | 無氧銅或鋁製樣品盒，打線或 flip-chip 封裝 |
| 磁屏蔽 | μ-metal 加超導屏蔽，擋住外部磁場與磁通雜訊 |

### 4.2 低溫端（稀釋冷凍機內）

| 設備 | 位置 | 作用 |
|---|---|---|
| 稀釋冷凍機 | — | 底板（MXC）溫度約 10 mK |
| 分級衰減器 | 4 K、Still、MXC | 輸入線總共約 −60 到 −70 dB，把室溫熱雜訊壓下來 |
| 低通濾波器、Eccosorb 紅外濾波器 | MXC | 濾掉高頻雜訊與紅外輻射（會產生準粒子） |
| 環行器/隔離器 | MXC | 擋住放大器的雜訊和泵浦訊號，不讓它們回灌到晶片 |
| JPA（約瑟夫森參量放大器） | MXC | 接近量子極限，頻寬較窄 |
| TWPA（行波參量放大器） | MXC | 接近量子極限且頻寬寬，適合頻率多工 |

| 同軸線 | 各級之間 | 輸入用不鏽鋼或 CuNi（導熱差）；輸出 MXC→4 K 段用 NbTi 超導線（損耗低又不導熱） |

| 設備 | 作用 |
|---|---|
| 微波訊號源（LO） | 上變頻與下變頻共用同一個 LO，相位才會一致 |
| 泵浦源 | 給 JPA/TWPA 提供泵浦訊號 |

常見的整合平台：Zurich Instruments SHFQA/UHFQA、Quantum Machines OPX、Qblox QRM、Keysight、QICK（Xilinx RFSoC）。

### 4.4 特性量測用的儀器

- **向量網路分析儀（VNA）**：掃 S21，用來找諧振腔頻率、量 κ 和 χ、做 punch-out 實驗。
- **頻譜分析儀**：檢查泵浦訊號、雜訊與雜散。

## 5. 實驗室實際的校準流程

1. **諧振腔頻譜**：用 VNA 掃 S21，找出每個讀取腔的頻率。
2. **Punch-out**：把讀取功率加大，腔頻率會跳回裸頻率 ω_r，以此確認這個諧振腔真的耦合著一顆量子位元。
3. **量子位元頻譜**：做兩音頻譜（two-tone spectroscopy），找出 ω_q。
4. **量測色散位移**：分別讓位元在 |0⟩ 和 |1⟩（先打一個 π 脈衝），各掃一次 S21，兩條曲線的頻率差就是 2χ。
5. **優化讀取參數**：調讀取頻率、功率、脈衝長度和積分權重。
6. **單發直方圖**：在 IQ 平面上畫出兩團分布，算出指派保真度矩陣 P(0|0)、P(1|1)。

讀取錯誤的主要來源：讀取途中的 T1 衰減、殘留熱激發（初始態不是純 |0⟩）、放大器雜訊（量測效率 η 不夠高），以及功率過高引起的能階躍遷。

---

## 一句話總結

> **色散讀取 = 讓量子位元「調音」諧振腔，再聽諧振腔的音高。**
> 失諧 |Δ| ≫ g 時，諧振腔頻率依位元狀態偏移 ±χ；在兩頻率中間送入探測微波，輸出訊號的相位差在 IQ 平面上分成兩團，2χ ≈ κ 時分得最開。整條讀取鏈從晶片上的諧振腔與 Purcell 濾波器開始，經過 mK 級的環行器與量子極限放大器、4 K 的 HEMT，最後由室溫的混頻器、ADC 與 FPGA 完成解調與判別。

## 附：數值計算程式

```python
import numpy as np

h = 6.62607015e-34; hbar = h / 2 / np.pi; kB = 1.380649e-23
fq, fr, g, alpha = 5.0, 7.0, 0.100, -0.250      # GHz（皆為 ω/2π）

D = fq - fr
chi = g**2 / D * alpha / (D + alpha)            # 腔頻率 = fr ± chi
kappa = 2 * abs(chi)                            # 最佳條件 2χ = κ
ncrit = D**2 / (4 * g**2)
gP = kappa * (g / D)**2                         # Purcell 衰減率 γ/2π
print(f"chi = {chi*1e3:.3f} MHz, 2chi = {2*chi*1e3:.3f} MHz, kappa(opt) = {kappa*1e3:.3f} MHz")
print(f"n_crit = {ncrit:.0f}, Purcell T1 limit = {1/(2*np.pi*gP*1e9)*1e6:.0f} us")

# 穿透 S21 = 1/(1 + 2i(ω_p - ω_res)/κ)，探測點放在兩個頻率正中間
for x in [0.25, 0.5, 1, 2, 4]:                  # x = 2χ/κ
    s0 = 1 / (1 + 1j * x); s1 = 1 / (1 - 1j * x)
    print(f"2chi/kappa = {x:<4}: 相位差 {np.degrees(np.angle(s1/s0)):6.1f} deg, "
          f"IQ 距離 {abs(s1 - s0):.3f}")

nbar = 10
P = nbar * hbar * 2*np.pi*fr*1e9 * 2*np.pi*kappa*1e9
print(f"7 GHz 光子 hf/kB = {h*fr*1e9/kB:.3f} K; 腔內 {nbar} 光子 ≈ {10*np.log10(P/1e-3):.0f} dBm")
# chi = -0.556 MHz, 2chi = -1.111 MHz, kappa(opt) = 1.111 MHz
# n_crit = 100, Purcell T1 limit = 57 us
# 2chi/kappa = 1: 相位差 90.0 deg, IQ 距離 1.000
# 7 GHz 光子 hf/kB = 0.336 K; 腔內 10 光子 ≈ -125 dBm
```
