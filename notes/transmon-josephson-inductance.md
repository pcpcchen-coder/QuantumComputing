## 1. JJ 為什麼是電感？從兩條方程式推出來

約瑟夫森方程式（見前一篇）：

$$I = I_c \sin\varphi \qquad\qquad V = \frac{\Phi_0}{2\pi}\frac{d\varphi}{dt}, \quad \Phi_0 = \frac{h}{2e}$$

對第一式取時間微分：

$$\frac{dI}{dt} = I_c\cos\varphi\,\frac{d\varphi}{dt} = I_c\cos\varphi\cdot\frac{2\pi}{\Phi_0}V$$

整理成電感的定義形式 V = L·dI/dt：

$$\boxed{V = \underbrace{\frac{\Phi_0}{2\pi I_c\cos\varphi}}_{L_J(\varphi)}\frac{dI}{dt}}
\qquad L_{J0} = \frac{\Phi_0}{2\pi I_c}$$

所以 JJ 的**電壓與電流變化率成正比**，行為就是一個電感，只是這個電感值會隨相位 φ 改變。

### 這個電感的能量從哪來？

一般線圈把能量存在**磁場**。JJ 的能量則存在**兩邊超導波函數的相位耦合**中：

$$U(\varphi) = E_J(1-\cos\varphi), \qquad E_J = \frac{\Phi_0 I_c}{2\pi}$$

在 φ 很小時展開：

$$U(\varphi) \approx \underbrace{\frac{E_J}{2}\varphi^2}_{\text{像線性電感}} \;-\; \underbrace{\frac{E_J}{24}\varphi^4}_{\text{非線性修正}} + \cdots$$

把 φ 換成磁通 Φ = (Φ₀/2π)φ，二次項正是 Φ²/2L_{J0}。所以**小振幅時它是普通電感，大振幅時它「變軟」**。這種電感屬於**動感電感（kinetic inductance）**，來源是庫柏對的慣性與相位剛性，而不是磁場。

### JJ 電感的行為

| 行為 | 公式 / 說明 |
|---|---|
| 隨相位變化 | L_J(φ) = L_{J0} / cos φ |
| 隨電流變化 | L_J(I) = L_{J0} / √(1 − (I/I_c)²)，電流越接近 I_c，電感越大 |
| φ = π/2（I = I_c） | L_J → ∞，超過 I_c 後跳到有電壓的耗散態（量子位元必須遠離這區） |
| π/2 < φ < π | L_J < 0（負電感），在 SQUID、rf-SQUID 等電路中會用到 |
| 可調 | 兩個 JJ 並聯成 SQUID：I_c,eff(Φ) = 2I_c\|cos(πΦ_ext/Φ₀)\|，外加磁通就能調電感 |
| 無耗散 | 在能隙頻率（Al 約 80–100 GHz）以下不吸收能量 |

**數值範例**：E_J/h = 15 GHz → I_c ≈ **30 nA**，L_{J0} ≈ **10.9 nH**。

### 為什麼要用 JJ 取代線性電感？

| 理由 | 說明 |
|---|---|
| **① 非線性** | 線性 LC 的能階等距，微波會一路往上激發，無法只挑出兩個能階；JJ 的 −E_J cos φ 讓能階**不等距**。 |
| **② 無耗散** | 二極體、電晶體也有非線性，但會耗能，耗能就會破壞量子相干。JJ 是目前已知**唯一同時「非線性」又「無耗散」**的電路元件。 |
| **③ 體積極小** | 約 100 nm × 200 nm 的接面就有約 10 nH。要用線圈做出 10 nH 需要毫米等級的繞線，還會帶來寄生電容與損耗。 |
| **④ 可調** | 用 SQUID 搭配磁通偏壓線，可以在實驗中即時調整頻率。 |

### 直覺圖像：量子單擺

−E_J cos φ 和單擺的位能 −mgl cos θ 長得一模一樣：

| Transmon | 單擺 |
|---|---|
| 相位 φ | 擺角 θ |
| 庫柏對數 n | 角動量 |
| E_J（相位耦合） | mgl（重力回復力） |
| E_C（充電能） | 1/轉動慣量 |

E_J/E_C 很大就像一個很重、擺幅很小的擺：它**幾乎**是簡諧振盪，但因為 cos 位能在邊緣比拋物線平坦，振幅越大頻率越低。這「一點點」不簡諧，就是量子位元的關鍵。

在範例參數下，相位的零點擾動只有 φ_zpf = (2E_C/E_J)^{1/4} ≈ **0.43 rad**，所以四次項只是小修正。這就是為什麼非諧性約等於 E_C，只有基頻的 5% 左右。

## 2. Transmon 電路長什麼樣子？

### 等效電路

```
            ┌──── C_g ──── 讀取共振腔 (λ/4, ~7 GHz) ── 饋線 (feedline) → 放大器
            │
   島 ●─────┼──── C_d ──── XY 驅動線（微波脈衝）
            │
          ┌─┴─┐
   C_Σ ═══╡   ╞═══ JJ（或 SQUID：兩個 JJ 並聯 ← Z 磁通線）
          └─┬─┘
            │
           ⏚ 地
```

核心只有兩個元件並聯：**一個 JJ（非線性電感）＋一個大電容 C_Σ**。

$$\hat H = 4E_C(\hat n - n_g)^2 - E_J\cos\hat\varphi, \qquad E_C = \frac{e^2}{2C_\Sigma}$$

名字 transmon 來自 *transmission-line shunted plasma oscillation qubit*（Koch et al., 2007）。最關鍵的設計就是「用大電容把 JJ 並聯起來」。

### 實際晶片上的樣子

| 部件 | 實際形狀 | 作用 |
|---|---|---|
| **電容板** | 十字形（Google Xmon）或兩塊並排的方形金屬板（IBM 等），數百 μm 大小 | 提供 C_Σ ≈ 70–100 fF，壓低 E_C |
| **約瑟夫森結** | Al / AlOx / Al，面積約 0.01–0.04 μm²，以雙角度陰影蒸鍍（Dolan bridge 或 Manhattan 製程）製作 | 非線性電感 |
| **SQUID 迴路**（可調型） | 兩個 JJ 圍成數 μm 的小迴路 | 用磁通調 E_J，進而調頻率 |
| **讀取共振腔** | 蜿蜒（meander）的共面波導，λ/4 長度，約 6–8 GHz | 色散讀取 |
| **Purcell 濾波器** | 共振腔與饋線之間的另一段濾波器 | 防止量子位元經由讀取線漏能 |
| **饋線** | 一條共面波導串接多個讀取共振腔 | 頻率多工讀取 |
| **XY 線 / Z 線** | 靠近電容板 / SQUID 的終端線 | 微波驅動 / 磁通調頻 |
| **耦合器** | 兩個量子位元之間的電容，或可調耦合器（本身也是一個 transmon 或 SQUID） | 雙量子位元閘 |
| **材料** | 藍寶石或高阻矽基板；電容板用 Al、Nb 或 Ta（Ta 表面氧化物較乾淨，T1 較長） | 減少介電損耗 |

外部環境：稀釋冷凍機 **10–20 mK**。原因是 hf/k_B 在 5 GHz 時約 0.24 K，溫度必須遠低於此，熱激發才可忽略；同時也要遠低於 Al 的超導臨界溫度 1.2 K。讀取訊號先經過 mK 級的量子極限放大器（JPA/TWPA），再進入 4 K 的 HEMT 放大器。

大型處理器另外會用**覆晶（flip-chip）、凸塊接合、矽穿孔**等 3D 整合技術，把控制線從另一層晶片接進來。

### 大十字電容的作用

十字金屬板就是 transmon 的**並聯電容 C_Σ**。它做四件事：前三件是物理作用，第四件是佈線需要。

> 3D 動畫第 1 章的「大十字電容的作用」分頁可以拖動 C_Σ，即時看 E_C、頻率、非諧性與電荷色散怎麼變（[`animations/transmon-3d.html#capacitor`](../animations/transmon-3d.html#capacitor)）。

#### ① 主要作用：壓低充電能 E_C，擋掉電荷雜訊

$$\hat H = 4E_C(\hat n - n_g)^2 - E_J\cos\hat\varphi,\qquad E_C = \frac{e^2}{2C_\Sigma}$$

其中 n_g 是環境裡亂跳的背景電荷，它是電荷雜訊的來源。

| | 只靠 JJ 本身的電容 | 加上大十字 |
|---|---|---|
| 電容 | 約 1–2 fF（接面只有約 0.02 μm²） | **約 77.5 fF** |
| E_C/h | 約 10–20 GHz | **250 MHz** |
| E_J/E_C | 約 1 | **約 60** |
| 頻率隨背景電荷的漂移 | 數百 MHz，比非諧性還大 | **約 1.9 kHz** |

電容加大後 E_C 變小，電荷雜訊造成的頻率漂移隨 √(8E_J/E_C) **指數下降**，背景電荷怎麼跳，頻率幾乎都不動。沒有這塊大電容，這顆元件就只是早期的 Cooper pair box，相干時間只有奈秒等級（數值見第 3 節的「機制二」）。

單擺比喻：**電容就是擺錘的質量**。擺錘越重，量子擾動越小，越不容易被外界的小推力影響。

#### ② 和 JJ 一起決定頻率與非諧性

把 transmon 看成 LC 振盪器，電容就是其中的 C：

- 頻率：f₀₁ ≈ √(8E_J E_C) − E_C ≈ 1/(2π√(L_J C_Σ))，範例為 5.21 GHz。
- 非諧性：**α ≈ −E_C**，由電容大小直接決定。

所以電容不能無限加大，要在兩件事之間取捨：

- **電容太小**：E_C 大，電荷雜訊嚴重。
- **電容太大**：E_C 小，α 跟著變小。|1⟩→|2⟩ 與 |0⟩→|1⟩ 的頻率太接近，脈衝容易把狀態推上 |2⟩，閘操作只能放慢。

實務上把 E_J/E_C 取在 50–100，70–100 fF 的電容大約落在這個範圍。

#### ③ 存放電場能量，也決定損耗

量子位元振盪時，能量在兩個地方之間來回交換：

- **電場能量**：島上的電荷，存在電容。
- **相位能量**：JJ 的 −E_J cos φ。

大部分電場集中在十字板與接地面之間的間隙。金屬表面的氧化層裡有缺陷（TLS），電場碰到它們就會被吸收能量，這是 T₁ 的主要限制之一。

所以電容板做到數百 μm、間隙也不能太窄，目的是把電場**攤開到大空間**，讓穿過表面缺陷的電場比例（表面參與比）變小，T₁ 才會長。改用 Ta 這類氧化層較乾淨的材料，處理的也是同一個問題。

#### ④ 為什麼是十字形：四隻手臂各接一個東西

同樣的電容量也能做成方塊，做成十字是佈線考量。以 Google 的 Xmon 為例：

| 手臂 | 連接對象 | 耦合方式 |
|---|---|---|
| 上 | 讀取共振腔 | 小電容耦合（色散讀取） |
| 左 | XY 驅動線 | 小電容耦合（送微波脈衝） |
| 下 | SQUID → 接地 | 直接連接（JJ 在這裡） |
| 右（或其他方向） | 相鄰的量子位元或可調耦合器 | 小電容耦合（雙位元閘） |

二維格子上每個量子位元要和上下左右的鄰居耦合（表面碼需要這種最近鄰連接），十字的四隻手臂剛好伸向四個方向。調整每隻手臂末端和對象的距離，就能分別設定讀取耦合 g、驅動強度與位元間耦合，彼此不太干擾。

IBM 的設計常用**兩塊並排的方形電容板**（浮接式，兩端都不接地）。物理作用一樣，只是幾何與耦合方式不同。

> **一句話：** 大十字電容讓 transmon「變重」以免被電荷雜訊推動；它和 JJ 一起決定頻率與非諧性；它把電場攤開以降低損耗；四隻手臂則各自接到讀取、驅動、接地與鄰居。

### 兩種主流設計路線（典型做法）

| | 固定頻率 transmon | 可調頻率 transmon |
|---|---|---|
| JJ | 單一 JJ | SQUID（兩個 JJ） |
| 優點 | 對磁通雜訊不敏感，相干時間長 | 頻率可調，能避開頻率碰撞，閘操作彈性大 |
| 雙量子位元閘 | 交叉共振（cross-resonance，以微波驅動） | 調頻讓 \|11⟩ 與 \|20⟩ 共振 → CZ 閘；或用可調耦合器 |
| 代表 | IBM 早期 Falcon / Eagle | Google Sycamore / Willow；IBM Heron 改用可調耦合器 |

## 3. 量子位元是怎麼實現的？

### 機制一：非諧性 → 只挑出兩個能階

| | 線性 LC 諧振子 | Transmon（範例參數，數值解） |
|---|---|---|
| E₁ − E₀ | 5.477 GHz | **5.214 GHz** |
| E₂ − E₁ | 5.477 GHz | **4.931 GHz** |
| 非諧性 α | 0 | **−283 MHz**（近似公式 α ≈ −E_C = −250 MHz） |

以 5.214 GHz 的微波驅動時，只有 |0⟩↔|1⟩ 共振；|1⟩↔|2⟩ 差了 283 MHz，**不共振**。於是最低的兩個能階形成一個量子位元。

近似公式：

$$\hbar\omega_{01} \approx \sqrt{8E_JE_C} - E_C, \qquad \alpha \approx -E_C$$

### 機制二：大電容 → 對電荷雜訊免疫

早期的 Cooper pair box（E_J/E_C ≈ 1）頻率會隨背景電荷 n_g 劇烈漂移，相干時間只有奈秒等級。Transmon 加上大電容之後：

- **電荷色散**（頻率隨 n_g 的漂移）**隨 √(8E_J/E_C) 呈指數下降**
- **非諧性**只以**冪次**緩慢下降

| E_J/E_C | f₀₁（E_C = 250 MHz） | 電荷色散（f₀₁ 隨 n_g 的最大漂移） | 非諧性 α |
|---|---|---|---|
| 1 | 0.64 GHz | 776 MHz（比頻率本身還大） | — |
| 10 | 1.94 GHz | 62.8 MHz | −353 MHz |
| 30 | 3.60 GHz | 448 kHz | −304 MHz |
| **60** | **5.21 GHz** | **1.9 kHz** | **−283 MHz** |
| 100 | 6.81 GHz | 6.3 Hz | −274 MHz |

E_J/E_C 從 10 提高到 60，電荷色散縮小約 3 萬倍，非諧性卻只少了兩成。**這就是 transmon 的設計精髓：犧牲一點非諧性，換來對電荷雜訊幾乎完全免疫。**

這也呼應前一篇提到的「相位與電荷是共軛變數」：transmon 讓相位相對確定、電荷大幅擾動，所以背景電荷的影響就被抹平了。

### 機制三：控制與讀取（電路量子電動力學，cQED）

| 操作 | 方法 | 典型數值 |
|---|---|---|
| **X / Y 旋轉** | 透過 XY 線送入頻率 f₀₁ 的微波脈衝，產生 Rabi 振盪；脈衝相位決定繞 X 或 Y 軸 | 20–50 ns；用 **DRAG** 脈衝整形，抑制漏到 \|2⟩ |
| **Z 旋轉** | 多數用「虛擬 Z」（只改後續脈衝的相位，零時間、零誤差）；可調型也可用磁通 | ~0 ns |
| **讀取** | **色散讀取**：量子位元與共振腔失諧 Δ，共振腔頻率會依位元狀態偏移 ±χ。送入探測微波，從反射或穿透訊號的相位與振幅判斷 \|0⟩ 或 \|1⟩ | g/2π ≈ 100 MHz、Δ/2π ≈ −1.8 GHz → χ/2π ≈ −0.77 MHz；讀取約數百 ns |
| **雙位元閘** | CZ：讓 \|11⟩ 與 \|20⟩ 短暫共振，累積 π 相位（**用到了 \|2⟩ 能階**）；或交叉共振、iSWAP | 30–60 ns；目前最佳保真度可達 99.9% 等級 |

色散偏移公式（transmon 版本，因為 \|2⟩ 能階也參與）：

$$\chi = \frac{g^2}{\Delta}\cdot\frac{\alpha}{\Delta+\alpha}$$

### 機制四：低損耗 → 足夠長的相干時間

| 指標 | 典型值 | 主要限制 |
|---|---|---|
| T1（能量弛豫） | 100–300 μs；Ta 材料的實驗室紀錄可達毫秒等級 | 表面氧化層中的二能階缺陷（TLS）、準粒子、輻射 |
| T2（相位相干） | 與 T1 同量級 | 磁通雜訊（可調型）、熱光子造成的去相位 |

## 一句話總結

> **Transmon = 一個無耗散的非線性電感（JJ）＋ 一個大電容。**
> JJ 的 −E_J cos φ 讓能階不等距，於是可以只挑出 |0⟩、|1⟩；大電容讓 E_J/E_C ≈ 50–100，電荷雜訊被指數壓制，非諧性卻只小幅下降；最後用微波控制、用共振腔色散讀取。

## 附：數值計算程式

```python
import numpy as np

def levels(EJ, EC, ng, N=40, k=4):
    """電荷基底下對角化 H = 4EC(n-ng)^2 - EJ cos(phi)，回傳最低 k 個能階（單位同 EJ, EC）"""
    n = np.arange(-N, N + 1)
    H = np.diag(4 * EC * (n - ng) ** 2) \
        - EJ / 2 * (np.eye(2 * N + 1, k=1) + np.eye(2 * N + 1, k=-1))
    return np.linalg.eigvalsh(H)[:k]

E = levels(EJ=15, EC=0.25, ng=0)   # GHz
E -= E[0]
print("f01 =", E[1], "GHz;  alpha =", (E[2] - E[1]) - E[1], "GHz")
# f01 = 5.214 GHz;  alpha = -0.283 GHz
```
