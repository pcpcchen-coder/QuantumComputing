量子電路入門 · 理論基礎

看電路之前的 6 堂課

量子電路的每一個閘，都在改變一組叫做「振幅」的數字。先把振幅、相位、量測、閘、多位元與干涉這六件事弄清楚，再去看〈十個基礎量子電路〉，就會知道每一步在做什麼。每堂課右邊的圖都可以拖拉、點按。

位元字串的寫法和 Qiskit 相同：q0 寫在最右邊，例如 |01⟩ 代表 q1 = 0、q0 = 1。

第 1 課

量子位元：兩個振幅

古典位元不是 0 就是 1。量子位元的狀態要用兩個數字描述，稱為振幅：

|ψ⟩ = α|0⟩ + β|1⟩ = (α, β)ᵀ
|α|² + |β|² = 1
  • |0⟩ = (1, 0)ᵀ、|1⟩ = (0, 1)ᵀ 是兩個「基底態」，就像 x、y 軸。
  • α、β 同時不為 0 時稱為疊加：不是「其實是 0 只是不知道」，而是兩個振幅都真的存在。
  • 量到 0 的機率是 |α|²，量到 1 的機率是 |β|²；所以振幅平方加起來一定是 1（正規化）。
  • 任何單一量子位元都可以寫成 α = cos(θ/2)、β = sin(θ/2)·eiφ，對應到 Bloch 球上的一個點：θ 是離北極的角度。

拖動 θ：Bloch 向量從北極（|0⟩）轉到南極（|1⟩），兩根長條的平方和永遠是 1。

量到 0 的機率 |α|²
量到 1 的機率 |β|²
|α|² + |β|²
第 2 課

相位：量不到，卻能干涉

振幅是複數，除了大小還有方向（相位）。把 β 寫成 sin(θ/2)·eiφ，φ 就是相對相位：

|ψ⟩ = cos(θ/2)|0⟩ + eiφ sin(θ/2)|1⟩
  • 改變 φ，|α|²、|β|² 都不變：直接量測看不出相位。
  • 但在 Bloch 球上，φ 讓向量繞 z 軸轉，|+⟩（φ = 0°）和 |−⟩（φ = 180°）指向相反方向。
  • 先做一個 H 再量測（等於「沿 x 方向量」），量到 0 的機率變成 (1 + sinθ·cosφ)/2，相位就看得到了。這就是干涉。
  • 兩個振幅同時乘上同一個 eiγ（全域相位）則完全沒有影響，任何量測都分不出來。

固定 θ = 90°，拖動 φ：左邊的機率不動，右邊「先做 H 再量」的機率從 100% 變到 0%。

直接量：量到 0
直接量：量到 1
先做 H 再量：量到 0
先做 H 再量：量到 1
第 3 課

量測：Born 規則與塌縮

量測是我們從量子電腦拿到答案的唯一方法，規則只有三條：

  • Born 規則：量到結果 k 的機率 = |振幅ₖ|²。
  • 只拿到一個結果：一次量測只會得到 0 或 1，振幅本身永遠看不到。
  • 塌縮：量完之後狀態變成剛量到的那個基底態，原本的疊加消失；不重新準備就再量，結果一定一樣。

所以要知道機率，就得把同一個電路重複跑很多次（shots）。跑 N 次，估計值的誤差大約是 1/√N：1,000 次約 ±3%。

按「量測 1 次」幾下，結果是隨機的；按「量測 1,000 次」，次數會貼近理論機率（灰色底）。

第 4 課

量子閘：可逆的旋轉（么正矩陣）

量子閘是一個 2×2 矩陣，作用在振幅向量上：新向量 = 矩陣 × 舊向量。合法的閘必須是么正矩陣（U†U = I），所以：

  • 總機率永遠保持 1，在 Bloch 球上就是一個旋轉。
  • 每個閘都可逆：H·H = I、X·X = I；量測則不可逆。
  • 連續做幾個閘 = 矩陣相乘，最後做的寫在最左邊：先 H 再 S，寫成 S·H|0⟩。
閘矩陣Bloch 球上
X[[0, 1], [1, 0]]繞 x 軸轉 180°（0 ↔ 1）
Y[[0, −i], [i, 0]]繞 y 軸轉 180°
Z[[1, 0], [0, −1]]繞 z 軸轉 180°（|1⟩ 變號）
H[[1, 1], [1, −1]] / √2繞 x、z 中間的斜軸轉 180°
S[[1, 0], [0, i]]繞 z 軸轉 90°
T[[1, 0], [0, eiπ/4]]繞 z 軸轉 45°

從 |0⟩ 開始按閘：試試 H → S → H，或 H → Z → H（和第 2 個電路範例相同）。

按一個閘，這裡會顯示「矩陣 × 舊向量 = 新向量」。

第 5 課

多位元：張量積、2ⁿ 個振幅與糾纏

兩顆位元有 4 種結果 |00⟩、|01⟩、|10⟩、|11⟩，所以要 4 個振幅。如果兩顆各自獨立，整體狀態是張量積：

(γ|0⟩ + δ|1⟩)q1 ⊗ (α|0⟩ + β|1⟩)q0
= γα|00⟩ + γβ|01⟩ + δα|10⟩ + δβ|11⟩
  • n 顆位元有 2ⁿ 個振幅：10 顆是 1,024 個，50 顆約 10¹⁵ 個，300 顆約 2 × 10⁹⁰ 個，比宇宙裡的原子（約 10⁸⁰ 個）還多。
  • 能寫成張量積的叫乘積態；寫不成的叫糾纏態。兩顆位元的判斷法：a₀₀·a₁₁ = a₀₁·a₁₀ 就是乘積態。
  • CNOT 這類兩位元閘可以把乘積態變成糾纏態，例如 Bell 態 (|00⟩ + |11⟩)/√2。
  • 糾纏態裡，單看任一顆都是隨機的，兩顆對照起來卻有關聯。

把 q0 拖到 90°（|+⟩），再勾選 CNOT：兩顆位元變成糾纏的 Bell 態。

第 6 課

干涉：振幅相加，不是機率相加

電路 H → 相位 φ → H → 量測：第一個 H 把位元分成「0」「1」兩條路徑，相位 φ 只加在「1」那條，第二個 H 再把兩條路徑合起來。

到 0 的振幅 = ½ + ½·eiφ　→　P(0) = cos²(φ/2)
到 1 的振幅 = ½ − ½·eiφ　→　P(1) = sin²(φ/2)
  • 量子力學裡，同一個結果的各條路徑要先把振幅（箭頭）相加，再取長度平方得到機率。
  • 箭頭同向就加強（建設性干涉），反向就抵消（破壞性干涉）。
  • 古典的「丟兩次硬幣」只會把機率相加，結果永遠是 50/50，不會抵消。
  • φ = 180° 時就是 H‑Z‑H = X：100% 量到 1。所有量子演算法都靠這個機制把答案的機率集中起來。

拖動 φ：看兩組箭頭頭接尾相加，箭頭總長的平方就是機率。

量子：P(1) = sin²(φ/2)

總結

看電路前，記住三條規則

1. 狀態是一組振幅

n 顆位元有 2ⁿ 個複數振幅；機率 = |振幅|²。振幅可以有正負、有相位。

2. 閘是可逆的旋轉

每個閘都是么正矩陣，只會重新分配振幅、不會讓機率變多或變少；也因此無法複製一個未知的量子態（不可複製定理）。

3. 量測只給一個答案

量測隨機抽出一個結果並破壞疊加。所以演算法要先用干涉，把答案的機率集中，再量測。
