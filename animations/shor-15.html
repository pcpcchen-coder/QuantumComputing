把「分解質因數」換成「找週期」

量子電腦只負責中間最難的一步，其他步驟都是古典計算。

直接嘗試分解一個大數很難，但數論告訴我們：只要找到函數 f(x) = aˣ mod N 的週期 r（最小的 r 讓 aʳ mod N = 1），就能用最大公因數算出 N 的因數。拿 a = 7、N = 15 來算：

為什麼週期能拿來分解？因為 7⁴ ≡ 1 (mod 15)，代表 7⁴ − 1 是 15 的倍數，而 7⁴ − 1 可以拆成 (7² − 1)(7² + 1) = 48 × 50。15 的因數必定分散在這兩個數裡，所以 gcd(48, 15) = 3、gcd(50, 15) = 5 就把 15 拆開了。這招要成立需要兩個條件：r 是偶數，而且 ar/2 mod N ≠ N − 1。a = 7 兩個條件都符合。

古典電腦找 r 只能一個一個試 x，數字一大（例如 2048 位元）就算不完。量子電腦的做法是：把所有 x 同時放進疊加態，算出 7ˣ mod 15，再用干涉把週期「放大」成可以量測的訊號。

流程：選 a → 檢查 gcd(a, N) = 1 → 量子電路找 r → r 是偶數？ → gcd(ar/2 ± 1, N)
本例：a = 7 → gcd(7, 15) = 1 ✓ → r = 4 → 偶數 ✓ → gcd(48, 15) = 3、gcd(50, 15) = 5

位元順序。本頁跟 Qiskit 一樣，編號 0 是最低位。寫成 ket 時最高位放左邊：|c2 c1 c0⟩、|w3 w2 w1 w0⟩。例如 |011⟩ 是 x = 3，|1101⟩ 是 13。

為什麼工作暫存器是 4 顆？它要裝下 0 到 14 的餘數，2⁴ = 16 > 15，4 顆剛好夠。一般來說需要 n = ⌈log₂N⌉ 顆。

為什麼計數暫存器只有 3 顆？教科書建議用 2n = 8 顆，讓量到的 y/2ᵗ 足夠接近 s/r，連分數才算得出 r。本例的 r = 4 剛好整除 2³ = 8，量到的分數完全精確，所以 3 顆就夠。2001 年 IBM 用核磁共振（NMR）第一次分解 15，也是用 3 + 4 = 7 顆位元。

為什麼工作暫存器從 1 開始？之後的受控閘做的都是「乘法」：把工作暫存器乘上 7、乘上 4。從 1 開始乘，最後得到的就是 7ˣ。如果從 0 開始，怎麼乘都是 0。

Hadamard 閘

3 個 H 閘：同時放進 x = 0 到 7

這一步讓之後的乘法可以一次作用在 8 個 x 上。

H 閘把 |0⟩ 變成「一半 |0⟩、一半 |1⟩」的疊加：

H = (1/√2) [ 1 1 ; 1 −1 ]
H|0⟩ = (|0⟩ + |1⟩)/√2
H|1⟩ = (|0⟩ − |1⟩)/√2

對 c0、c1、c2 各做一次，三個括號乘開剛好是 8 項，每一項就是一個 3 位元的二進位數：

(|0⟩+|1⟩)(|0⟩+|1⟩)(|0⟩+|1⟩) / √8
= ( |000⟩ + |001⟩ + |010⟩ + |011⟩ + |100⟩ + |101⟩ + |110⟩ + |111⟩ ) / √8
= (1/√8) Σx=0..7 |x⟩ 　每項振幅 1/√8 ≈ 0.354，機率 1/8 = 12.5%
|ψ₁⟩ = (1/√8) Σx=0..7 |x⟩ ⊗ |0001⟩

工作暫存器還沒被動到，所以兩個暫存器現在是「各過各的」（沒有糾纏）。

受控模乘法（模冪）

把 7ˣ mod 15 寫進工作暫存器

這是整個演算法最花閘的部分，也是週期被寫進量子態的地方。

3.1　把指數拆成二進位

我們要的是把 |x⟩|1⟩ 變成 |x⟩|7ˣ mod 15⟩。定義一個么正運算 U|y⟩ = |7y mod 15⟩（乘以 7 再取餘數）。因為 x = c0·1 + c1·2 + c2·4，所以

7ˣ = 7c0 · 72·c1 · 74·c2　⇒　Ux = (U¹)c0 · (U²)c1 · (U⁴)c2
控制位元要做的運算等於乘以用到的閘
c0U¹7 mod 15 = 73 個 Fredkin + 4 個 CNOT
c1U²49 mod 15 = 42 個 Fredkin
c2U⁴2401 mod 15 = 1不需要任何閘

「受控」的意思是：控制位元是 |1⟩ 就執行，是 |0⟩ 就不動。控制位元處在疊加態時，兩個分支會同時發生，所以 8 個 x 各自拿到自己該乘的結果。

3.2　×7 mod 15 的位元技巧

15 這個數很特別：16 ≡ 1 (mod 15)。所以一個 4 位元數乘以 2 再 mod 15，結果正好是把位元循環左移 1 格（最高位繞回最低位）。由此得到兩個好用的結果：

循環右移 1 格 = 循環左移 3 格 = ×2³ = ×8 (mod 15)　← 3 個 SWAP
4 個位元全部翻轉：y → 15 − y = ×(−1) (mod 15)　← 4 個 X
兩個合起來：×8 × (−1) = ×(−8) ≡ ×7 (mod 15)

3.4　受控 U²（×4）與 U⁴（×1）

×4 = ×2²，也就是循環左移 2 格：w0 ↔ w2、w1 ↔ w3 兩組對調。只要 2 個 Fredkin，控制位元是 c1。

驗算：y = 7 = 0111，交換 w1、w3 得到 1101，再交換 w0、w2（兩個都是 1，沒變），結果 1101 = 13，而 7 × 4 = 28 = 15 + 13 ✓。

U⁴ 是 ×7⁴ = ×2401 ≡ ×1 (mod 15)，等於什麼都不做，所以 c2 不接任何閘。c2 還是有用：它經過 H 之後參與逆 QFT 的干涉，決定量測結果的最高位。

週期 4 已經藏在量子態裡：工作暫存器值相同的那些 x，彼此都相差 4。但現在直接量計數暫存器只會隨機得到 0 到 7 之一，看不出週期。下一步要用干涉把它變成看得出來的訊號。

另一種看法：相位回踢。U 的本徵態是 |us⟩ = ½ Σk=0..3 e−2πi·sk/4 |7ᵏ mod 15⟩，本徵值是 e2πi·s/4，s = 0, 1, 2, 3。起始的 |1⟩ 剛好等於 ½(|u₀⟩+|u₁⟩+|u₂⟩+|u₃⟩)。受控 U 作用在本徵態上時，工作暫存器不變，反而把相位 e2πi·s/4 「踢回」控制位元。所以計數暫存器裡記的是相位 s/r，逆 QFT 再把這個相位讀出來。這就是量子相位估計（QPE）的觀點，兩種看法結果完全相同。

3.6　實驗用的精簡版

受控 U¹ 的輸入其實永遠是 |0001⟩，不需要一個對所有 y 都正確的乘法器。c0 = 1 時只要把 0001 變成 0111，也就是翻轉 w1、w2，2 個 CNOT 就夠，取代原本的 3 個 Fredkin + 4 個 CNOT。

早期分解 15 的實驗大多用這種「已知輸入」的精簡電路。它的結果和完整版一模一樣（本頁的數值已用 Qiskit 驗證），但只適用於這個特定例子，不能推廣成通用的分解程式。

逆量子傅立葉轉換（QFT†）

用干涉把週期變成尖峰

3 顆位元的逆 QFT 只要 7 個閘：1 個 SWAP、3 個 H、3 個受控相位閘。

QFT 把「位置」變成「頻率」。逆 QFT 的定義是：

QFT† |x⟩ = (1/√8) Σy=0..7 e−2πi·xy/8 |y⟩　（x 每加 1，|y⟩ 的相位就多轉 −45°·y）

輸入是「每隔 4 格出現一次」的疊加時，只有頻率和週期對得上的 y 會互相加強，其他 y 會互相抵消。週期 r = 4，在 8 格裡重複 8/4 = 2 次，所以尖峰出現在 2 的倍數：y = 0、2、4、6。

受控相位閘 CP(θ) 的矩陣是 diag(1, 1, 1, eiθ)：只有兩顆位元都是 1 的項會乘上相位 eiθ，其他項不變。它對兩顆位元是對稱的，哪顆當控制都一樣。

為什麼 SWAP 放在最前面？標準 QFT 電路的輸出位元順序是倒過來的，最後要用 SWAP 反轉回來。逆 QFT 是把 QFT 的閘倒著做、角度取負號，所以 SWAP 變成第一個閘。

5.2　干涉：為什麼奇數 y 會消失

假設工作暫存器是 w（第 4 步選的值），計數暫存器是 (|x₀⟩ + |x₀+4⟩)/√2。逆 QFT 之後，量到 y 的振幅是兩支箭頭相加：

振幅(y) = ¼ · ( e−2πi·x₀y/8 + e−2πi·(x₀+4)y/8 ) = ¼ · e−2πi·x₀y/8 · ( 1 + e−iπy )
y 偶數：e−iπy = +1 → 兩支同向，長度 ½ → 機率 ¼
y 奇數：e−iπy = −1 → 兩支反向，互相抵消 → 機率 0

換算方式：Fredkin ≈ 8 個 CNOT、SWAP = 3 個 CNOT、受控相位閘 = 2 個 CNOT 加單位元旋轉。實際數字會隨硬體的原生閘與編譯器最佳化而不同。

三個關鍵角色

H 閘負責「平行」：把 8 個 x 同時放進疊加態。

受控 U 負責「寫入週期」：讓工作暫存器和 x 糾纏，相差 4 的 x 綁在一起。

逆 QFT 負責「讀出週期」：用干涉消掉不對的頻率，只留下 8/r 的整數倍。

放大到真實的 RSA

分解 15 只是示範。RSA-2048 的 N 有 2048 位元，計數暫存器要約 4000 顆位元，模乘法也不能再用循環移位的技巧，要用真正的量子算術電路，而且需要量子錯誤更正。2019 年 Gidney 與 Ekerå 估計約需 2,000 萬顆實體位元；2025 年 Gidney 把估計降到不到 100 萬顆有雜訊的實體位元，運算約一週。目前的硬體還差得很遠。

Qiskit 程式碼

# Shor 演算法：N = 15, a = 7，3 顆計數位元 + 4 顆工作位元
import numpy as np
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister
from qiskit_aer import AerSimulator

c = QuantumRegister(3, "c")    # 計數暫存器 c0..c2（c0 是最低位）
w = QuantumRegister(4, "w")    # 工作暫存器 w0..w3（w0 是最低位）
m = ClassicalRegister(3, "m")
qc = QuantumCircuit(c, w, m)

# ① 初始化：工作暫存器 = |0001⟩ = 1
qc.x(w[0])

# ② 疊加：計數暫存器 = x = 0..7
qc.h(c)

# ③ 受控 U¹：×7 mod 15 = 循環右移（×8）+ 全部翻轉（×(−1)）
qc.cswap(c[0], w[0], w[1])
qc.cswap(c[0], w[1], w[2])
qc.cswap(c[0], w[2], w[3])
for q in w:
    qc.cx(c[0], q)

# ③ 受控 U²：×4 mod 15 = 循環移 2 格
qc.cswap(c[1], w[1], w[3])
qc.cswap(c[1], w[0], w[2])

# ③ 受控 U⁴：7⁴ ≡ 1 (mod 15)，不需要任何閘

# ④ 逆 QFT
qc.swap(c[0], c[2])
qc.h(c[0])
qc.cp(-np.pi / 2, c[0], c[1])
qc.h(c[1])
qc.cp(-np.pi / 4, c[0], c[2])
qc.cp(-np.pi / 2, c[1], c[2])
qc.h(c[2])

# ⑤ 量測
qc.measure(c, m)

counts = AerSimulator().run(qc, shots=1000).result().get_counts()
print(counts)   # 約 {'000': 250, '010': 250, '100': 250, '110': 250}

from fractions import Fraction
from math import gcd
for bits in counts:
    y = int(bits, 2)
    r = Fraction(y, 8).limit_denominator(15).denominator
    if y and pow(7, r, 15) != 1:      # 例如 y = 4 → r = 2，試倍數
        r *= 2
    if y and r % 2 == 0 and pow(7, r, 15) == 1:
        h = pow(7, r // 2, 15)
        print(bits, "→ r =", r, "→ 因數", gcd(h - 1, 15), gcd(h + 1, 15))
